**Purpose.**
- AN1 opens with the axioms of a complete ordered field and goes straight to sequences, limits and continuity. Every one of those chapters handles functions ℝ ⊇ D → ℝ as finished objects: it adds and composes them, inverts monotone ones, takes their sup over a set, floors them, and uses polynomials, exp, log and real powers as examples. This chapter supplies that vocabulary **with proofs from the complete ordered field**, so that AN1 never stops to justify it.
- It proves the factor theorem and "a nonzero polynomial function of degree ≤ d has at most d roots" **directly on functions ℝ → ℝ**, without fd5 (spec/08 §A2: "不依賴 F5"); the formal ring R[x] stays in *Algebraic Preliminaries*.
- It introduces exp through a **borrowed box** (E1)–(E3), paid in AN1.10, and derives from the box everything AN1 needs: positivity, monotonicity, the bounds 1 + x ≤ exp x ≤ 1/(1 − x), **uniqueness** (any two functions satisfying (E1), (E2) are equal, proved here by a supremum), log, real powers and their laws, and the growth comparisons.
- It builds the **table of strange functions** that AN1 cites (spec/08 §A2, §C5): Dirichlet, x·𝟙_ℚ, Thomae, a bijection monotone on no interval, a strictly increasing function with a gap in its image, a staircase with infinitely many steps that hugs the diagonal, a zigzag that takes every value of [0, 1/2] near 0, an unbounded function on a closed interval, a bounded function on a closed interval whose sup is not attained. Each entry carries only what can be proved now; the questions continuity and integration ask of it are named, and answered later.
- **Nothing here uses limits, continuity or derivatives.** The only completeness tool is the supremum. (§07's Looking-ahead remark says this, checkably.)
- The reader leaves able to (i) prove a function monotone by factoring out y − x; (ii) prove an inequality between suprema by bounding every value and by producing a witness within ε; (iii) pin down a floor by its defining inequality; (iv) bound a polynomial by its leading term; (v) compute with exp, log and a^x knowing exactly which borrowed fact each step uses.

**Signature moves** (`index.md`, "Named moves"; each links to its method box).
- **Read a graph as a set of pairs** (`exm-method-graph-pairs`, §01): a statement about pictures becomes a statement "(x, y) ∈ graph g ⟺ (x′, y′) ∈ graph f".
- **Factor out y − x** (`exm-method-factor-difference`, §02): to prove f strictly increasing on D, write f(y) − f(x) = (y − x)·Q(x, y) for x < y in D and show Q(x, y) > 0.
- **Bound every value, then find a witness** (`exm-method-sup-two-halves`, §03): sup_A f ≤ M by bounding each f(x); sup_A f ≥ M by producing, for each ε > 0, an x ∈ A with f(x) > M − ε. (Faded triple, below.)
- **Pin the floor by its inequality** (`exm-method-floor-inequality`, §04): ⌊A⌋ = m is proved by m ≤ A < m + 1, or by "for every integer j: j ≤ A ⟺ j ≤ m".
- **Let the leading term dominate** (`exm-method-leading-term`, §05): for |x| ≥ R, the lower terms of a polynomial are smaller than its top term, with R written down from the coefficients.
- **Squeeze, then close the gap by Archimedes** (`exm-method-archimedes-squeeze`, §06): if every element of a set is ≤ L and some are ≥ L − C/n for every n, then the sup is L.

## 01-real-functions-and-graphs.md — Real Functions and Their Graphs

Budget: 3,500 main-line words; fold ≤ 300. Idea-level method section.

- **Hook.** "Let f(x) = x²/x." What is f(0)? A formula is not a function until its domain is named, and two formulas on different domains are different functions even when they agree wherever both make sense. fd2 already made this precise (`@fd2:def-function`, `@fd2:prp-function-equality`); here we specialize to D ⊆ ℝ and learn to read a graph as the set of pairs it is.
- **`def-real-function`.** A real function is a function f: D → ℝ with D ⊆ ℝ (`@fd2:def-function`); its graph is graph f ≔ {(x, f(x)) : x ∈ D} ⊆ ℝ² (`@fd2:def-cartesian-product`). Two real functions are equal iff same domain and same value at each point (`@fd2:prp-function-equality`).
- **`exm-first-real-functions`.** Constant, identity, |x| (fd3's absolute value as a function), x ↦ 1/x on ℝ∖{0}, √x on [0, ∞) (`@fd3:prp-cof-square-roots`), the restriction of x ↦ x² to [0, ∞), and 𝟙_A for A ⊆ ℝ. Figure: |x| and 1/x.
- **`prp-graph-vertical-line`.** For D ⊆ ℝ and G ⊆ ℝ²: G is the graph of a real function on D iff for every a ∈ D there is exactly one y with (a, y) ∈ G, and no (a, y) ∈ G has a ∉ D. Proof: unwinding `@fd2:def-function`. (Effort in proportion: three sentences.)
- **Warning.** No natural-domain convention. "x²/x" on ℝ∖{0} and x on ℝ differ (domains); the first is the restriction of the second. A set like {(x, y) : x² + y² = 1} is not a graph over any D (the pairs (0, 1), (0, −1)).
- **Quick check.** Which of these are graphs, and over which D: {(x, y) : y = x²}; {(x, y) : x = y²}; {(x, y) : y ≥ 0, x = y²}? (Yes over ℝ; no, (1, 1) and (1, −1); yes, over [0, ∞), the graph of √.)
- **`def-function-algebra`.** f + g, fg, cf on D_f ∩ D_g; f/g on {x ∈ D_f ∩ D_g : g(x) ≠ 0}; max(f, g), min(f, g), |f| pointwise; g ∘ f on {x ∈ D_f : f(x) ∈ D_g}, which is fd2's composition of g with the restriction of f, codomain shrunk (`@fd2:def-composition`; one sentence says so). Associativity of ∘ with these domains: pointer to `@fd2:prp-composition-associative` (both sides have domain {x : f(x) ∈ D_g, g(f(x)) ∈ D_h}).
- **`exm-method-graph-pairs`** `[Method: reading a graph as a set of pairs]`. Template: to prove "the graph of g is the graph of f moved by M", show for all (x, y): (x, y) ∈ graph g ⟺ M⁻¹(x, y) ∈ graph f, by unwinding y = g(x) into a statement about f. When: transformations, inverses (§02), symmetry. Usual failure: moving the graph the wrong way (the graph of x ↦ f(x − a) is moved **right** by a, since (x, y) ∈ graph g ⟺ (x − a, y) ∈ graph f).
- **`prp-graph-transformations`.** Let f: D → ℝ, a, b ∈ ℝ, c > 0. (a) g(x) ≔ f(x − a) + b on D + a has graph graph f + (a, b); (b) x ↦ f(−x) on −D has graph the reflection (x, y) ↦ (−x, y) of graph f; (c) −f has graph the reflection (x, y) ↦ (x, −y); (d) cf has graph {(x, cy)}, and x ↦ f(x/c) on cD has graph {(cx, y)}. Proof of (a) in full by the method; (b)–(d) "the same unwinding" with one line each. Figure: |x| and |x − 1| − 2.
- **`def-even-odd-function`.** D symmetric (x ∈ D ⇒ −x ∈ D); even: f(−x) = f(x); odd: f(−x) = −f(x). In graph language (by (b), (c)): even iff graph symmetric about the y-axis; odd iff symmetric about the origin.
- **`prp-even-odd-decomposition`.** On a symmetric D, every f is f = e + o with e even, o odd, in exactly one way: e(x) = (f(x) + f(−x))/2, o(x) = (f(x) − f(−x))/2. Uniqueness: e − e′ = o′ − o is even and odd, hence 0 (h(x) = h(−x) = −h(x) gives 2h(x) = 0).
- **Exercises.**
  - **A1.** Graph or not, and over which D: (a) {(x, y) : y² = x}, D = [0, ∞) — no: (1, 1), (1, −1); (b) {(x, y) : y = |x|} — yes, D = ℝ; (c) {(x, y) : x = 2} — over no D (two points (2, 0), (2, 1)); (d) {(x, y) : xy = 1} — yes, D = ℝ∖{0}, the function 1/x. **A2** `[Is this legal? ## 02-monotone-functions-and-inverses.md — Monotone Functions and Inverse Functions

Budget: 4,000 main-line words; fold ≤ 400. **Full-level method section.**

- **Hook.** "1/x is decreasing" — on ℝ∖{0}? Then −1 < 1 would give 1/(−1) ≥ 1/1, which is false. Decreasing on each half, not on the union. The definition must name the set, and the proof must use only that set.
- **`def-monotone-function`.** For f: D → ℝ and A ⊆ D: increasing on A (x < y in A ⇒ f(x) ≤ f(y)), strictly increasing, decreasing, strictly decreasing; monotone / strictly monotone. Quantifiers in symbols (STYLE §10). Constant functions are increasing and decreasing.
- **Quick check** (weird examples first). Is a constant function increasing? Is 1/x decreasing on ℝ∖{0}? Is 𝟙_{[0, ∞)} increasing? (Yes, and decreasing, not strictly; no, the hook's pair; yes, not strictly.)
- **`exm-method-factor-difference`** `[Method: factor out y − x]`. Template: fix x < y in A; write f(y) − f(x) = (y − x)·Q(x, y); show Q(x, y) > 0 (resp. ≥ 0, < 0) for all x < y in A. When: polynomial and rational expressions; whenever a difference of powers appears (yⁿ − xⁿ = (y − x)Σ_{j<n} x^j y^{n−1−j}, `@fd2:prp-geometric-sum` or ⟨F4.6⟩ `prp-finite-sum-rules`, telescoping). Usual failures: (i) proving Q ≥ 0 and concluding strict; (ii) using a sign of x or y that holds only on part of A — split A first. **Givens/Goal paragraph** (prose form, STYLE §12.5): Givens: x, y ∈ A, x < y, the formula for f; Goal: f(x) < f(y); the gap: the sign of f(y) − f(x).
- **`exm-cube-increasing`** (worked example 1, with `[Scratch work]`). x ↦ x³ is strictly increasing on ℝ: y³ − x³ = (y − x)(y² + xy + x²) and y² + xy + x² = (y + x/2)² + 3x²/4 > 0 unless x = y = 0, which x < y excludes. Scratch work shows the attempt "x < y ⇒ x³ < y³ by multiplying inequalities" failing for negative numbers (−2 < 1 but multiplying −2 < 1 by itself is illegal), then the factoring.
- **`exm-squash-function`** (worked example 2). σ(x) ≔ x/(1 + |x|) is strictly increasing on ℝ with image (−1, 1). Split: for 0 ≤ x < y, σ(y) − σ(x) = (y − x)/((1 + x)(1 + y)); for x < y ≤ 0, (y − x)/((1 − x)(1 − y)); for x < 0 ≤ y, σ(x) < 0 ≤ σ(y). Image: |σ(x)| < 1, and for v ∈ [0, 1), x = v/(1 − v) ≥ 0 gives σ(x) = v; for v ∈ (−1, 0), x = v/(1 + v). Sidecar checks the two difference formulas.
- **`prp-monotone-algebra`.** On A ⊆ D_f ∩ D_g: (a) f, g increasing ⇒ f + g increasing, strictly if one is strict; (b) c ≥ 0 and f increasing ⇒ cf increasing; −f decreasing; (c) f, g increasing and ≥ 0 on A ⇒ fg increasing; (d) f increasing and > 0 on A ⇒ 1/f decreasing; (e) for g ∘ f with f(A) ⊆ B: f increasing on A and g increasing on B ⇒ g ∘ f increasing; f increasing and g decreasing ⇒ decreasing; both decreasing ⇒ increasing; "strictly" carries through when both are strict. Proofs: one line each from `@fd3:prp-ordered-ring-rules`, `@fd3:prp-ordered-field-halves` (d), `@fd3:prp-reciprocal-order`. Warning after (c): drop "≥ 0" and it fails: f = g = x on ℝ gives fg = x², and −1 < 0 while (−1)² = 1 > 0 = 0².
- **`prp-strictly-monotone-injective`.** If f is strictly increasing on A then f is injective on A and for x, y ∈ A: x < y ⟺ f(x) < f(y), x ≤ y ⟺ f(x) ≤ f(y). Proof: trichotomy (`@fd3:prp-ordered-ring-rules` / `@fd2:def-partial-order`, total order). **Self-explanation prompt** in the next proof refers back here.
- **`exm-injective-not-monotone`** (Warning: the converse fails). f on ℝ: f(0) ≔ 1, f(1) ≔ 0, f(x) ≔ x otherwise: injective, neither increasing (f(0) > f(1)) nor decreasing (f(1) < f(2)). Second: 1/x on ℝ∖{0} is injective and not monotone. (AN1.6 shows that on an interval a **continuous** injective function is strictly monotone: prose, no `@ref`.)
- **`thm-monotone-inverse`.** Let f: A → ℝ be strictly increasing (A ⊆ ℝ). Then f, viewed as a map A → f(A), is a bijection; its inverse f⁻¹: f(A) → A is strictly increasing; and graph f⁻¹ = {(y, x) : (x, y) ∈ graph f}, the reflection of graph f in the line y = x. Same with "decreasing". *Idea* short (citing the method box for the graph part). Proof: surjective onto f(A) by definition of image (`@fd2:def-image`), injective by `prp-strictly-monotone-injective`, so `@fd2:thm-bijection-iff-inverse` gives f⁻¹; for u < v in f(A) write u = f(x), v = f(y); if x ≥ y then f(x) ≥ f(y), i.e. u ≥ v; so x < y. Graph: (y, x) ∈ graph f⁻¹ ⟺ x = f⁻¹(y) ⟺ f(x) = y ⟺ (x, y) ∈ graph f. Self-explanation prompt: "where is totality of ≤ used?" (in "if x ≥ y": the negation of x < y is x ≥ y only in a total order).
- **`exm-odd-roots`** (and the root as an inverse). ## 03-bounds-and-suprema-of-functions.md — Bounded Functions and Their Suprema

Budget: 4,500 main-line words; fold ≤ 400. **Full-level method section.** Opening frame recalls `@fd3:def-complete-ordered-field` and `@fd2:def-order-supremum` (spiral: sup of a set in a poset → in ℝ → of a function).

- **Hook.** x/(1 + x) on [0, ∞) stays below 1, creeps toward it, never reaches it. "Its maximum is 1" is false; "its least upper bound is 1" is true and needs proof in two halves.
- **`prp-real-infimum`.** Every non-empty A ⊆ ℝ bounded below has an infimum, and inf A = −sup(−A) (`@fd2:exm-sets-of-numbers-as-images` for −A). Proof: lower bounds of A are the negatives of upper bounds of −A. (If F4.6 owns it: citation.)
- **`prp-real-sup-approximation`.** Let A ⊆ ℝ be non-empty and s an upper bound of A. Then s = sup A iff for every ε > 0 there is a ∈ A with a > s − ε. Mirror for inf. Proof: (⇒) s − ε < s is not an upper bound; (⇐) an upper bound u < s gives ε ≔ s − u and a witness a > u.
- **`def-bounded-function`.** f: D → ℝ is bounded above (below) on A ⊆ D if f(A) is; bounded if both; equivalently, some M with |f(x)| ≤ M on A (`@fd3:prp-absolute-value-ordered-field` (d)).
- **`def-sup-of-function`.** For non-empty A ⊆ D with f bounded above on A: sup_A f ≔ sup f(A); inf_A f likewise; f **attains** its sup on A if sup_A f ∈ f(A), and then sup_A f = max_A f.
- **`exm-method-sup-two-halves`** `[Method: bound every value, then find a witness]`. Template: to prove sup_A f = M: (≤) show f(x) ≤ M for every x ∈ A; (≥) given ε > 0, produce x ∈ A with f(x) > M − ε (or: show any M′ < M is exceeded). Givens/Goal paragraph. When: every sup computation and every inequality between sups. Usual failures: (i) proving only (≤); (ii) choosing the witness for one ε and calling it done for all; (iii) mixing witnesses from two functions (see C3).
- **`exm-sup-not-attained`** (worked example 1, `[Scratch work]`). sup_{[0, ∞)} x/(1 + x) = 1, not attained. (≤): x/(1 + x) < 1. (≥): scratch work solves x/(1 + x) > 1 − ε backwards for 0 < ε < 1 ("x > (1 − ε)/ε"); the proof takes x ≔ 1/ε and checks 1/(1 + ε) > 1 − ε since (1 − ε)(1 + ε) = 1 − ε² < 1; for ε ≥ 1 take x = 0 (0 > 1 − ε). inf = 0 attained at 0.
- **`exm-sup-attained-parabola`** (worked example 2). sup_{[0, 1]} x(1 − x) = 1/4, attained at 1/2: x(1 − x) = 1/4 − (x − 1/2)² ≤ 1/4 (or ⟨F4.6⟩ `thm-am-gm` with the two numbers x, 1 − x). Here (≥) needs no ε: an attained value is its own witness.
- **Quick check.** sup and inf of x² on (−1, 2); attained? (4, not attained; 0, attained at 0.) And of 𝟙_ℚ on [0, 1]? (1 and 0, both attained.)
- **`thm-sup-function-rules`.** Let A be non-empty, f, g: D → ℝ bounded above on A ⊆ D, c ∈ ℝ. (a) f ≤ g on A ⇒ sup_A f ≤ sup_A g; (b) sup_A (f + g) ≤ sup_A f + sup_A g; (c) sup_A (f + c) = sup_A f + c; (d) for c ≥ 0, sup_A (cf) = c sup_A f; (e) for f bounded below, sup_A (−f) = −inf_A f; (f) for non-empty B ⊆ A, sup_B f ≤ sup_A f; (g) for f, g bounded on A, |sup_A f − sup_A g| ≤ sup_A |f − g|. Proofs: (a), (b), (f) by the first half only ("bound every value"); (c), (d) two halves, (d) with the case c = 0 separately; (e) from `prp-real-infimum`; (g) from f ≤ g + |f − g| ≤ g + sup_A |f − g| and (a), (c), then symmetry. Faded triple, full step: (b) and (d) written out with the method's two halves named. Warning after (b): strict inequality occurs (f = x, g = 1 − x on [0, 1]: 1 < 2).
- **`prp-sup-oscillation`** (key proof; try it first). For f bounded on non-empty A: sup{|f(x) − f(y)| : x, y ∈ A} = sup_A f − inf_A f. Idea from the obstacle: the obvious candidate pair (a maximizer and a minimizer) may not exist; take near-maximizer and near-minimizer within ε/2 each. Proof: (≤) for x, y ∈ A, f(x) − f(y) ≤ sup f − inf f, and by symmetry so is f(y) − f(x), hence |f(x) − f(y)| ≤ sup f − inf f (`@fd3:prp-absolute-value-ordered-field` (d)); (≥) by `prp-real-sup-approximation`, x with f(x) > sup f − ε/2 and y with f(y) < inf f + ε/2, so |f(x) − f(y)| ≥ f(x) − f(y) > sup f − inf f − ε. Self-explanation prompt: "why ε/2 and not ε?" AN2 calls this number the oscillation of f on A (prose).
- **`prp-iterated-sup`** (fold or main line, drafter's choice; budget counted as main line). For f: A × B → ℝ bounded above, A, B non-empty: sup_{(a, b) ∈ A × B} f(a, b) = sup_{a ∈ A} sup_{b ∈ B} f(a, b) = sup_{b ∈ B} sup_{a ∈ A} f(a, b). Proof: the inner sups exist and are ≤ the total sup S; conversely each f(a, b) ≤ sup_b f(a, b) ≤ sup_a sup_b f, so S ≤ it. Used by AN2 (double series; spec/08 AN2.12) and F4.11 (sup metrics).
- **Exercises.**

## 04-floor-and-step-functions.md — Floor, Distance to the Integers, and Step Functions

Budget: 4,000 main-line words; fold ≤ 300. Idea-level method section.

- **Hook.** F3.2 and F3.9 gave every element of an Archimedean field an integer part. As a function on ℝ, x ↦ ⌊x⌋ is the first function in the book that jumps; it is also the tool behind counting, rounding and the strange functions of §07.
- **`def-floor-ceiling`.** ℝ is Archimedean (`@fd3:thm-reals-complete-ordered-field`, `@fd3:thm-cof-complete-archimedean`), so by `@fd3:prp-integer-part-ordered-field` each x ∈ ℝ has exactly one m ∈ ℤ with m ≤ x < m + 1: ⌊x⌋ ≔ m. ⌈x⌉ ≔ −⌊−x⌋. The fractional part x − ⌊x⌋ ∈ [0, 1). (ℤ ⊆ ℝ via ι_ℝ, one sentence citing `@fd3:thm-rationals-embed-ordered-field`.) Figure: ⌊x⌋ on [−2, 3] with closed/open endpoints.
- **`exm-method-floor-inequality`** `[Method: pin the floor by its inequality]`. Template: to prove ⌊A⌋ = m, show m ∈ ℤ and m ≤ A < m + 1 (uniqueness does the rest); or show "for every j ∈ ℤ: j ≤ A ⟺ j ≤ m" (`prp-floor-rules` (g)). Usual failure: computing ⌊A⌋ by "dropping the decimals", which is wrong for negative A (⌊−2.5⌋ = −3).
- **`prp-floor-rules`.** For x, y ∈ ℝ, n ∈ ℤ, k ∈ ℤ_{>0}: (a) x − 1 < ⌊x⌋ ≤ x, and ⌊x⌋ = x iff x ∈ ℤ; (b) ⌊x + n⌋ = ⌊x⌋ + n; (c) x ≤ y ⇒ ⌊x⌋ ≤ ⌊y⌋ (increasing, not strictly); (d) ⌊x⌋ + ⌊y⌋ ≤ ⌊x + y⌋ ≤ ⌊x⌋ + ⌊y⌋ + 1; (e) ⌊−x⌋ = −⌊x⌋ if x ∈ ℤ and −⌊x⌋ − 1 otherwise; (f) ⌈x⌉ is the unique m ∈ ℤ with m − 1 < x ≤ m; (g) for j ∈ ℤ: j ≤ x ⟺ j ≤ ⌊x⌋; (h) ⌊⌊x⌋/k⌋ = ⌊x/k⌋. Proofs: (a), (b), (d), (e), (f) by the method (pin by inequality); (g) (⇐) transitivity, (⇒) j ≤ x < ⌊x⌋ + 1 gives j < ⌊x⌋ + 1, so j ≤ ⌊x⌋ by discreteness of ℤ (cite fd3's discreteness clause used in `@fd3:prp-integer-part-ordered-field`'s proof: `@fd3:thm-integers-ordered-ring` (c)); (c) from (g); (h) worked in full as the method's second form: for j ∈ ℤ, j ≤ ⌊x⌋/k ⟺ jk ≤ ⌊x⌋ ⟺ jk ≤ x ⟺ j ≤ x/k (by (g) twice), and two integers with the same integers below them are equal.

## 05-polynomial-functions.md — Polynomial Functions and Their Roots

Budget: 4,000 main-line words; fold ≤ 400. Idea-level method section. Opening frame: fd3 Ch6 used polynomial functions of a list of coefficients in its example ℝ(x) (`@fd3:exm-rational-function-field` after the fd3 re-cut; ℝ(x) and `lem-cof-polynomial-closure` are parked for AN1.11 (fd3 re-cut, 2026-10-26, fd3/authoring/design/layout-proposal.md); was `@fd3:lem-cof-polynomial-closure`); here they become objects with a degree and a root count, all on ℝ. One sentence: *Algebraic Preliminaries* treats polynomials as formal expressions over any field; nothing here needs that.

- **Hook.** Can x³ − 2x² − x + 2 vanish at four points? We find three (−1, 1, 2). The factor theorem says why there is no fourth, and that argument works for every degree.
- **`def-real-polynomial-function`.** For a list (a₀, …, a_d) of reals, p(x) ≔ Σ_{i=0}^{d} a_i xⁱ on ℝ (`@fd2:def-sum-product`, `@fd2:def-power`). Sums and products of polynomial functions are polynomial functions, with the top coefficient of a product the product of the top coefficients: cite `@fd3:lem-cof-polynomial-closure` (a), (b) (stated there for arbitrary lists over ℝ).
- **`thm-real-factor-theorem`.** Let p be given by (a₀, …, a_d) with d ≥ 1, and c ∈ ℝ. There is a list (b₀, …, b_{d−1}) with b_{d−1} = a_d such that p(x) − p(c) = (x − c)q(x) for every x, q given by the b's. In particular p(c) = 0 ⇒ p(x) = (x − c)q(x). Proof: p(x) − p(c) = Σ a_i (xⁱ − cⁱ) and xⁱ − cⁱ = (x − c) Σ_{j=0}^{i−1} x^j c^{i−1−j} (telescoping, ⟨F4.6⟩ `prp-finite-sum-rules`); exchanging the finite double sum gives b_j = Σ_{i=j+1}^{d} a_i c^{i−1−j}, so b_{d−1} = a_d. Sidecar checks the b_j formula symbolically for d ≤ 5.
- **`thm-real-polynomial-root-count`** (key proof; try it first; proof ordering in B2). If (a₀, …, a_d) has a_d ≠ 0, the set of roots {x : p(x) = 0} is finite with at most d elements. Proof by induction on d (`@fd1:ax-induction`): d = 0: p = a₀ ≠ 0 has no roots. Step d ≥ 1: if p has no root, done; otherwise fix a root c, p(x) = (x − c)q(x) with q of top coefficient a_d ≠ 0 and length d; a root r ≠ c of p is a root of q (no zero divisors, `@fd3:lem-field-fraction-rules` (d)); so roots(p) ⊆ roots(q) ∪ {c}, which has at most (d − 1) + 1 elements (`@fd2:prp-subset-finite`, `@fd2:prp-disjoint-union-count`). Self-explanation prompt: "where is 'no zero divisors' used?"
- **`cor-polynomial-function-identity`.** If two lists of length at most d + 1 give polynomial functions that agree at d + 1 distinct points (in particular, everywhere), the lists agree after padding with zeros. Proof: the difference list, if not all zero, cut after its last non-zero entry, has degree e ≤ d and at least d + 1 > e roots. Compare `@fd3:lem-cof-polynomial-closure` (c), which needs agreement for all large t.
- **`def-polynomial-function-degree`.** By the corollary a non-zero polynomial function determines its coefficient list up to trailing zeros; its degree is the index of the last non-zero coefficient, its leading coefficient that coefficient. The zero function has no degree (one sentence: AN and LA conventions differ; this volume never needs deg 0).
- **`exm-method-leading-term`** `[Method: let the leading term dominate]`. Template: for p of degree d ≥ 1, set S ≔ |a₀| + … + |a_{d−1}| and R ≔ 1 + S/|a_d|; for |x| ≥ R the lower terms are smaller in absolute value than a_d xᵈ. When: signs of p far out, roots bounds, growth comparisons, limits at infinity (AN1). Usual failure: forgetting |x| ≥ 1 when bounding |x|ⁱ ≤ |x|^{d−1}.
- **`prp-polynomial-leading-term`.** With S, R as above and |x| ≥ R: (a) |p(x) − a_d xᵈ| < |a_d| |x|ᵈ, so p(x) ≠ 0 and p(x) has the sign of a_d xᵈ; (b) |p(x)| ≥ |a_d| |x|^{d−1}. Consequences: every root lies in (−R, R); a non-constant polynomial function is unbounded on ℝ; for odd d, p takes both signs. Proof: for |x| ≥ 1, |Σ_{i<d} a_i xⁱ| ≤ S|x|^{d−1} = |a_d|(R − 1)|x|^{d−1} < |a_d| |x|ᵈ since |x| > R − 1; (b) |p(x)| ≥ |a_d||x|^{d−1}(|x| − R + 1) ≥ |a_d| |x|^{d−1} (reverse triangle, `@fd3:prp-absolute-value-ordered-field` (f)). Worked example: p(x) = x³ − 2x² − x + 2: S = 4, R = 5, roots in (−5, 5) (they are −1, 1, 2). Prose: that an odd-degree p has a root needs more than signs, namely the intermediate value theorem of AN1.
- **`def-rational-function`.** r = p/q with q not the zero function, on {x : q(x) ≠ 0}, which omits at most deg q points (`thm-real-polynomial-root-count`). Warning: (x² − 1)/(x − 1) and x + 1 are different functions (domains), equal on ℝ∖{1}.
- **Quick check.** Can a polynomial function of degree 2 vanish at 0, 1 and 2? Is x ↦ |x| a polynomial function on [0, ∞)? (No, unless it is zero — then it has no degree; yes: the restriction of x.) The second question returns in R4 (on all of ℝ).

## 06-exponential-and-logarithm.md — The Exponential, the Logarithm, and Real Powers

Budget: 4,800 main-line words; fold ≤ 600 (C3 and the remark on (E3)). Idea-level method section.

- **Hook.** F4.6 gave 2^{3/2}. What is 2^{√2}? Not a root of anything; and "the limit of 2^q as q → √2" needs limits. The way through is the exponential function. Its construction needs power series, which belong to analysis; this section borrows exactly three facts about it, says so in one box, and derives the rest, including the fact that those three already pin the function down.
- **`ax-exponential`** `[What This Volume Borrows about the Exponential]`. There is a function exp: ℝ → ℝ with (E1) exp(x + y) = exp x · exp y for all x, y; (E2) exp x ≥ 1 + x for every x; (E3) for every y > 0 there is x ∈ ℝ with exp x = y. **Assumed here and proved in AN1.10** (the drafter names the volume and chapter as books.json and the atlas give them at S3; spec/08 §C3 moves AN1.10 into the AN2 volume). Paragraph in the manner of `ax-cosine-sine`: a statement assumed in one volume and proved in another; nothing above the box uses it; from here on these three and **no others** (no derivative, no series, no value of e); each proof that uses one names it. One sentence: the box is smaller than spec/08's placeholder "(E1)–(E4)" because uniqueness (`thm-exp-unique`) is proved, not borrowed.
- **Warning.** e^x is not yet notation (it becomes notation after `prp-real-power-consistent`); "exp is continuous", "exp′ = exp" are true but not in the box and not used.
- **`prp-exp-first-consequences`.** (a) exp 0 = 1; (b) exp x > 0 and exp(−x) = 1/exp x; (c) exp is strictly increasing on ℝ; (d) exp x ≤ 1/(1 − x) for x < 1; (e) exp(nx) = (exp x)ⁿ for n ∈ ℤ (negative powers as reciprocals); (f) exp(qx) = (exp x)^q for q ∈ ℚ, the rational power of ⟨F4.6⟩ `def-rational-power`. Proofs: (a) exp 0 = exp(0)², exp 0 ≥ 1 by (E2), so exp 0 = 1 (cancel, `@fd3:lem-field-fraction-rules`); (b) exp x · exp(−x) = 1 and exp x = exp(x/2)² ≥ 0; (c) by the factor-out method in multiplicative form: exp y = exp x · exp(y − x) ≥ exp x (1 + y − x) > exp x; (d) exp(−x) ≥ 1 − x > 0 and (b), `@fd3:prp-reciprocal-order`; (e) induction (`@fd1:ax-induction`) and (b); (f) for q = m/n (n ≥ 1): exp(qx)ⁿ = exp(mx) = (exp x)^m and exp(qx) > 0, so exp(qx) is the positive n-th root of (exp x)^m (⟨F4.6⟩ `thm-real-nth-root` uniqueness).
- **`exm-method-archimedes-squeeze`** `[Method: squeeze, then close the gap by Archimedes]`. Template: to prove sup S = L, show (i) every s ∈ S is ≤ L; (ii) for every n ≥ N₀ some s_n ∈ S has s_n ≥ L − C/n with C fixed in advance; then (iii) any L′ < L is exceeded, by `@fd3:prp-archimedean-reciprocal` with ε ≔ (L − L′)/C. When: identifying a supremum given a two-sided estimate. Usual failure: letting C depend on n.
- **`thm-exp-unique`** (key proof). For every x ∈ ℝ, exp x = sup{(1 + x/n)ⁿ : n ∈ ℤ_{>0}, n > |x|}. Consequently, if E: ℝ → ℝ also satisfies (E1) and (E2), then E = exp. Proof: fix x and n > |x|, so 1 + x/n > 0 and 1 − x/n > 0. By (E2) exp(x/n) ≥ 1 + x/n > 0, so by (E1), (e) and monotonicity of n-th powers on [0, ∞) (⟨F4.6⟩ `prp-power-monotone`), exp x = exp(x/n)ⁿ ≥ (1 + x/n)ⁿ. By (d), exp(x/n) ≤ 1/(1 − x/n), so exp x ≤ (1 − x/n)^{−n}. Then (1 + x/n)ⁿ = (1 − x²/n²)ⁿ (1 − x/n)^{−n} ≥ (1 − x²/n²)ⁿ exp x ≥ (1 − x²/n) exp x by `@fd2:thm-bernoulli` (−x²/n² ≥ −1 since n > |x|). So (1 + x/n)ⁿ ∈ [exp x − x² exp x/n, exp x], and the method (C = x² exp x) gives the sup. The second sentence: the set and its sup were built from (E1), (E2) only, so E(x) is the same sup. Self-explanation prompt: "why must n exceed |x|?" (both bases positive: needed to raise inequalities to the n-th power and to invert). Sidecar checks the two-sided bound for sample x, n.
- **`def-euler-number`.** e ≔ exp 1. By `thm-exp-unique` with x = 1 and (d): (1 + 1/n)ⁿ ≤ e ≤ (1 − 1/n)^{−n} for n ≥ 2 (B1 turns this into 2.5 < e < 3).
- **`def-logarithm`.** exp: ℝ → (0, ∞) is a bijection ((b), (c), (E3)); log ≔ its inverse (0, ∞) → ℝ, strictly increasing by `thm-monotone-inverse`; graph log is graph exp reflected in y = x (figure, with 1 + x and 1/(1 − x)).
- **`prp-log-rules`.** For x, y > 0, q ∈ ℚ: (a) log 1 = 0, log e = 1; (b) log(xy) = log x + log y, log(1/x) = −log x; (c) log(x^q) = q log x; (d) 1 − 1/x ≤ log x ≤ x − 1, with equality only at x = 1. Proofs: apply exp, which is injective, to both sides; (d) from (E2) at t = log x, then at log(1/x); strictness from exp t > 1 + t for t ≠ 0, by two cases: for t ≥ −2, 1 + t/2 ≥ 0, so exp t = exp(t/2)² ≥ (1 + t/2)² = 1 + t + t²/4 > 1 + t; for t < −2, exp t > 0 > 1 + t. Sidecar.
- **`def-real-power`.** For a > 0 and x ∈ ℝ: a^x ≔ exp(x log a). For x > 0, 0^x ≔ 0 (one sentence; 0^0 = 1 stays fd2's `def-power` with natural exponent). Negative bases get no real powers here (except the odd roots of `exm-odd-roots`, which are a different symbol).
- **`prp-real-power-consistent`.** For a > 0 and q ∈ ℚ, exp(q log a) equals F4.6's a^q; in particular for n ∈ ℕ it is fd2's aⁿ, and e^x = exp x for every x. Proof: `prp-exp-first-consequences` (f) with x = log a and exp(log a) = a.
- **`prp-real-power-laws`.** For a, b > 0, x, y ∈ ℝ: a^{x+y} = a^x a^y; (a^x)^y = a^{xy}; (ab)^x = a^x b^x; a^{−x} = 1/a^x; a^x > 0; for a > 1, x ↦ a^x is strictly increasing, for 0 < a < 1 strictly decreasing; for x > 0, a ↦ a^x is strictly increasing on (0, ∞), for x < 0 strictly decreasing; log(a^x) = x log a. Proofs one line each from (E1), `prp-log-rules`, `prp-monotone-algebra` (e) (composition of monotone maps) and the sign of log a.
- **`prp-exp-beats-powers`.** (a) For x > 0 and k ∈ ℕ: exp x > (x/(k + 1))^{k+1}; hence for every M > 0, exp x > M x^k for every x > M(k + 1)^{k+1}. (b) For x > 0 and m ∈ ℤ_{>0}: log x < m x^{1/m}; hence for every ε > 0, log x < εx for every x > 4/ε². ## 07-strange-functions.md — A Table of Strange Functions

Budget: 3,500 main-line words; fold ≤ 300. Terse level except the Idea for `prp-thomae-large-values`. Last section: R group.

- **Hook.** Every function so far had a formula one could draw. The next chapters define continuity, limits and integrals, and each definition will be tested against functions that resist drawing. We collect them now, prove what can be proved without limits, and record the questions that the later definitions will answer.
- **`lem-irrationals-dense`.** For real a < b there is an irrational x with a < x < b. Proof: a rational q with a − √2 < q < b − √2 (`@fd3:thm-rationals-dense-ordered-field`, F = ℝ); x ≔ q + √2 is irrational, since otherwise √2 = x − q would be rational (`@fd3:thm-no-rational-square-two`, transported to ℝ by ι_ℝ preserving products: one sentence citing `@fd3:thm-rationals-embed-ordered-field`).
- **`def-dirichlet-function`** D ≔ 𝟙_ℚ: ℝ → ℝ. **`prp-dirichlet-properties`.** (a) every rational q ≠ 0 is a period, and no irrational number is (D(T) = D(0) = 1 forces T ∈ ℚ); (b) on every interval (a, b) with a < b, sup D = 1 and inf D = 0, both attained (density, `lem-irrationals-dense`), so by `prp-sup-oscillation` the oscillation on every such interval is 1; (c) D is monotone on no such interval.
- **x·D(x)** (entry in the table, statement inline): |xD(x)| ≤ |x|; for a ≠ 0, every interval around a contains a point x with |xD(x) − aD(a)| ≥ |a|/2 (irrationals near a rational a; rationals with |x| ≥ |a|/2 near an irrational a). A question for AN1.5: at which points is it continuous?
- **`def-thomae-function`.** T(x) ≔ 1/q if x = p/q in lowest terms with q ≥ 1 (`@fd5:prp-rationals-lowest-terms`, moved with F3.5 → F5.1 (fd3 re-cut, 2026-10-26, fd3/authoring/design/layout-proposal.md)), T(x) ≔ 0 if x is irrational; T(0) = 1. **`prp-thomae-large-values`.** (a) T has period 1; (b) for every ε > 0 and every a < b, the set {x ∈ [a, b] : T(x) ≥ ε} is finite; (c) every interval (a, b) contains points with T > 0 and points with T = 0. Idea: T(x) ≥ ε forces x = p/q with q ≤ 1/ε; for each such q only the p with aq ≤ p ≤ bq, finitely many. Proof of (b): the set is contained in ⋃_{q=1}^{⌊1/ε⌋} {p/q : p ∈ ℤ, ⌈aq⌉ ≤ p ≤ ⌊bq⌋}, a finite union of finite sets (`@fd2:prp-subset-finite`). Quick check: T(3/4), T(−6/8), T(0.6), T(√2/2). (1/4, 1/4, 1/5, 0.)
- **`exm-strange-involution`.** J(x) ≔ x for x ∈ ℚ, −x for x ∉ ℚ. J ∘ J = id, so J is a bijection ℝ → ℝ (`@fd2:thm-bijection-iff-inverse`); J is monotone on no interval (two rationals p < q give J(p) < J(q); two irrationals r < s, by `lem-irrationals-dense`, give J(r) > J(s)); J is its own inverse but is not the identity — compare §02 C2, where "increasing" forces the identity.
- **`exm-strange-jump`** recalled from §02 (H; image not an interval).
- **`exm-strange-staircase`.** s(0) ≔ 0, s(x) ≔ 1/⌊1/x⌋ for 0 < x ≤ 1 (so s = 1/n on (1/(n + 1), 1/n]). **`prp-staircase-squeeze`.** s is increasing on [0, 1], takes infinitely many values, and 0 ≤ s(x) − x < 2x² for 0 < x ≤ 1. Proof: n ≔ ⌊1/x⌋ satisfies n ≤ 1/x < n + 1 (`prp-floor-rules`), so x ≤ 1/n and s(x) − x < 1/n − 1/(n + 1) = 1/(n(n + 1)) ≤ 2/(n + 1)² < 2x² (n + 1 ≤ 2n; x > 1/(n + 1)). Increasing: from `prp-floor-rules` (c) applied to 1/x, which is decreasing. Figure against y = x. Question for AN1.5/AN1.7: infinitely many jumps, yet hugging the diagonal at 0 — is it continuous at 0? differentiable there? (Prose; its derivative at 0 is 1, AN1.7.)
- **`exm-strange-zigzag`.** Z(0) ≔ 0, Z(x) ≔ dist(1/x, ℤ) for x ≠ 0. **`prp-zigzag-all-values`.** For every δ > 0 and every t ∈ [0, 1/2] there is x ∈ (0, δ) with Z(x) = t; and |x Z(x)| ≤ |x|/2 for all x. Proof: integer n > 1/δ (Archimedes), x ≔ 1/(n + t) ∈ (0, δ), Z(x) = dist(n + t, ℤ) = dist(t, ℤ) = t (`prp-distance-to-integer` (b), (c): t ∈ [0, 1/2] gives dist(t, ℤ) = min(t, 1 − t) = t). Remark: the same shape with sin in place of dist(·, ℤ) appears once sine is available (F4.10, AN1); §04 C2's inequality is what makes Z's cousin x·Z(x) small.
- **`exm-strange-unbounded`.** R(0) ≔ 0, R(x) ≔ 1/x on (0, 1]: defined on a closed bounded interval, unbounded above (Archimedes). **`exm-strange-sup-missed`.** M(x) ≔ x on [0, 1), M(1) ≔ 0: bounded on [0, 1], sup 1 not attained. Question for AN1.6: what hypothesis would prevent both?
