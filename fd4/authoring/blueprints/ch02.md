**Purpose.**
- fd3 already owns the axioms: F3.2's `@fd3:def-commutative-ring-and-field` defines "field", `@fd3:prp-ring-algebra` proves the ring rules, F3.5 proves ℤ/pℤ a field (`@fd3:thm-integers-mod-prime-field`). This chapter does **not** prove those again. It (i) restates the definition under the published label `def-field` (the label every linear-algebra chapter cites), collects the rules under the published `thm-field-basic-properties`, and checks the standard examples; (ii) names 𝔽_p and computes in it; (iii) adds the three notions that the linear-algebra and algebra volumes need and fd3 never defined for a general field: **subfield**, **field homomorphism**, **characteristic**; (iv) identifies the smallest subfield of every field (ℚ or 𝔽_p), and (v) closes with the binomial theorem in a commutative ring, the Frobenius map and Fermat's little theorem.
- The reader leaves able to (i) decide whether a given set with two operations is a field, naming the failing axiom; (ii) compute inverses and solve linear equations in 𝔽_p; (iii) run the subfield test; (iv) prove that a map is (or cannot be) a field homomorphism by applying it to a defining equation; (v) find the characteristic of a field and say what "characteristic ≠ 2" buys.

**Signature moves** (`index.md`, "Named moves").
- **Test inside the big field.** For K ⊆ L, the identities (F1), (F2), (F5), (F6), (F9) hold in K because they hold for all elements of L; only closure and the elements 0, 1, −a, a⁻¹ need checking. (Used in `prp-subfield-test`, `exm-q-sqrt2-field`, `prp-subfield-intersection`.)

## index.md

- **Story.** Linear algebra solves equations by adding, subtracting, multiplying and dividing by non-zero numbers, nothing else; a field is a number system where exactly that works. fd3 already defined fields and built ℚ, ℝ, ℤ/pℤ. This chapter looks at fields as a kind of object: the rules every field obeys, the finite fields 𝔽_p and how to compute in them, fields inside fields, maps between fields that respect both operations, and one number, the characteristic, that says whether 1 + 1 + ⋯ + 1 can ever be 0. Two facts organize everything: a homomorphism of fields is forced to be injective, and every field contains exactly one copy of ℚ or of exactly one 𝔽_p. The chapter ends with the identity (x + y)^p = x^p + y^p, true in every field of characteristic p, and with Fermat's little theorem as its shadow in 𝔽_p.
- **What you need:** F3.2 (commutative rings and fields, `@fd3:prp-ring-algebra`, multiples n·a, ℚ); F3.5 (gcd, Euclid's lemma, ℤ/nℤ, units, ℤ/pℤ a field); F4.1 (ℂ, conjugation), for examples; F3.10 and F3.4 (ℝ, √2), for examples.
- **Time:** core ≈ 14 hours; full ≈ 22 (drafter re-estimates per STYLE §11.9).
- **One definition, two books (paragraph).** "Field" was defined in F3.2 (`@fd3:def-commutative-ring-and-field`), and the linear-algebra volumes cite it as `def-field`. ## 01-field-axioms.md — The Field Axioms and the First Examples

- **Hook** (reuse LA §0.7's opening, rewritten): the system 2x + 3y = 7, x − y = 1 solved at school; list the moves used (add, subtract, multiply an equation, divide by a non-zero number, rearrange, expand). In ℤ, 2x = 1 has no solution (F3.5: `@fd3:cor-integers-even-odd` (a): 2x is even and 1 is odd). Slogan: *a field is a number system where you can add, subtract, multiply, and divide by anything non-zero, with the usual rules.*
- **`def-field`** (kept label; statement as LA's). A field is a set F with two functions + : F × F → F and · : F × F → F satisfying (F1)–(F9): (F1)–(F6), (F9) as in `@fd3:def-commutative-ring-and-field`; (F7) there is 1 ∈ F **with 1 ≠ 0** and a·1 = a for every a; (F8) every non-zero a has a⁻¹ with aa⁻¹ = 1. Write a − b ≔ a + (−b), a/b ≔ ab⁻¹ (b ≠ 0).
  - Remark (the fd3 twin, one paragraph): F is a field in this sense iff it is a field in the sense of `@fd3:def-commutative-ring-and-field` (a commutative ring, (F1)–(F7) and (F9), in which in addition 1 ≠ 0 and (F8) hold): the clauses are the same, and only the place of "1 ≠ 0" differs (inside (F7) here, as in the linear-algebra volumes; a separate clause there, so that the zero ring is a ring). Every fd3 result about fields therefore applies, and conversely. Quantifier order in (F3) vs (F4) (LA's paragraph, kept).
  - Reading in groups (LA's bullet list, kept): (F1)–(F4) addition; (F5)–(F8) multiplication, inverses only for non-zero elements; (F9) the link.
- **`thm-field-basic-properties`** (kept label; (a)–(f) verbatim from LA, (g) new). Let F be a field and a, b, c, d ∈ F. (a) 0 and 1 are unique. (b) (Cancellation) a + b = a + c ⇒ b = c; ab = ac and a ≠ 0 ⇒ b = c. (c) −a is unique; for a ≠ 0, a⁻¹ is unique. (d) 0·a = 0. (e) (−1)a = −a. (f) ab = 0 ⇒ a = 0 or b = 0. (g) For b, d ≠ 0: bd ≠ 0, (bd)⁻¹ = b⁻¹d⁻¹, (b⁻¹)⁻¹ = b, a/b + c/d = (ad + bc)/(bd), (a/b)(c/d) = (ac)/(bd).
  - Proof (by citation where fd3 already has the fact; the text says so in one sentence before the proof: "most of this was proved in fd3 for every commutative ring; we collect it"). (a) `@fd3:prp-ring-algebra` (a). (b) additive: add −a on the left, (F2), (F4), (F1), (F3) (three lines, LA's); multiplicative: multiply by a⁻¹ (F8), (F5), (F6), (F7). (c) negatives: `@fd3:prp-ring-algebra` (a); inverses: in a field every non-zero element is a unit (that is (F8)), and a unit's inverse is unique (`@fd3:def-ring-unit`). (d) `@fd3:prp-ring-algebra` (b) with (F6). (e) `@fd3:prp-ring-algebra` (c) with a = 1 and (F7): (−1)b = −(1·b) = −b. (f) if a ≠ 0, b = a⁻¹(ab) = a⁻¹·0 = 0, by (F7), (F8), (F5), (F6), (d) (LA's display). (g) bd ≠ 0 is (f) contraposed; (bd)(b⁻¹d⁻¹) = (bb⁻¹)(dd⁻¹) = 1 by (F5), (F6), so (c); b⁻¹b = 1 gives (b⁻¹)⁻¹ = b by (c); for the sum, (ab⁻¹ + cd⁻¹)(bd) = ad + cb by (F9), (F5), (F6), (F8), (F7), then multiply by (bd)⁻¹; the product by (F5), (F6) and the inverse of bd.
  - *Idea* (LA's, kept): each part is a short chain of axioms found backwards from the goal; uniqueness by "suppose two, show equal"; for (d) write 0 = 0 + 0 and cancel; for (f) spend the hypothesis a ≠ 0 on (F8).
  - Remark: (g) is F3.9's `@fd3:lem-field-fraction-rules` (a), (b) (proved there for every field; compared with, not cited, since F3.9 is not on this chapter's prerequisite path). Two small consequences used without comment: 0 + a = a, 1·a = a. Every identity of school algebra proved from (F1)–(F9) (such as (a + b)² = a² + 2ab + b², `@fd3:prp-ring-algebra` (d); (−a)(−b) = ab, (c)) holds in every field.
- **`cor-field-squares-equal`.** Let F be a field and x, y ∈ F. Then x² = y² iff x = y or x = −y. In particular x² = 1 iff x = 1 or x = −1. Proof: (x − y)(x + y) = x² − y² by (F9), (F6) and `@fd3:prp-ring-algebra` (c); then (f) of the theorem; conversely (−y)² = y² by `@fd3:prp-ring-algebra` (c). Remark: y and −y may coincide even for y ≠ 0 (in 𝔽_2, §02; and in every field with 1 + 1 = 0, §05); and the corollary fails in rings with zero divisors: in ℤ/8ℤ, [3]² = [1] (F3.5 compared). F4.5 (roots) builds on this; F4.1 (square roots in ℂ), which comes earlier, proved the case of ℂ directly (`@prp-complex-square-roots` (b), compared with); R1 uses the corollary in ℂ.
- **`prp-field-linear-equation`.** Let F be a field and a, b, c, d, e, f ∈ F. (a) If a ≠ 0, the equation ax = b has exactly one solution x ∈ F, namely x = a⁻¹b. ## 03-subfields.md — Subfields

- **Hook.** ℚ ⊆ ℝ ⊆ ℂ, each a field with the operations of the next. Is {a + b√2 : a, b ∈ ℚ} ⊆ ℝ a field? It is closed under + and ·, but is 1/(1 + 2√2) of that form? A short test settles such questions once.
- **`def-subfield`.** Let L be a field. A **subfield** of L is a subset K ⊆ L with 0, 1 ∈ K that is closed under +, ·, negatives, and inverses of non-zero elements. (Same words as the first paragraph of linear algebra's def-restriction-of-scalars; LA1.1 should cite this, open question 6.)
- **`prp-subfield-test`.** Let L be a field and K ⊆ L.
  - (a) If K is a subfield of L, then K with the restrictions of + and · is a field, whose 0, 1, negatives and inverses are those of L.
  - (b) Conversely, if K is closed under + and · and is a field with the restricted operations, then K is a subfield of L: its zero is 0_L, its one is 1_L, and its negatives and inverses are those of L.
  - (c) K is a subfield of L iff 1 ∈ K, a − b ∈ K for all a, b ∈ K, and ab⁻¹ ∈ K for all a, b ∈ K with b ≠ 0.
  - Proof. (a) The move **test inside the big field**: (F1), (F2), (F5), (F6), (F9) are identities "for all" elements of L, so in particular of K; (F3), (F4), (F7), (F8) are witnessed by 0, −a, 1, a⁻¹, which lie in K; 1 ≠ 0 in L. (b) 0_K + 0_K = 0_K = 0_K + 0_L in L, so 0_K = 0_L by cancellation in L (`thm-field-basic-properties` (b)); 1_K·1_K = 1_K = 1_K·1_L in L with 1_K ≠ 0_K = 0_L, so 1_K = 1_L by multiplicative cancellation; the negative of a in K satisfies a + x = 0_L, so it is −a by uniqueness in L ((c)); likewise inverses. (c) ⇒: 1 ∈ K, a − b = a + (−b), ab⁻¹. ⇐: 0 = 1 − 1; −b = 0 − b; b⁻¹ = 1·b⁻¹ for b ≠ 0; a + b = a − (−b) (`@fd3:prp-ring-algebra` (a): −(−b) = b); ab = a(b⁻¹)⁻¹ for b ≠ 0 (`thm-field-basic-properties` (g)), and ab = 0 ∈ K for b = 0 ((d)).
  - Self-explanation: "in (b), where is it used that L is a field, and not just a commutative ring?" (cancellation of 1_K, which needs 1_K ≠ 0 and inverses in L; the warning shows it fails in a ring).
- **Warning (false conclusion: a subset can be a field with a different 1).** In the ring ℤ/6ℤ, the subset {[0], [3]} is closed under + and ·, and is a field with the restricted operations ([3] + [3] = [0], [3][3] = [9] = [3]; a copy of 𝔽_2), but its one is [3], not [1]. So (b) needs L to be a field: in ℤ/6ℤ, [3]·[3] = [3]·[1] does not allow cancelling [3]. And a field structure on a subset with **other** operations does not make it a subfield: {0, 1} with the operations of 𝔽_2 is a field, but {0, 1} is not a subfield of ℚ (1 + 1 = 2).
- **`exm-q-sqrt2-field`** (kept label; LA statement). ℚ(√2) ≔ {a + b√2 : a, b ∈ ℚ} ⊆ ℝ is a field (a subfield of ℝ); find the inverse of 1 + 2√2. ## 04-field-homomorphisms.md — Field Homomorphisms

- **Hook.** Complex conjugation z ↦ z̄ turns sums into sums and products into products (F4.1, `@thm-conjugate-properties`); so does a + b√2 ↦ a − b√2 on ℚ(√2) (F3.4, `@fd3:exm-cof-sqrt2-conjugation`). A map that respects both operations carries every equation of F to an equation of L. This section studies such maps.
- **`def-field-homomorphism`.** Let F, L be fields. A (field) **homomorphism** φ : F → L is a function with φ(a + b) = φ(a) + φ(b), φ(ab) = φ(a)φ(b) for all a, b ∈ F, and φ(1) = 1. A bijective homomorphism is an **isomorphism**; F and L are **isomorphic**, F ≅ L, if one exists; an isomorphism F → F is an **automorphism**. Remark: F3.4's order-preserving field maps (`@fd3:def-cof-order-preserving-map`) are the homomorphisms of ordered fields that also preserve <. One sentence on notation: from here on F ≅ L means isomorphic as fields; F3.4's ≅ (an order-preserving isomorphism) is said in words, "isomorphic as ordered fields" (ℚ(√2) has the non-identity field automorphism a + b√2 ↦ a − b√2, which is not order-preserving).
- **`prp-field-homomorphism-properties`** (key proof: (c)). Let φ : F → L be a homomorphism and a, b ∈ F.
  - (a) φ(0) = 0, φ(−a) = −φ(a), φ(a − b) = φ(a) − φ(b).
  - (b) If a ≠ 0, then φ(a) ≠ 0 and φ(a⁻¹) = φ(a)⁻¹.
  - (c) φ is injective.
  - (d) φ(F) is a subfield of L, and φ, with codomain φ(F), is an isomorphism F → φ(F).
  - (e) The composite of homomorphisms is a homomorphism; the inverse of an isomorphism is an isomorphism; id_F is an automorphism.
  - (f) φ(n·a) = n·φ(a) for n ∈ ℕ, and φ(a^n) = φ(a)^n for n ∈ ℕ (powers by the ledger line).
  - Proof. (a) The move **push the equation through φ**: φ(0) = φ(0 + 0) = φ(0) + φ(0), cancel in L (`thm-field-basic-properties` (b)); φ(a) + φ(−a) = φ(a + (−a)) = φ(0) = 0, uniqueness of negatives in L ((c)); a − b = a + (−b). (b) φ(a)φ(a⁻¹) = φ(aa⁻¹) = φ(1) = 1; if φ(a) = 0 this reads 0 = 1 in L ((d) and (F7)); so φ(a) ≠ 0 and φ(a⁻¹) = φ(a)⁻¹ by uniqueness of inverses. (c) If φ(a) = φ(b), then φ(a − b) = 0 by (a), so a − b = 0 by (b) (contrapositive). (d) `prp-subfield-test` (c): 1 = φ(1) ∈ φ(F); φ(a) − φ(b) = φ(a − b); φ(a)φ(b)⁻¹ = φ(ab⁻¹) for φ(b) ≠ 0 (then b ≠ 0, by (a)). Surjective onto its image by `@fd2:def-image`; injective by (c). (e) Composition: direct. Inverse ψ of an isomorphism: φ(ψ(x) + ψ(y)) = x + y = φ(ψ(x + y)), so ψ(x) + ψ(y) = ψ(x + y) by injectivity; same for ·; ψ(1) = 1 since φ(1) = 1 (`@fd2:def-inverse-function`). (f) `@fd1:ax-induction` on n: φ(0·a) = φ(0) = 0 = 0·φ(a); φ((n + 1)·a) = φ(n·a + a) = n·φ(a) + φ(a). Powers likewise.
  - *Idea* (for (c)): a homomorphism cannot send a non-zero element to 0, because a non-zero element has an inverse, and φ(a)φ(a⁻¹) = 1 ≠ 0. Injectivity is that fact applied to a − b.
  - Answer to the prompt: φ(1) = 1 is used in (b); the zero map F → L satisfies the first two clauses and is not injective.
- **`exm-complex-conjugation-automorphism`.** (i) z ↦ z̄ is an automorphism of ℂ, not the identity (ī = −i ≠ i), and z̄ = z iff z ∈ ℝ (F4.1's `@thm-conjugate-properties` (a), (b) for the homomorphism property; "z̄ = z iff z ∈ ℝ" is **not** among its parts (a)–(e), so the example proves it in one line from `@def-conjugate-modulus`: a − bi = a + bi iff b = 0, with `@prp-reals-embed-complex`; bijective since it is its own inverse by (a)). (ii) The inclusion of a subfield K → L is a homomorphism (not surjective when K ≠ L). (iii) a + b√2 ↦ a − b√2 is an automorphism of ℚ(√2) (F3.4's `@fd3:exm-cof-sqrt2-conjugation`; recalled, not re-proved). (iv) Contrast (prose): ℝ has no automorphism other than the identity (F3.4, `@fd3:thm-cof-field-automorphism-identity`), and §05 shows the same for ℚ and 𝔽_p.
- **`exm-field-homomorphism-obstructions`.** (i) There is no homomorphism ℂ → ℝ: φ(i)² = φ(i²) = φ(−1) = −1 by (a) and (f), but a square in the ordered field ℝ is ≥ 0 (`@fd3:thm-reals-ordered-field`, `@fd3:prp-ordered-ring-rules` (e)), and −1 < 0. (ii) There is no homomorphism 𝔽_2 → ℚ: φ(1) + φ(1) = φ(1 + 1) = φ(0) = 0, but 1 + 1 = 2 ≠ 0 in ℚ. (iii) There is no homomorphism ℚ → 𝔽_p: φ(p·1) = p·φ(1) = p·1 = 0 in 𝔽_p by (f), but p·1 = p ≠ 0 in ℚ, against (c). (iv) The zero map is additive and multiplicative but not a homomorphism. §05 explains (ii) and (iii) at once (`prp-characteristic-invariant`).
- **Warning.** A bijection that respects + alone is not an isomorphism: x ↦ 2x on ℚ is additive and bijective, but 2(1·1) = 2 ≠ 4 = (2·1)(2·1). Both clauses, and φ(1) = 1, must be checked.

## 05-characteristic-and-prime-subfield.md — Integer Multiples, the Characteristic, and the Prime Subfield

- **Hook** (LA's, kept): in ℚ adding 1 to itself never gives 0; in 𝔽_2 two copies do, in 𝔽_p p copies. This number decides whether "2x = 0 ⇒ x = 0" is valid, and it is preserved by homomorphisms.
- **Integer multiples.** n·a for n ∈ ℕ in a commutative ring is F3.2's (§03, "Multiples": 0·a ≔ 0, (n + 1)·a ≔ n·a + a). For n ∈ ℤ with n < 0, define n·a ≔ −((−n)·a) (every integer is m or −m with m ∈ ℕ, `@fd3:prp-naturals-embed-integers` (c)). For R = ℤ, n·a = na (F3.2's remark for n ∈ ℕ; for n < 0 by `@fd3:prp-ring-algebra` (c)).
- **`lem-integer-multiples`** (kept label; (a)–(c) LA's, the hypothesis widened from "field" to "commutative ring", which contains LA's case). Let R be a commutative ring, a ∈ R, m, k ∈ ℕ. (a) (m·1) + (k·1) = (m + k)·1; (b) (m·1)(k·1) = (mk)·1; (c) (m·1)a = m·a. (d) The same three identities hold for all m, k ∈ ℤ, together with (m + k)·a = m·a + k·a, (−m)·a = −(m·a), m·(a + b) = m·a + m·b, (m·a)b = m·(ab) and (mk)·a = m·(k·a).
  - Proof: (a)–(c) LA's inductions (`@fd1:ax-induction` through `@fd3:cor-omega-identification`), the sum law also being F3.2's `@fd3:prp-ordered-ring-rules` (h) whose proof uses no order. (d) First (−m)·a = −(m·a) for all m ∈ ℤ (definition, and −(−x) = x, `@fd3:prp-ring-algebra` (a)); then (m − k)·a = m·a − k·a for m, k ∈ ℕ (case m ≥ k from (a) applied to (m − k) + k; case m < k by negating the first case); every integer is a difference of two natural numbers, which reduces each identity to (a)–(c) and `@fd3:prp-ring-algebra` (c). The drafter writes the sign cases as a two-column table, not prose.
  - Remark: in ℤ/nℤ, k·[1] = [k] (`@fd3:thm-integers-mod-n-ring` (d)); with (d), also for k < 0. So χ : ℤ → R, n ↦ n·1, respects +, · and sends 1 to 1.
- **`def-characteristic`** (kept label; LA's statement). If some positive integer n has n·1 = 0, the characteristic char F is the least such n; otherwise char F ≔ 0. (Existence of the least: `@fd3:prp-integer-least-element`, named in the text.) Stated for a field F; the same words define it for a commutative ring (one sentence; ℤ/6ℤ "has characteristic 6").
- **`prp-characteristic-divides`.** Let F be a field with c ≔ char F, and n ∈ ℤ. Then n·1 = 0 iff c | n. (For c = 0: iff n = 0, since 0 | n iff n = 0, `@fd3:prp-divisibility-rules-integers` (a).) Consequently, for n ∈ ℤ, n·1 is invertible in F iff c ∤ n; in particular 2 ≔ 1 + 1 is invertible iff char F ≠ 2.
  - Proof (the move **count copies of 1**, with F3.5's **least positive element, then divide**): c = 0: for n > 0, n·1 ≠ 0 by definition; for n < 0, n·1 = −((−n)·1) ≠ 0. c > 0: n = qc + r with 0 ≤ r < c (`@fd3:thm-integers-division-remainder`); n·1 = (q·1)(c·1) + r·1 = r·1 by `lem-integer-multiples` (d) and (F3), `thm-field-basic-properties` (d); so n·1 = 0 iff r·1 = 0 iff r = 0 (minimality of c, r < c). Invertibility: in a field, non-zero iff invertible ((F8); `thm-field-basic-properties` (d) for 0).
  - Remark: this is the form LA1.4, LA2.7, LA2.8, LA4.14, LA4.15 ("char F ≠ 2, so 2 is invertible") and AL4.8 ("|G|·1 is invertible when char F ∤ |G|") use.
- **`thm-characteristic-prime`** (kept label). char F is 0 or a prime. Proof (LA's, kept): 1·1 = 1 ≠ 0, so c ≠ 1; if c = rs with 1 < r, s < c, then (r·1)(s·1) = (rs)·1 = 0 (`lem-integer-multiples` (b)), so r·1 = 0 or s·1 = 0 (`thm-field-basic-properties` (f)), against minimality. *Idea*: the argument of `thm-zp-field-iff-prime` "⇒", run inside F.
- **`prp-characteristic-invariant`.** (a) If K is a subfield of L, then char K = char L. (b) If φ : F → L is a homomorphism, then char F = char L. (c) So there is no homomorphism between fields of different characteristic. Proof: (a) 1_K = 1_L and + agrees (`prp-subfield-test` (a)), so n·1_K = n·1_L (induction). (b) φ(n·1) = n·1 (`prp-field-homomorphism-properties` (f)), and φ(x) = 0 iff x = 0 ((a), (c) there).
- **`exm-characteristics`.** ℚ: char 0, since n·1 > 0 for n ≥ 1 in an ordered ring with 1 ≠ 0 (`@fd3:prp-ordered-ring-rules` (h), `@fd3:thm-rationals-ordered-field`). ℝ: char 0 likewise (`@fd3:thm-reals-ordered-field`), or as ℚ ⊆ ℝ by (a). ℂ: char 0, as ℝ ⊆ ℂ by (a). Every ordered field has characteristic 0 (same reason). 𝔽_p: char p, since n·[1] = [n] = [0] iff p | n (`@fd3:thm-integers-mod-n-ring` (d)) and the least positive multiple of p is p. ℚ(√2), ℚ(i): 0 by (a). The four-element field of §02 C1: 2 (1 + 1 = 0; an exercise's field, named only, nothing rests on it). ℤ/6ℤ: 6 as a ring, not a field (no contradiction with the theorem).
- **`thm-prime-subfield`** (key proof; Try it first; Before reading on: "where is char F = 0 used, and why does the same formula fail for F = 𝔽_5?"). Let F be a field and P its prime subfield (`def-prime-subfield`).
  - (a) If char F = p > 0, then ι_F([n]) ≔ n·1 is a well-defined homomorphism 𝔽_p → F, it is the **only** homomorphism 𝔽_p → F, and its image is P. So P ≅ 𝔽_p.
  - (b) If char F = 0, then ι_F(m/n) ≔ (m·1)(n·1)⁻¹ (m, n ∈ ℤ, n > 0) is a well-defined homomorphism ℚ → F, it is the **only** homomorphism ℚ → F, and its image is P. So P ≅ ℚ.
  - Proof. (a) Well defined: [n] = [n′] means p | n − n′, so (n − n′)·1 = 0 (`prp-characteristic-divides`), so n·1 = n′·1 (`lem-integer-multiples` (d)); this is `@fd3:thm-well-defined-on-classes` (a) for the quotient map of `@fd3:def-integers-mod-n-ring`. Homomorphism: `lem-integer-multiples` (d) and the definition of + and · on ℤ/pℤ. Image ⊇ P: the image is a subfield (`prp-field-homomorphism-properties` (d)). Image ⊆ P: every subfield K contains 1 and is closed under + and negatives, so contains every n·1 (induction, then negatives). Uniqueness: a homomorphism ψ has ψ([n]) = ψ(n·[1]) = n·ψ([1]) = n·1 (`@fd3:thm-integers-mod-n-ring` (d) with `lem-integer-multiples` (d); `prp-field-homomorphism-properties` (f) extended to n ∈ ℤ by (a) there). (b) ℚ = (ℤ × ℤ_{>0})/~ is F3.2's set of classes [(m, n)] with n > 0 (`@fd3:def-rationals-as-classes`), and [(m, n)] = m/n (`@fd3:prp-integers-embed-rationals` (a)); the operations of `@fd3:def-rational-operations` are stated for such pairs. Image = P: as in (a), a subfield contains m·1, n·1, hence (m·1)(n·1)⁻¹.   - Answer to the prompt: char 0 is used for n·1 ≠ 0 (the inverse exists) and nowhere else; in 𝔽_5, 5·1 = 0, so "1/5 ↦ (1·1)(5·1)⁻¹" has no meaning, matching `exm-field-homomorphism-obstructions` (iii).
  - *Idea* (from the Try it first): a homomorphism has no freedom on 1, hence none on 1 + ⋯ + 1, on negatives, or on quotients; the only question is whether n·1 can be 0, and the characteristic answers it.
  - Remark: for an ordered field F, (b) is F3.9's `@fd3:thm-rationals-embed-ordered-field`, where order gave n·1 > 0 (`@fd3:prp-naturals-in-ordered-field`); the notation ι_F is kept. The same idea gives F3.4's `@fd3:prp-cof-map-fixes-rationals`.
- **`cor-homomorphisms-fix-prime-subfield`.** (a) Every homomorphism φ : F → L maps the prime subfield of F onto that of L, with φ ∘ ι_F = ι_L. (b) The only automorphism of ℚ, and the only automorphism of 𝔽_p, is the identity. (c) Every automorphism of a field F fixes each element of its prime subfield. Proof: φ ∘ ι_F is a homomorphism from ℚ or 𝔽_p (same characteristic by `prp-characteristic-invariant`), so equals ι_L by uniqueness; (b) id is a homomorphism ℚ → ℚ, so the unique one (`thm-prime-subfield` with F = ℚ: ι_ℚ = id); (c) is (a) with L = F.

(c) p·a = 0 for every a ∈ F. ## 06-frobenius-and-fermat.md — The Binomial Theorem, the Frobenius Map, and Fermat's Little Theorem

- **Hook.** In 𝔽_5: (1 + 2)^5 = 3^5 = 243 = 3 and 1^5 + 2^5 = 33 = 3. "(x + y)^p = x^p + y^p", the classic algebra error, is a theorem in characteristic p. To prove it we need the binomial theorem in a general commutative ring, which school proves only for numbers.
- **Ledger line (template, as F3.5 and F3.4 do).** Finite sums Σ_{k=m}^{n} a_k, products and powers a^n (n ∈ ℕ) in a commutative ring R: the recursions of `@fd2:def-sum-product` and `@fd2:def-power` with X = R (`@fd2:thm-recursion` read on ω), their "finite lists", "shifting the index" and "splitting off the last term" remarks, and `@fd2:prp-power-laws` (a)–(c), whose proofs use only (F1)–(F7), (F9) and induction, run unchanged in R. (Written once in §06's opening paragraph and in the ledger; §04 (f) and §05 use powers under the same line.) The power laws are also F4.1's `@prp-power-laws-commutative-ring` (same statements; cited there in a remark only, since F4.1 is a `see` edge of this chapter).
- **`lem-ring-finite-sums`.** Let R be a commutative ring, n ∈ ℕ, c ∈ R, and a_k, b_k ∈ R for 0 ≤ k ≤ n. (a) Σ_{k=0}^{n} (a_k + b_k) = Σ a_k + Σ b_k; (b) c·Σ_{k=0}^{n} a_k = Σ_{k=0}^{n} c a_k; (c) Σ_{k=0}^{n} m·a_k = m·Σ a_k for m ∈ ℤ; (d) if a_k = 0 for every k ≠ j, then Σ_{k=0}^{n} a_k is a_j when j ≤ n and 0 when j > n; (e) −Σ a_k = Σ (−a_k). Proof: induction on n (`@fd1:ax-induction`), splitting off the last term, with (F1), (F2), (F9), for (c) `lem-integer-multiples` (c), (d) with (b), and for (e) `@fd3:prp-ring-algebra` (a). Items (a), (b), (d), (e) are F4.4's (Σ1)–(Σ4), stated here so that F4.4 can cite them (open question 3).
- **`def-binomial-coefficients`.** The function ℕ × ℕ → ℕ, (n, k) ↦ \binom{n}{k}, defined by recursion on n (`@fd2:thm-recursion` with X the set of functions ℕ → ℕ): \binom{0}{0} ≔ 1, \binom{0}{k} ≔ 0 for k ≥ 1; \binom{n+1}{0} ≔ 1, \binom{n+1}{k+1} ≔ \binom{n}{k} + \binom{n}{k+1} (Pascal). Facts with one-line inductions: \binom{n}{k} = 0 for k > n; \binom{n}{n} = 1; \binom{n}{1} = n. Table rows n = 0, …, 6 (sidecar). Remark: \binom{n}{k}·k!·(n − k)! = n! is true but neither proved nor used (the route below avoids division).
- **`prp-binomial-absorption`.** For all n, k ∈ ℕ: (k + 1)\binom{n+1}{k+1} = (n + 1)\binom{n}{k}. Proof: induction on n for the statement "for all k" (`@fd1:ax-induction`). Base n = 0: k = 0 gives 1 = 1; k ≥ 1 gives 0 = 0. Step: k = 0 is \binom{n+2}{1} = n + 2; for k = j + 1: (j + 2)\binom{n+2}{j+2} = (j + 2)\binom{n+1}{j+1} + (j + 2)\binom{n+1}{j+2} = [(j + 1)\binom{n+1}{j+1} + \binom{n+1}{j+1}] + (j + 2)\binom{n+1}{j+2} = (n + 1)\binom{n}{j} + \binom{n+1}{j+1} + (n + 1)\binom{n}{j+1} (hypothesis twice) = (n + 1)\binom{n+1}{j+1} + \binom{n+1}{j+1} = (n + 2)\binom{n+1}{j+1}. Sidecar checks the identity for n, k < 30.
- **`thm-binomial-commutative-ring`.** Let R be a commutative ring, x, y ∈ R, n ∈ ℕ. Then (x + y)^n = Σ_{k=0}^{n} \binom{n}{k}·(x^k y^{n−k}). Proof: induction on n; (x + y)^{n+1} = (x + y)^n x + (x + y)^n y; distribute (`lem-ring-finite-sums` (b)) and pull the integer multiples through products (y(m·a) = m·(ya), from `lem-integer-multiples` (c) and (F5), (F6)); shift the index of the first sum; combine term by term with `lem-ring-finite-sums` (a), `lem-integer-multiples` (d) (sum law) and Pascal; the end terms k = 0 and k = n + 1 separately. Sidecar checks n ≤ 8 in ℤ/7ℤ and ℤ/12ℤ on all pairs. Remark: LA uses this in 𝔽_p[x] (LA2.6) and for commuting matrices; it needs commutativity (prose pointer: LA1.0's matrices).
- **`lem-prime-divides-binomial`.** Let p be prime and 0 < k < p. Then p | \binom{p}{k}. Proof: `prp-binomial-absorption` with n = p − 1 and k − 1: k\binom{p}{k} = p\binom{p−1}{k−1}, so p | k\binom{p}{k}; p ∤ k since 0 < k < p (`@fd3:prp-divisibility-rules-integers` (e)), so gcd(p, k) = 1 (`@fd3:cor-prime-divides-product` (a)); Euclid's lemma `@fd3:thm-euclid-lemma-integers`. (The binomial coefficients are read in ℕ ⊆ ℤ.) Warning-adjacent remark: false for composite n: \binom{4}{2} = 6, and 4 ∤ 6.
- **`thm-frobenius-homomorphism`** (key proof; Try it first; Before reading on: "where is p prime used?"). Let F be a field of characteristic p > 0. (a) (x + y)^p = x^p + y^p and (xy)^p = x^p y^p for all x, y ∈ F, and 1^p = 1; so Fr : F → F, x ↦ x^p, is a homomorphism, hence injective. (b) (x − y)^p = x^p − y^p. (c) If F is finite, Fr is an automorphism of F.
  - Proof. (a) The binomial theorem; for 0 < k < p, \binom{p}{k}·z = (\binom{p}{k}·1)z = 0, since p | \binom{p}{k} (`lem-prime-divides-binomial`) gives \binom{p}{k}·1 = 0 (`prp-characteristic-divides`); the end terms are x^p and y^p. (xy)^p = x^p y^p is `@fd2:prp-power-laws` (c) under the ledger line. Injective: `prp-field-homomorphism-properties` (c). (b) (a) applied to x − y and y. (c) An injective map from a finite set to itself is surjective (`@fd2:thm-finite-no-proper-copy`, as F3.5's §05 C2 repair uses it).
  - Answer to the prompt: only in `lem-prime-divides-binomial` (Euclid's lemma needs p prime); `thm-characteristic-prime` guarantees that char F, when positive, is prime, so the hypothesis "char F = p > 0" already makes p prime.
  - *Idea*: expand; every middle coefficient is a multiple of p; p·1 = 0 kills it.
- **`thm-fermat-little`.** Let p be prime. (a) a^p = a for every a ∈ 𝔽_p. (b) a^{p−1} = 1 for every non-zero a ∈ 𝔽_p; so a⁻¹ = a^{p−2}. (c) For every a ∈ ℤ, p | a^p − a; and p | a^{p−1} − 1 if p ∤ a.
  - Proof. (a) Fr : 𝔽_p → 𝔽_p is a homomorphism (`thm-frobenius-homomorphism` (a), char 𝔽_p = p by `exm-characteristics`), hence equal to id, the only homomorphism 𝔽_p → 𝔽_p (uniqueness in `thm-prime-subfield` (a) with F = 𝔽_p; `cor-homomorphisms-fix-prime-subfield` (b)). (b) a·a^{p−1} = a = a·1, cancel a ≠ 0 (`thm-field-basic-properties` (b)); a·a^{p−2} = 1. (c) [ab] = [a][b] (`@fd3:thm-quotient-ring-by-ideal` (c)), hence [a^p] = [a]^p by induction, and [a]^p = [a] by (a); likewise (b). (No letter for the quotient map: in fd4, π is only the number, NOTATION.)
  - Remark: a second proof of (a), by induction on r ∈ {0, …, p − 1} with ((r + 1)·1)^p = (r·1)^p + 1 (`thm-frobenius-homomorphism` (a)), is §06 C2; AL1.4 proves (b) again from Lagrange's theorem (prose pointer).
- **`exm-frobenius-computations`.** (i) 3^{100} in 𝔽_7: 3^6 = 1, 100 = 16·6 + 4, so 3^{100} = 3^4 = 81 = 4. (ii) 2^{100} = 1 in 𝔽_101 (101 prime). (iii) The inverse of 7 in 𝔽_31 two ways: Fermat, 7^{29}; Euclid (F3.5): 31 = 4·7 + 3, 7 = 2·3 + 1, 1 = 7 − 2·3 = 7 − 2(31 − 4·7) = 9·7 − 2·31; both give 9 (7·9 = 63 = 2·31 + 1). (iv) Fr on 𝔽_p is the identity (`thm-fermat-little` (a)). What Fr does on the four-element field of §02 C1 is §05 C3. Sidecar for (i)–(iii).
- **Warning (false conclusion: the exponent must be a prime characteristic).** (x + y)² = x² + y² fails in 𝔽_3 (x = y = 1: 4 = 1 vs 2), where the exponent is not the characteristic. Even with n = char, n must be prime: (x + y)^4 = x^4 + y^4 fails in the ring ℤ/4ℤ, of characteristic 4 (1 + 1: 16 = 0 vs 2), where the middle coefficient \binom{4}{2} = 6 is not a multiple of 4.
