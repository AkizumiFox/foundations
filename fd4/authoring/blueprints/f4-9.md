**Purpose.**
- Give the analysis volumes the geometry of ℝⁿ they cite without proof today: lines and segments with their parametrizations, hyperplanes and half-spaces, nearest points, spheres, convex sets, convex combinations and hulls, star-shaped sets.
- Turn geometric notions into **statements about distances**: "x lies on the segment [p, q]" is "‖p − x‖ + ‖x − q‖ = ‖p − q‖" (`thm-betweenness`). This is the bridge that lets a map that only knows distances be shown to respect segments, lines and convexity.
- Prove the main theorem honestly and without linear algebra: **every isometry of ℝⁿ is x ↦ Ax + b, where A has orthonormal columns; it is a bijection, and the rows of A are orthonormal too**.
- Hand F4.10 the classification of plane isometries in real coordinates (direct and opposite; rotation about a point, reflection, glide reflection), which F4.10 rewrites as z ↦ az + w and z ↦ a z̄ + w and supplies with angles.
- The reader leaves able to (i) parametrize lines and segments and solve for parameters; (ii) turn a distance condition into a linear one by expanding a square; (iii) prove a set convex by the two-point test, and show convex sets contain convex combinations; (iv) prove two vectors equal by showing the squared norm of their difference is 0; (v) recognise, from a formula, which isometry of the plane a map is.

- **Story** (~150 words). Chapter 3 gave ℝⁿ its inner product and its distance. This chapter asks what the distance alone determines. Analysis uses the convex sets of this chapter at once; the complex numbers then turn the plane's isometries into multiplication.

### 5.1 Section 4.1: Lines and Segments (`01-lines-and-segments.md`)

**Budget** ≤ 5,000 (expected ~4,300). One fold (the p = q edge cases of `cor-point-pinned-on-segment`). Four Quick checks, one warning, one notation remark.

**Opening (~120).** In ℝ² a line is often described by an equation ax + by = c. That description does not survive the move to ℝⁿ, and analysis needs lines in ℝⁿ: for the mean value theorem along a segment, for convex sets, for the paths of complex analysis. This section describes lines by a starting point and a direction, segments by the parameter interval [0, 1], and proves that membership in a segment can be read off from distances alone.

**`## Lines` (~900).**
1. **Naive attempt** (≤ 80 words): "a line is the solution set of one linear equation". In ℝ² this works (Section 4.2 proves it, `exm-lines-in-the-plane`); in ℝ³ the set { x : x₁ + x₂ + x₃ = 1 } contains (1, 0, 0), (0, 1, 0) and (0, 0, 1), which lie on no common line (the drafter shows this in one line after the definition: a line through the first two is (1, 0, 0) + ℝ(−1, 1, 0), whose points have third coordinate 0). A line has one degree of freedom, so describe it by one parameter.
2. **`def-line-rn`** `[Lines in ℝⁿ]`: "Let p, v ∈ ℝⁿ with v ≠ 0. The **line through p with direction v** is \( p + \nR v \coloneqq \{ p + tv : t \in \nR \} \). A subset L ⊆ ℝⁿ is a **line** if L = p + ℝv for some such p and v; the map t ↦ p + tv from ℝ to ℝⁿ is then a **parametrization** of L."
3. **Quick check** (weird examples): (a) Is {p} a line? (b) Is ℝ itself a line in ℝ¹? (c) Is (3, 5, 7) on (1, 1, 1) + ℝ(1, 2, 3)? (d) Does the parameter of a point on p + ℝv depend only on the point? *Solution:* (a) No: since v ≠ 0, p + tv = p + uv gives (t − u)v = 0, so t = u (`prp-norm-rules`: ‖(t − u)v‖ = |t − u|‖v‖); distinct parameters give distinct points, so a line has more than one point. (b) Yes, ℝ = 0 + ℝ·1. (c) Yes, t = 2. (d) Yes, by (a): each point of p + ℝv has exactly one parameter.
4. **`prp-line-parametrizations`** `[When Two Parametrizations Give the Same Line]`: "Let v, v′ ≠ 0. Then p + ℝv = p′ + ℝv′ if and only if p′ ∈ p + ℝv and v′ = λv for some real λ ≠ 0." *Proof.* (⇐) p′ = p + sv; then p′ + tv′ = p + (s + tλ)v, and p + tv = p′ + ((t − s)/λ)v′; double inclusion. (⇒) p′ = p′ + 0v′ ∈ p + ℝv. Also p′ + v′ ∈ p + ℝv, say p′ + v′ = p + uv, and p′ = p + sv; subtracting, v′ = (u − s)v, and λ ≔ u − s ≠ 0 because v′ ≠ 0.
5. **`prp-line-through-two-points`** `[Two Points Determine a Line]`: "Let p ≠ q in ℝⁿ. Exactly one line contains p and q, namely p + ℝ(q − p)." *Proof.* Contains p (t = 0) and q (t = 1); q − p ≠ 0. If L = r + ℝv contains both, p = r + sv, q = r + uv, so q − p = (u − s)v with u ≠ s; by `prp-line-parametrizations` (p ∈ L, q − p a non-zero multiple of v), L = p + ℝ(q − p).
6. **`def-collinear`**: points are **collinear** if some line contains them all. One sentence: two points are always collinear; three need not be (the naive attempt's three points).

**`## Meeting points` (~650).**
1. **`exm-two-lines-in-space`** `[Two Lines in ℝ³]`: L₁ = (1, 0, 1) + ℝ(1, 1, 0), L₂ = (0, 2, 0) + ℝ(1, 0, 1), L₃ = (2, 1, 1) + ℝ(0, 1, 1). Do L₁ and L₂ meet? Do L₁ and L₃?
   - **`[Scratch work]`** (≤ 12 lines): a common point has a parameter on each line, and the parameters need not agree, so use two letters (s on L₁, t on the other); write the coordinate equations and solve.
   - *Solution.* L₁ ∩ L₂: (1 + s, s, 1) = (t, 2, t) gives s = 2, t = 1 from the second and third coordinates, and then 1 + s = 3 ≠ 1 = t. No common point. Neither direction is a multiple of the other ((1, 1, 0) = λ(1, 0, 1) forces λ = 1 and λ = 0), so the lines are not parallel either: **skew** lines, which ℝ² does not have (§01 B2). L₁ ∩ L₃: (1 + s, s, 1) = (2, 1 + u, 1 + u) gives u = 0, s = 1, and the first coordinate checks: 2 = 2. One common point, (2, 1, 1).
2. **`exm-method-parametrize`** `[Method: parametrize and solve]`.
   - **Template.** Write the general point of each line or segment with its own parameter. Turn the question ("is x on it?", "where do they meet?") into equations, one per coordinate. Solve for the parameters; check every equation, not only those used to solve; for a segment, check that the parameter lies in [0, 1].
   - **When to use it.** Questions about which points lie on lines, segments or rays, and where they meet.
   - **The usual failure.** One letter for two parameters (the two lines need not reach the common point at the same parameter); solving from some coordinates and not checking the others.
3. **Quick check.** "Are (1, 2) + ℝ(2, −1) and (5, 0) + ℝ(−4, 2) the same line?" *Solution:* (5, 0) = (1, 2) + 2(2, −1) and (−4, 2) = −2(2, −1), so yes, by `prp-line-parametrizations`.

**`## Segments` (~700).**
1. **`def-segment-rn`** `[Segments]`: "For p, q ∈ ℝⁿ, the **segment** from p to q is \( [p, q] \coloneqq \{ (1 - t)p + tq : t \in [0, 1] \} \). Its **midpoint** is (p + q)/2, the point with t = 1/2." Remarks in prose: (1 − t)p + tq = p + t(q − p), so for p ≠ q the segment is the part of the line through p and q with parameter in [0, 1]; [p, q] = [q, p] (replace t by 1 − t); [p, p] = {p}.
2. **Notation remark** `**Segments and intervals.**` For n = 1 and p ≤ q the segment [p, q] is the interval [p, q]; for p > q it is the interval [q, p]. The chapter writes [p, q] for a segment only when p and q have been declared points of ℝⁿ.
3. **`lem-subsegment`** `[A Segment Between Points of a Segment]`: "If x, y ∈ [p, q], then [x, y] ⊆ [p, q]." *Proof.* x = p + s(q − p), y = p + u(q − p) with s, u ∈ [0, 1]; (1 − t)x + ty = p + ((1 − t)s + tu)(q − p), and 0 ≤ (1 − t)s + tu ≤ (1 − t) + t = 1 by `@fd3:prp-ordered-field-halves` (d) and `@fd3:prp-ordered-ring-rules` (b). (§03 uses this to show segments are convex.)
4. **Quick check.** "Is (2, 0, 1) on [(1, −1, 2), (3, 0, 0)]?" *Solution:* No: (2, 0, 1) − (1, −1, 2) = (1, 1, −1) is not a multiple of (2, 1, −2) (first coordinates force the factor 1/2, second coordinates 1).

**`## Between by distances` (~1,500).**
1. Lead (~80): in a triangle with vertices p, x, q, the triangle inequality says ‖p − q‖ ≤ ‖p − x‖ + ‖x − q‖; the picture suggests equality exactly when x lies on [p, q]. To prove this we need the case of equality in the triangle inequality.
2. **`lem-triangle-equality`** `[Equality in the Triangle Inequality]`: "For u, w ∈ ℝⁿ, ‖u + w‖ = ‖u‖ + ‖w‖ holds if and only if u = 0 or w = λu for some real λ ≥ 0." *Proof.* Both sides are non-negative, so equality holds iff the squares agree (`@fd3:prp-ordered-ring-rules` (g)). Expanding, ‖u + w‖² = ‖u‖² + 2⟨u, w⟩ + ‖w‖² and (‖u‖ + ‖w‖)² = ‖u‖² + 2‖u‖‖w‖ + ‖w‖², so equality iff ⟨u, w⟩ = ‖u‖‖w‖. (⇐) If u = 0, both sides are 0. If w = λu with λ ≥ 0: ⟨u, w⟩ = λ‖u‖² = ‖u‖ · λ‖u‖ = ‖u‖‖w‖. (⇒) Then |⟨u, w⟩| = ‖u‖‖w‖, so by the equality case of Cauchy–Schwarz (`thm-cauchy-schwarz-rn`) one of u, w is a multiple of the other. If u = 0 we are done. If u ≠ 0 and u = μw, then w ≠ 0 and w = μ⁻¹u (μ ≠ 0); so in every case with u ≠ 0, w = λu for some λ, and λ‖u‖² = ⟨u, w⟩ = ‖u‖‖w‖ = |λ|‖u‖², so λ = |λ| ≥ 0. (Binding rule 4: deleted if F4.8 proves it.)
3. **`thm-betweenness`** `[Points Between Two Points]`: "Let p, q, x ∈ ℝⁿ. Then x ∈ [p, q] if and only if ‖p − x‖ + ‖x − q‖ = ‖p − q‖. Moreover, if x = (1 − t)p + tq with t ∈ [0, 1], then ‖p − x‖ = t‖p − q‖ and ‖x − q‖ = (1 − t)‖p − q‖."
   - **`[Scratch work]`** (≤ 20 lines). (⇒) is computation. For (⇐), name u ≔ x − p and w ≔ q − x, so u + w = q − p and the hypothesis is the equality case of the triangle inequality. Table:

     | Givens | Goal |
     |---|---|
     | ‖p − x‖ + ‖x − q‖ = ‖p − q‖ | x = (1 − t)p + tq for some t ∈ [0, 1] |
     | ‖u‖ + ‖w‖ = ‖u + w‖, u = x − p, w = q − x | x = p + t(q − p), t ∈ [0, 1] |
     | u = 0, or w = λu with λ ≥ 0 (`lem-triangle-equality`) | Case u = 0: t = 0. Case w = λu: q − p = (1 + λ)u, so u = (q − p)/(1 + λ): t = 1/(1 + λ) ∈ (0, 1] |

   - *Proof.* (⇒ and the "moreover") x − p = t(q − p) and q − x = (1 − t)(q − p), so ‖p − x‖ = t‖q − p‖ and ‖x − q‖ = (1 − t)‖q − p‖ (`prp-norm-rules`, t ≥ 0, 1 − t ≥ 0), and they add to ‖p − q‖. (⇐) As in the table, citing `lem-triangle-equality`; 1 + λ ≥ 1 > 0, so 0 < 1/(1 + λ) ≤ 1 (`@fd3:prp-ordered-field-halves` (c)).
   - Aftermath (one sentence): the statement on the right mentions only distances; Section 4.4 exploits exactly this.
4. **`exm-method-equality-case`** `[Method: use the equality case]`.
   - **Template.** You know an inequality A ≤ B (triangle, Cauchy–Schwarz, AM–GM) and the hypothesis says A = B. Recall the exact condition for equality; it usually says that some vectors are non-negative multiples of each other, or that some numbers are equal. Write that condition with a named multiplier, and solve for what you want.
   - **When to use it.** A sum of distances equals a distance; a product equals the bound of Cauchy–Schwarz; "the shortest way" or "the extreme case" questions.
   - **The usual failure.** Using "one is a multiple of the other" without the sign (λ ≥ 0 is what separates [p, q] from the rest of the line), or forgetting the case u = 0.
5. **`cor-point-pinned-on-segment`** `[A Point Is Pinned by Its Distances to the Ends]`: "Let p, q ∈ ℝⁿ and s, r ≥ 0 with s + r = ‖p − q‖. Then exactly one x ∈ ℝⁿ has ‖p − x‖ = s and ‖x − q‖ = r. If p ≠ q, it is x = p + (s/‖p − q‖)(q − p)." *Proof.* p ≠ q: the named x works by the "moreover" of `thm-betweenness` with t = s/‖p − q‖ ∈ [0, 1]. Any such x satisfies the distance equation, so x ∈ [p, q], x = (1 − t)p + tq, and then s = ‖p − x‖ = t‖p − q‖ fixes t, hence x (parameters are unique, §01 Quick check (d)). The case p = q (s = r = 0, x = p) goes in the fold.
6. **Quick check.** "Show that the midpoint of [p, q] is the only point at distance ‖p − q‖/2 from both p and q." *Solution:* `cor-point-pinned-on-segment` with s = r = ‖p − q‖/2, t = 1/2.
7. **Warning** `**Equal distances do not make a midpoint.**` ‖p − x‖ = ‖x − q‖ alone does not put x on [p, q]: p = (−1, 0), q = (1, 0), x = (0, 1). The sum condition is what forces x onto the segment. (Section 4.2 identifies the set of points equidistant from p and q.)

**Exercises.**
- **A1.** (a) Parametrize the line through (1, −1, 2) and (3, 0, 0); is (5, 1, −2) on it? (b) Find the midpoint of the segment between those two points. *Answers:* (a) (1, −1, 2) + ℝ(2, 1, −2); yes, t = 2. (b) (2, −1/2, 1).
- **A2.** Show that (1, 2), (3, 5), (7, 11) are collinear and decide which lies between the other two. *Answer:* (7, 11) − (1, 2) = (6, 9) = 3·(2, 3) = 3((3, 5) − (1, 2)), so all three lie on (1, 2) + ℝ(2, 3) with parameters 0, 1, 3; (3, 5) = (1, 2) + (1/3)((7, 11) − (1, 2)) with 1/3 ∈ [0, 1], so (3, 5) is between the others.
- **B1.** Let v ≠ 0 and a < b. Show that p + tv ∈ [p + av, p + bv] if and only if a ≤ t ≤ b. *Answer:* (⇐) s ≔ (t − a)/(b − a) ∈ [0, 1] gives (1 − s)(p + av) + s(p + bv) = p + (a + s(b − a))v = p + tv. (⇒) p + tv = p + ((1 − s)a + sb)v with s ∈ [0, 1]; parameters are unique (v ≠ 0), so t = a + s(b − a) ∈ [a, b].
- **B2.** In ℝ², let v, v′ ≠ 0. Show: (a) v′ is a multiple of v iff v₁v′₂ − v₂v′₁ = 0; (b) if v′ is not a multiple of v, the lines p + ℝv and p′ + ℝv′ meet in exactly one point. *Answer:* (a) (⇒) substitute v′ = λv. (⇐) If v₁ ≠ 0, put λ ≔ v′₁/v₁: then λv₁ = v′₁ and λv₂ = v′₁v₂/v₁ = v₁v′₂/v₁ = v′₂. If v₁ = 0 then v₂ ≠ 0, and λ ≔ v′₂/v₂ works the same way. (b) p + sv = p′ + tv′ is the system sv₁ − tv′₁ = d₁, sv₂ − tv′₂ = d₂ with d ≔ p′ − p. With D ≔ v₁v′₂ − v₂v′₁ ≠ 0 by (a), multiplying the equations by v′₂ and v′₁ and subtracting eliminates t: sD = d₁v′₂ − d₂v′₁; multiplying by v₂ and v₁ and subtracting eliminates s: tD = d₁v₂ − d₂v₁. So any solution is s = (d₁v′₂ − d₂v′₁)/D, t = (d₁v₂ − d₂v₁)/D, and substitution shows this pair is a solution. Sidecar checks both formulas.
- **B3.** Show that L₄ = (0, 0, 0) + ℝ(1, 0, 0) and L₅ = (0, 1, 0) + ℝ(0, 0, 1) are skew: they do not meet and neither direction is a multiple of the other. *Answer:* (s, 0, 0) = (0, 1, t) fails in the second coordinate; (1, 0, 0) = λ(0, 0, 1) fails in the first.
- **B4** (prove or disprove). (a) If ‖p − x‖ = ‖x − q‖ = ‖p − q‖/2, then x is the midpoint of [p, q]. (b) If ‖p − x‖ = ‖x − q‖, then x ∈ [p, q]. (c) Any three points of ℝ² are collinear. (d) If p + ℝv = p + ℝw, then v = w. (e) Two lines with two distinct common points are equal. *Answers:* (a) True: §01 Quick check after `cor-point-pinned-on-segment`. (b) False: the warning's p = (−1, 0), q = (1, 0), x = (0, 1): ‖p − x‖ = ‖x − q‖ = √2, but x ∉ [p, q] (the second coordinate of every point of [p, q] is 0). (c) False: (0, 0), (1, 0), (0, 1); the only line through the first two is (0, 0) + ℝ(1, 0) (`prp-line-through-two-points`), whose points have second coordinate 0. (d) False: w = 2v (`prp-line-parametrizations`). (e) True: both are the unique line through the two points (`prp-line-through-two-points`).
- **C1** (exit check; marking scheme). Prove: of three distinct collinear points, exactly one lies on the segment between the other two. *Answer:* write them as p + t_iv with distinct t₁, t₂, t₃ (one line, distinct points, distinct parameters); relabel so that t₁ < t₂ < t₃ (trichotomy). By B1 (re-proved inline in two lines), p + t₂v ∈ [p + t₁v, p + t₃v]. If also p + t₁v ∈ [p + t₂v, p + t₃v], B1 gives t₂ ≤ t₁, a contradiction; the same for p + t₃v. *Marking scheme* (5 marks): one common parametrization with distinct parameters (1); ordering (1); existence via a named s ∈ [0, 1] (1); uniqueness of the parameter used (1); the two exclusions (1).
- **C2.** Let p ≠ q. Show that { x : ‖p − x‖ − ‖x − q‖ = ‖p − q‖ } = { q + t(q − p) : t ≥ 0 }. *Answer:* the condition says ‖p − q‖ + ‖q − x‖ = ‖p − x‖, so q ∈ [p, x] by `thm-betweenness`; q = (1 − s)p + sx with s ∈ [0, 1], s ≠ 0 since q ≠ p; so x = p + (1/s)(q − p) = q + (1/s − 1)(q − p), with 1/s − 1 ≥ 0. Conversely, for x = q + t(q − p), q = (1 − s)p + sx with s = 1/(1 + t) ∈ (0, 1], so q ∈ [p, x], and `thm-betweenness` gives the equation.

### 5.2 Section 4.2: Hyperplanes and Nearest Points (`02-hyperplanes-and-nearest-points.md`)

**Budget** ≤ 5,000 (expected ~4,400). Four Quick checks. No fold.

**Opening (~100).** One linear equation in n unknowns cuts out a hyperplane: a line in ℝ², a plane in ℝ³. Hyperplanes are where the question "how far is x from this set?" has a formula, and where a single move, expanding a square, turns distance conditions into linear ones.

**`## Hyperplanes` (~1,100).**
1. **`def-hyperplane-rn`** `[Hyperplanes and Half-Spaces]`: "Let a ∈ ℝⁿ with a ≠ 0 and c ∈ ℝ. The **hyperplane** \( H_{a,c} \coloneqq \{ x \in \nR^n : \ip{a}{x} = c \} \); a is a **normal vector** of it. The sets { x : ⟨a, x⟩ ≤ c } and { x : ⟨a, x⟩ ≥ c } are the **closed half-spaces** of \( H_{a,c} \), and the same with < and > the **open half-spaces**." One sentence: H_{a,c} contains p₀ ≔ (c/‖a‖²)a, and x ∈ H_{a,c} iff x − p₀ ⊥ a (since ⟨a, p₀⟩ = c).
2. **`prp-hyperplane-normals`** `[When Two Equations Give the Same Hyperplane]`: "H_{a,c} = H_{a′,c′} if and only if (a′, c′) = (λa, λc) for some λ ≠ 0." *Proof.* (⇐) ⟨λa, x⟩ = λc iff ⟨a, x⟩ = c. (⇒) Every p₀ + w with w ⊥ a lies in H_{a,c} = H_{a′,c′}, so ⟨a′, p₀ + w⟩ = c′ for all w ⊥ a; with w = 0, ⟨a′, p₀⟩ = c′, hence ⟨a′, w⟩ = 0 for all w ⊥ a. Take w ≔ a′ − μa with μ ≔ ⟨a′, a⟩/‖a‖², which is ⊥ a (the projection residual, `prp-projection-rn`). Then ‖w‖² = ⟨a′, w⟩ − μ⟨a, w⟩ = 0, so a′ = μa; μ ≠ 0 since a′ ≠ 0; and c′ = ⟨a′, p₀⟩ = μc.
3. **`exm-lines-in-the-plane`** `[Lines of ℝ² Are Its Hyperplanes]`: "(a) In ℝ², H_{a,c} = p₀ + ℝ(−a₂, a₁). (b) Every line p + ℝv in ℝ² equals H_{a,c} with a = (−v₂, v₁), c = ⟨a, p⟩." *Solution.* (a) ⊇: ⟨a, (−a₂, a₁)⟩ = 0. ⊆: for x ∈ H_{a,c}, w ≔ x − p₀ has a₁w₁ + a₂w₂ = 0; with t ≔ (a₁w₂ − a₂w₁)/‖a‖², t(−a₂, a₁) = w (first coordinate: (−a₁a₂w₂ + a₂²w₁)/‖a‖² = (a₁²w₁ + a₂²w₁)/‖a‖² = w₁, using a₂w₂ = −a₁w₁; the second the same way). (b) a ≠ 0 since v ≠ 0, and ⟨a, v⟩ = 0, so p + ℝv ⊆ H_{a,c}; by (a), H_{a,c} = p₀ + ℝ(−a₂, a₁) = p₀ + ℝ(−v₁, −v₂), and `prp-line-parametrizations` (p ∈ H_{a,c}, direction −v) gives equality. Aftermath: in ℝ² "line" and "hyperplane" coincide; in ℝ³ a hyperplane contains the three non-collinear points of §01's naive attempt, so it is not a line.
4. **Quick check.** "Write the line through (1, 3) and (4, −1) as ax + by = c." *Solution:* direction (3, −4), normal (4, 3), c = 4 + 9 = 13: 4x + 3y = 13 (check (4, −1): 16 − 3 = 13).

**`## Expanding a square` (~1,000).**
1. Lead: the set of points at equal distance from p and from q looks like a condition of degree two, but it is linear.
2. **`prp-perpendicular-bisector`** `[Points Equidistant from Two Points]`: "Let p ≠ q in ℝⁿ. Then { x : ‖x − p‖ = ‖x − q‖ } = H_{q−p, c} with c = (‖q‖² − ‖p‖²)/2. This hyperplane contains the midpoint (p + q)/2. Moreover ‖x − p‖ < ‖x − q‖ iff ⟨q − p, x⟩ < c."
   - **`[Scratch work]`** (≤ 12 lines): distances involve square roots; square them (both sides non-negative, `@fd3:prp-ordered-ring-rules` (g)); expand; the ‖x‖² terms cancel and what remains is linear in x.
   - *Proof.* ‖x − p‖² = ‖x‖² − 2⟨x, p⟩ + ‖p‖², and the same with q. Equality (and the strict inequality) of the squares is equivalent to that of the distances; subtracting, ‖x − p‖² − ‖x − q‖² = 2⟨q − p, x⟩ − (‖q‖² − ‖p‖²). Midpoint: ⟨q − p, (p + q)/2⟩ = (‖q‖² − ‖p‖²)/2.
3. **`exm-method-expand-the-square`** `[Method: expand the square]`.
   - **Template.** Square the distances (they are non-negative, so nothing is lost). Expand each ‖x − y‖² as ‖x‖² − 2⟨x, y⟩ + ‖y‖². Cancel what appears on both sides. What remains is usually linear in the unknown point, or a quadratic in one real parameter that you can complete to a square.
   - **When to use it.** Equidistance; nearest points; whether a map keeps distances; any identity between norms.
   - **The usual failure.** Writing ‖x − y‖² = ‖x‖² − ‖y‖², or dropping the factor 2 in the cross term. Squaring an equation between quantities of unknown sign.
4. **Quick check.** "Find the set of points of ℝ² equidistant from (0, 0) and (2, 4)." *Solution:* ⟨(2, 4), x⟩ = 10, that is x₁ + 2x₂ = 5, through the midpoint (1, 2).

**`## Nearest points` (~1,200).**
1. **`prp-nearest-point-on-line`** `[Nearest Point on a Line]`: "Let L = p + ℝv and x ∈ ℝⁿ, and put t₀ ≔ ⟨x − p, v⟩/‖v‖², m ≔ p + t₀v. Then for every t, ‖x − (p + tv)‖² = ‖x − m‖² + (t − t₀)²‖v‖², and x − m ⊥ v. Hence m is the unique point of L nearest to x, and ‖x − m‖² = ‖x − p‖² − ⟨x − p, v⟩²/‖v‖²." *Proof.* Idea citing the box: expand ‖(x − p) − tv‖² = ‖x − p‖² − 2t⟨x − p, v⟩ + t²‖v‖² and complete the square in t (move "complete the square in the parameter"). x − m ⊥ v is F4.8's projection residual (`prp-projection-rn`). Uniqueness: (t − t₀)²‖v‖² > 0 for t ≠ t₀.
2. **`prp-nearest-point-on-hyperplane`** `[Distance to a Hyperplane]`: "Let H = H_{a,c} and x ∈ ℝⁿ, and put x* ≔ x − ((⟨a, x⟩ − c)/‖a‖²)a. Then x* ∈ H, and for every y ∈ H, ‖x − y‖² = ‖x − x*‖² + ‖x* − y‖². Hence x* is the unique point of H nearest to x, and its distance from x is |⟨a, x⟩ − c|/‖a‖." *Proof.* ⟨a, x*⟩ = ⟨a, x⟩ − (⟨a, x⟩ − c) = c. x − x* is a multiple of a; x* − y ⊥ a since both lie in H; Pythagoras (`prp-pythagoras-rn`). Distance: ‖μa‖ = |μ|‖a‖ with μ = (⟨a, x⟩ − c)/‖a‖².
3. **Quick check.** "Distance from (1, 2, 3) to the plane x₁ + x₂ + x₃ = 0, and the nearest point." *Solution:* 6/√3 = 2√3; (1, 2, 3) − 2(1, 1, 1) = (−1, 0, 1).

**`## Spheres and lines` (~700).**
1. **`def-sphere-rn`** `[Spheres]`: for c ∈ ℝⁿ, r > 0, S(c, r) ≔ { x : ‖x − c‖ = r } (a circle when n = 2).
2. **`prp-line-meets-sphere`** `[A Line Meets a Sphere in at Most Two Points]`: "Let L = p + ℝv, and let d be the distance from c to L (`prp-nearest-point-on-line`, nearest point m = p + t₀v). Then L ∩ S(c, r) is empty if d > r, is {m} if d = r, and has exactly two points, p + (t₀ ± √(r² − d²)/‖v‖)v, if d < r." *Proof.* By `prp-nearest-point-on-line` with x = c, ‖p + tv − c‖² = d² + (t − t₀)²‖v‖²; this equals r² iff (t − t₀)² = (r² − d²)/‖v‖²; a square is ≥ 0, and a non-negative real has exactly the two square roots ±√ (`@fd3:prp-cof-square-roots` and `@fd3:prp-ordered-ring-rules` (f)), distinct when positive. A line with d = r is **tangent** to the sphere at m, and m − c ⊥ v.

**`## Crossing a hyperplane` (~300).**
1. **`prp-segment-crosses-hyperplane`** `[A Segment Between the Two Sides Crosses Once]`: "If ⟨a, p⟩ < c < ⟨a, q⟩, then [p, q] meets H_{a,c} in exactly one point, (1 − t)p + tq with t = (c − ⟨a, p⟩)/(⟨a, q⟩ − ⟨a, p⟩)." *Proof.* φ(t) ≔ ⟨a, (1 − t)p + tq⟩ = ⟨a, p⟩ + t(⟨a, q⟩ − ⟨a, p⟩) is linear in t with positive slope; solve φ(t) = c; 0 < t < 1. (AN2.3 uses half-spaces to separate; one sentence of prose, no forward label.)

### 5.3 Section 4.3: Convex Sets (`03-convex-sets.md`)

**Budget** ≤ 5,000 (expected ~4,200). One fold (the case λ_{k+1} = 1 in `thm-convex-contains-combinations`). Four Quick checks.

**Opening and motivation (~350).** Analysis repeatedly needs to move from one point of a set to another along a segment without leaving the set: the mean value theorem in several variables, connectedness, Cauchy's theorem. Before the definition, the **weird-examples Quick check**: "Which of these sets contain the whole segment between any two of their points: a disc; an annulus 1 ≤ ‖x‖ ≤ 2 in ℝ²; a line; a set of two points; ∅; the union of the two coordinate axes of ℝ²?" *Solution:* disc yes (proved below); annulus no ((−3/2, 0), (3/2, 0), midpoint 0); line yes; two points no; ∅ yes (nothing to check); the axes no ((1, 0), (0, 1), midpoint (1/2, 1/2)).

**`## Convex sets and balls` (~1,000).**
1. **`def-convex-set-rn`** `[Convex Sets]`: "A set C ⊆ ℝⁿ is **convex** if [p, q] ⊆ C for all p, q ∈ C."
2. **`def-ball-rn`** `[Balls in ℝⁿ]`: for c ∈ ℝⁿ, r > 0: B(c, r) ≔ { x : ‖x − c‖ < r } (open ball), B̄(c, r) ≔ { x : ‖x − c‖ ≤ r } (closed ball). One sentence: the words "open" and "closed" are names here; *Analysis on the Real Line* explains them, and Chapter 7 defines balls for any distance.
3. **`prp-balls-convex`** `[Balls Are Convex]`: "B(c, r) and B̄(c, r) are convex."
   - **`[Scratch work]`** with table: Givens ‖p − c‖ < r, ‖q − c‖ < r, t ∈ [0, 1]; Goal ‖(1 − t)p + tq − c‖ < r; write c = (1 − t)c + tc, so the vector is (1 − t)(p − c) + t(q − c); triangle inequality and homogeneity.
   - *Proof.* ‖(1 − t)(p − c) + t(q − c)‖ ≤ (1 − t)‖p − c‖ + t‖q − c‖ ≤ max(‖p − c‖, ‖q − c‖) < r. (The middle step: (1 − t)α + tβ ≤ (1 − t)M + tM = M.) Closed ball the same with ≤.
4. **`exm-method-two-point-test`** `[Method: the two-point test]`.
   - **Template.** Let p, q ∈ C and t ∈ [0, 1]. Write the defining condition of C for p and for q. Write (1 − t)p + tq and check the condition for it, usually by splitting a vector or a sum as (1 − t)(…) + t(…) and using the triangle inequality or linearity.
   - **When to use it.** Proving a set convex from its definition.
   - **The usual failure.** Checking only the midpoint (t = 1/2), which is not enough (§03 C3); using t ∈ ℝ, or weights that are not non-negative, which proves something about lines instead.

**`## Examples and operations` (~900).**
1. **`prp-convex-examples`** `[Lines, Segments, Hyperplanes and Half-Spaces Are Convex]`. *Proof.* Lines: (1 − t)(p + sv) + t(p + uv) = p + ((1 − t)s + tu)v. Segments: `lem-subsegment`. Hyperplanes and half-spaces: ⟨a, (1 − t)x + ty⟩ = (1 − t)⟨a, x⟩ + t⟨a, y⟩, which is = c, ≤ c, < c … when both are (strict cases: at least one weight positive).
2. **`prp-convex-operations`** `[Operations That Keep Convexity]`: "(a) The intersection of any family of convex subsets of ℝⁿ is convex. (b) If C is convex, so are b + C and λC (b ∈ ℝⁿ, λ ∈ ℝ). (c) A union of two convex sets need not be convex." *Proof.* (a) `@fd2:def-family-union-intersection`: p, q in every member, so [p, q] ⊆ every member. (b) (1 − t)(b + x) + t(b + y) = b + ((1 − t)x + ty). (c) {p} ∪ {q} with p ≠ q.
3. **Quick check.** "Is { x ∈ ℝ² : x₁ ≥ 0, x₂ ≥ 0, x₁ + x₂ ≤ 1 } convex?" *Solution:* yes, an intersection of three closed half-spaces, by `prp-convex-examples` and `prp-convex-operations` (a).

**`## Convex combinations and the convex hull` (~1,400).**
1. **`def-convex-combination-rn`** `[Convex Combinations]`: for points p₁, …, p_k ∈ ℝⁿ (k ≥ 1) and reals λ₁, …, λ_k ≥ 0 with Σ λ_i = 1, the point Σ λ_i p_i is a **convex combination** of p₁, …, p_k. For k = 2 these are exactly the points of [p₁, p₂].
2. **`thm-convex-contains-combinations`** `[A Convex Set Contains the Convex Combinations of Its Points]`: "If C is convex and p₁, …, p_k ∈ C, every convex combination of p₁, …, p_k lies in C." *Proof* by induction on k ≥ 1 (`@fd2:thm-induction` from base 1). k = 1: λ₁ = 1. Step (move "peel off the last point"): given λ₁, …, λ_{k+1}, if λ_{k+1} = 1 then all other λ_i = 0 and the point is p_{k+1} (fold). Otherwise s ≔ 1 − λ_{k+1} = Σ_{i≤k} λ_i > 0, and Σ_{i≤k+1} λ_i p_i = s·(Σ_{i≤k} (λ_i/s) p_i) + λ_{k+1}p_{k+1}; the bracket is a convex combination of k points, in C by the hypothesis; the whole is a point of the segment from it to p_{k+1} (weights s and λ_{k+1} = 1 − s), in C by convexity. Scratch work (≤ 10 lines) saying why one splits off one point: convexity speaks about two points only.
3. **`def-convex-hull-rn`** `[Convex Hull]`: for S ⊆ ℝⁿ, conv S is the intersection of all convex subsets of ℝⁿ containing S. By `prp-convex-operations` (a) it is convex, contains S and lies inside every convex set containing S: the **smallest** convex set containing S (the same argument as `@fd2:prp-smallest-closed-set`; ℝⁿ itself is one such set, so the family is non-empty).
4. **`thm-convex-hull-combinations-rn`** `[The Convex Hull Is the Set of Convex Combinations]`: "conv S is the set K of all convex combinations of finitely many points of S." *Proof.* K ⊆ conv S: every convex set containing S contains K by `thm-convex-contains-combinations`. conv S ⊆ K: K contains S (k = 1) and is convex: given Σ λ_i p_i and Σ μ_j q_j, (1 − t)Σλ_ip_i + tΣμ_jq_j is a combination of the list p₁, …, p_k, q₁, …, q_l with weights (1 − t)λ_i, tμ_j ≥ 0 summing to (1 − t) + t = 1. So conv S, the smallest convex superset, lies in K.
5. **`exm-triangle-as-hull`** `[Triangles]`: conv{p, q} = [p, q]; for three points, conv{p₁, p₂, p₃} = { λ₁p₁ + λ₂p₂ + λ₃p₃ : λ_i ≥ 0, Σλ_i = 1 }, the (filled) **triangle**. Worked: (1, 1) = (1/3)(0, 0) + (1/3)(3, 0) + (1/3)(0, 3) lies in the triangle with those vertices, and (2, 2) does not (3λ₂ = 2 = 3λ₃ forces λ₂ + λ₃ = 4/3 > 1). (CA.2's triangles: prose pointer, no label.)
6. **Quick check.** "Show that every convex combination of points of a closed half-space lies in it, without the theorem." *Solution:* ⟨a, Σλ_ip_i⟩ = Σλ_i⟨a, p_i⟩ ≤ Σλ_ic = c.

**`## Star-shaped sets` (~450).**
1. **`def-star-shaped`** `[Star-Shaped Sets]`: S ⊆ ℝⁿ is **star-shaped about** c ∈ S if [c, x] ⊆ S for every x ∈ S.
2. One sentence: a non-empty convex set is star-shaped about each of its points.
3. **`exm-star-not-convex`** `[Star-Shaped, Not Convex]`: the union A of the coordinate axes of ℝ² is star-shaped about 0 ((1 − t)·0 + t(x₁, 0) = (tx₁, 0) ∈ A, likewise on the other axis) and not convex (weird-examples check). Also the "plus-shaped" union of two segments [(−1, 0), (1, 0)] ∪ [(0, −1), (0, 1)].
4. **Quick check.** "Is A star-shaped about (1, 0)?" *Solution:* no: [(1, 0), (0, 1)] contains (1/2, 1/2) ∉ A.

**Exercises.**
- **A1.** Which are convex? (a) { (x, y) : y ≥ x² }; (b) { (x, y) : y ≤ x² }; (c) ℤ²; (d) { x ∈ ℝ² : 1 ≤ ‖x‖ ≤ 2 }. *Answers:* (a) yes (B1); (b) no: (−1, 1) and (1, 1) are in it, the midpoint (0, 1) is not (1 ≤ 0 fails); (c) no: (0, 0), (1, 0), midpoint (1/2, 0); (d) no: (−3/2, 0), (3/2, 0), midpoint 0.

- **C1.** Show { (x, y) : x > 0, xy ≥ 1 } is convex. *Answer:* let (a, b), (c, d) be in it, t ∈ [0, 1], x ≔ (1 − t)a + tc > 0, y ≔ (1 − t)b + td ≥ (1 − t)/a + t/c (b ≥ 1/a, d ≥ 1/c). (AN2.3 cites this for connected subsets of ℝ; prose.) *Marking scheme* (4): inf/sup exist or the infinite cases (1); a, b found (1); segment = interval for n = 1 (1); conclusion (1).

(b) Show that ℚ² ⊆ ℝ² is midpoint convex and not convex. *Answer:* (a) induction on m: m = 0 gives t ∈ {0, 1}; for m + 1, if k is even, t = (k/2)/2^m; if k is odd, t is the average of t₁ = (k − 1)/2^{m+1} and t₂ = (k + 1)/2^{m+1}, both with even numerator, so the points for t₁, t₂ are in C by the hypothesis, and (1 − t)p + tq is their midpoint. (b) Midpoints of rational points are rational; but [(0, 0), (1, 0)] contains (1/√2, 0), and 1/√2 = √2/2 ∉ ℚ (`@fd3:thm-no-rational-square-two`; √2 from `@fd3:prp-cof-square-roots`).

### 5.4 Section 4.4: Isometries (`04-isometries.md`)

**Budget** ≤ 5,000 (expected ~4,100). One fold (the t < 0 case of `thm-isometry-preserves-segments`). Four Quick checks.

**Opening: the hook (~250).** Translations, reflections and rotations of the plane keep every distance. Are there others? Must a map that keeps all distances be **onto**, or could it squeeze ℝⁿ into a part of itself, as x ↦ x + 1 squeezes [0, ∞) into [1, ∞)? This section collects what distances alone force; Section 4.5 answers both questions.

**`## Definition and examples` (~900).**
1. **`def-isometry-rn`** `[Isometries of ℝⁿ]`: "A map f: ℝⁿ → ℝⁿ is an **isometry** if ‖f(x) − f(y)‖ = ‖x − y‖ for all x, y ∈ ℝⁿ." Note in prose: not assumed onto.
2. **Quick check** (weird candidates): (a) x ↦ −x; (b) x ↦ 2x; (c) on ℝ, x ↦ |x|; (d) on ℝ², (x₁, x₂) ↦ (x₂, x₁); (e) a constant map. *Solution:* (a) yes; (b) no (distances double); (c) no (−1 and 1 go to the same point); (d) yes; (e) no (two different points go to one).
3. **`exm-isometry-examples`** `[Translations, Coordinate Changes]`: τ_b(x) ≔ x + b; a permutation of coordinates; a change of sign of some coordinates. Proofs in one line each: τ_b(x) − τ_b(y) = x − y; ‖·‖² is a sum of squares, unchanged by reordering (finite-sum re-indexing, F4.6) or by changing signs.
4. **`def-reflection-hyperplane`** `[Reflection in a Hyperplane]`: for a ≠ 0, c ∈ ℝ: ρ_{a,c}(x) ≔ x − 2((⟨a, x⟩ − c)/‖a‖²)a. Prose: with x* the nearest point of H_{a,c} (`prp-nearest-point-on-hyperplane`), ρ_{a,c}(x) = 2x* − x, so x* is the midpoint of [x, ρ_{a,c}(x)].
5. **`prp-reflection-properties`** `[Properties of Reflections]`: "(a) ρ_{a,c} is an isometry. (b) ρ_{a,c} ∘ ρ_{a,c} = id, so ρ_{a,c} is a bijection and its own inverse. (c) ρ_{a,c}(x) = x iff x ∈ H_{a,c}. (d) For p ≠ q, the reflection in the hyperplane of `prp-perpendicular-bisector` sends p to q and q to p. (e) If c = 0, ρ_{a,0}(0) = 0." *Proof.* (a) Idea citing `exm-method-expand-the-square`: with w = x − y and μ = ⟨a, w⟩/‖a‖², ρ(x) − ρ(y) = w − 2μa and ‖w − 2μa‖² = ‖w‖² − 4μ⟨a, w⟩ + 4μ²‖a‖² = ‖w‖² − 4μ²‖a‖² + 4μ²‖a‖² = ‖w‖². (b) ⟨a, ρ(x)⟩ − c = −(⟨a, x⟩ − c), so ρ(ρ(x)) = ρ(x) + 2((⟨a, x⟩ − c)/‖a‖²)a = x; `@fd2:thm-bijection-iff-inverse`. (c) The correction term is 0 iff ⟨a, x⟩ = c. (d) With a = q − p, c = (‖q‖² − ‖p‖²)/2: ⟨a, p⟩ − c = ⟨q, p⟩ − (‖p‖² + ‖q‖²)/2 = −‖q − p‖²/2, so ρ(p) = p + a = q; then ρ(q) = ρ(ρ(p)) = p by (b). (e) ⟨a, 0⟩ − 0 = 0.

**`## Composites, inverses and the origin` (~600).**
1. **`prp-isometry-composition`** `[Composites and Inverses of Isometries]`: "(a) The composite of two isometries is an isometry. (b) Every isometry is injective. (c) If an isometry is bijective, its inverse is an isometry." *Proof.* (a) one line. (b) f(x) = f(y) gives ‖x − y‖ = 0. (c) ‖f⁻¹(u) − f⁻¹(w)‖ = ‖f(f⁻¹(u)) − f(f⁻¹(w))‖ = ‖u − w‖.
2. **`prp-isometry-reduce-to-origin`** `[Every Isometry Is a Translate of One Fixing 0]`: "If f is an isometry, g ≔ τ_{−f(0)} ∘ f is an isometry with g(0) = 0, and f = τ_{f(0)} ∘ g." (Move "reduce to the origin".)

**`## What distances force` (~1,600).**
1. **`exm-method-distances-only`** `[Method: describe it by distances alone]`.
   - **Template.** To show that every isometry f carries objects of some kind to objects of the same kind, find a description of the kind that mentions only distances between points. Apply f: the distances are unchanged, so the images satisfy the same description.
   - **When to use it.** Midpoints, segments, spheres, balls, perpendicular bisectors under isometries; later, any notion defined by a metric (Chapter 7).
   - **The usual failure.** Using a description that mentions more than distances, such as a parameter or a sum p + tv, and then claiming that f respects it: that is what has to be proved.
2. **`thm-isometry-preserves-segments`** `[Isometries Preserve Segments and Lines]`: "Let f be an isometry of ℝⁿ and p, q, v ∈ ℝⁿ. (a) f((1 − t)p + tq) = (1 − t)f(p) + tf(q) for every t ∈ [0, 1]; hence f([p, q]) = [f(p), f(q)], and f maps midpoints to midpoints. (b) f(p + tv) = f(p) + t(f(p + v) − f(p)) for every t ∈ ℝ; hence if v ≠ 0, f maps the line p + ℝv onto the line f(p) + ℝ(f(p + v) − f(p))."
   - **`[Scratch work]`** with table: Givens ‖f(x) − f(y)‖ = ‖x − y‖; x = (1 − t)p + tq. Goal f(x) = (1 − t)f(p) + tf(q). The goal mentions a sum, which f is not known to respect; the bridge is `thm-betweenness` and `cor-point-pinned-on-segment`, which describe x by its distances to p and q.

     | Givens | Goal |
     |---|---|
     | x = (1 − t)p + tq | f(x) = (1 − t)f(p) + tf(q) |
     | ‖p − x‖ = t‖p − q‖, ‖x − q‖ = (1 − t)‖p − q‖ (`thm-betweenness`) | f(x) is the point at distances t‖f(p) − f(q)‖ and (1 − t)‖f(p) − f(q)‖ from f(p), f(q) |
     | the same equations with f applied (isometry) | `cor-point-pinned-on-segment`: that point is f(p) + t(f(q) − f(p)) |

   - *Proof.* (a) As in the table (p = q is trivial: both sides f(p)). Onto: every point of [f(p), f(q)] is (1 − t)f(p) + tf(q) = f((1 − t)p + tq). (b) t ∈ [0, 1] is (a) with q = p + v. For t > 1: p + v = (1 − 1/t)p + (1/t)(p + tv), so by (a) f(p + v) = (1 − 1/t)f(p) + (1/t)f(p + tv); solve for f(p + tv). For t < 0 (fold): p = (1 − s)(p + tv) + s(p + v) with s = −t/(1 − t) ∈ (0, 1), so f(p) = (1 − s)f(p + tv) + sf(p + v), and solving, using 1/(1 − s) = 1 − t and s/(1 − s) = −t, gives f(p + tv) = (1 − t)f(p) + tf(p + v). Lines: f(p + v) ≠ f(p) by injectivity, and every point f(p) + t(f(p + v) − f(p)) is attained.
3. **`cor-isometry-convex-image`** `[Isometries Carry Convex Sets to Convex Sets]`: "If f is an isometry and C ⊆ ℝⁿ is convex, then f(C) is convex. Also f(B(c, r)) ⊆ B(f(c), r) and f(S(c, r)) ⊆ S(f(c), r)." *Proof* (terse). [f(p), f(q)] = f([p, q]) ⊆ f(C). Balls and spheres: distances to c. One sentence: "⊆" becomes "=" in Section 4.5, once f is known to be onto.
4. **Quick check.** "An isometry f of ℝ² has f(0, 0) = (1, 1) and f(2, 0) = (1, 3). What is f(1, 0)? f(3, 0)?" *Solution:* midpoint (1, 2); f(0 + 3·(1, 0)) = (1, 1) + 3((1, 2) − (1, 1)) = (1, 4), by (b) with p = 0, v = (1, 0).
5. Closing paragraph (~100): (b) says f is "affine along each line". Whether it is affine on all of ℝⁿ, and whether it is onto, needs one more idea: Section 4.5.

### 5.5 Section 4.5: Isometries Fixing the Origin (`05-isometries-fixing-the-origin.md`)

**Budget** ≤ 5,000 (expected ~4,600). Two folds (the induction details in `lem-orthonormal-at-most-n`; the uniqueness clause of `thm-isometries-of-rn`). Four Quick checks, one Try-it-first.

**Opening (~120).** By `prp-isometry-reduce-to-origin` every isometry is a translation after one that fixes 0. This section shows that an isometry fixing 0 keeps inner products, is linear, and is given by an array with orthonormal columns, and then that it is onto. The tools are the inner product of Chapter 3 and one new move.

**`## Inner products are kept` (~500).**
1. **`prp-isometry-preserves-inner-product`** `[An Isometry Fixing 0 Keeps Norms and Inner Products]`: "If f is an isometry with f(0) = 0, then ‖f(x)‖ = ‖x‖ and ⟨f(x), f(y)⟩ = ⟨x, y⟩ for all x, y." *Proof* (terse, the expand-the-square back-reference): ‖f(x)‖ = ‖f(x) − f(0)‖ = ‖x‖; and ⟨x, y⟩ = (‖x‖² + ‖y‖² − ‖x − y‖²)/2 (expanding ‖x − y‖²), the same for f(x), f(y), and each term on the right is kept.
2. **Quick check.** "Does the identity ⟨x, y⟩ = (‖x‖² + ‖y‖² − ‖x − y‖²)/2 need f? Check it for x = (1, 2), y = (3, −1)." *Solution:* ⟨x, y⟩ = 1; (5 + 10 − 13)/2 = 1.

**`## Linearity` (~1,100).**
1. **Try it first** (as in §1 above).
2. **`thm-isometry-fixing-origin-linear`** `[An Isometry Fixing the Origin Is Linear]`: "If f is an isometry of ℝⁿ with f(0) = 0, then f(x + y) = f(x) + f(y) and f(λx) = λf(x) for all x, y ∈ ℝⁿ and λ ∈ ℝ."
   - **`[Scratch work]`** with table: Goal u = v with u = f(x + y), v = f(x) + f(y). We know nothing about f of a sum, only inner products of f-values. So expand ‖u − v‖² into inner products of f-values, replace each by the inner product of the points (`prp-isometry-preserves-inner-product`), and recognise the result.

     | Givens | Goal |
     |---|---|
     | ⟨f(a), f(b)⟩ = ⟨a, b⟩ for all a, b | f(x + y) = f(x) + f(y) |
     | | ‖f(x + y) − f(x) − f(y)‖² = 0 |
     | expand into 6 inner products of f-values; replace each | ‖(x + y) − x − y‖² = 0 ✓ |

   - *Proof.* ‖f(x + y) − f(x) − f(y)‖² = ‖f(x + y)‖² + ‖f(x)‖² + ‖f(y)‖² − 2⟨f(x + y), f(x)⟩ − 2⟨f(x + y), f(y)⟩ + 2⟨f(x), f(y)⟩, which by `prp-isometry-preserves-inner-product` equals the same expression without f, that is ‖(x + y) − x − y‖² = 0. So f(x + y) − f(x) − f(y) = 0 (`prp-norm-rules`). Likewise ‖f(λx) − λf(x)‖² = ‖λx‖² − 2λ⟨λx, x⟩ + λ²‖x‖² = 0.
   - Aftermath (~80): a second route is §04 C3's repaired argument: midpoints and `thm-isometry-preserves-segments` (b) give additivity, and (b) with p = 0 gives f(tv) = tf(v). The expansion is shorter and is the route F4.11 cannot take for other distances (no inner product): one sentence, the thread.
3. **`exm-method-norm-zero`** `[Method: prove u = v by expanding ‖u − v‖²]`.
   - **Template.** To prove two vectors equal, show ‖u − v‖² = 0. Expand it as ‖u‖² − 2⟨u, v⟩ + ‖v‖² (or into more terms, if u and v are sums), and evaluate each term with what you know.
   - **When to use it.** You know inner products or norms of the vectors, but not their coordinates; typical for maps known only to keep distances or inner products.
   - **The usual failure.** Expanding the norm, not its square; losing a cross term when u or v is a sum of three vectors (there are six terms for ‖a − b − c‖²).
4. **Proof ordering (A3 below)** sits after the box.

**`## Maps given by columns` (~900).**
1. **`def-orthonormal-list-rn`** `[Orthonormal Lists]`: vectors u₁, …, u_k ∈ ℝⁿ form an **orthonormal list** if ⟨u_i, u_j⟩ = 1 for i = j and 0 for i ≠ j. Example: e₁, …, eₙ.
2. **`def-columns-map`** `[The Map Given by Columns]`: "Let a₁, …, aₙ ∈ ℝᵐ. The array A with **columns** a₁, …, aₙ (an m × n array of reals, entry a_{ij} the i-th coordinate of a_j) **gives** the map ℝⁿ → ℝᵐ, x ↦ Ax ≔ Σ_{j=1}^{n} x_j a_j; in coordinates, (Ax)_i = Σ_j a_{ij}x_j." Prose: A(x + y) = Ax + Ay, A(λx) = λAx, Ae_j = a_j (finite sums, F4.6); such arrays are called matrices, and the linear algebra volumes (*Spaces and Maps*) study them; here only this formula is used (binding rule 1).
3. **`prp-orthonormal-columns-isometry`** `[Orthonormal Columns Give an Isometry]`: "If a₁, …, aₙ ∈ ℝᵐ is an orthonormal list, then ⟨Ax, Ay⟩ = ⟨x, y⟩ for all x, y ∈ ℝⁿ; in particular ‖Ax − Ay‖ = ‖x − y‖." *Proof.* ⟨Σ_i x_ia_i, Σ_j y_ja_j⟩ = Σ_iΣ_j x_iy_j⟨a_i, a_j⟩ = Σ_i x_iy_i (linearity of ⟨,⟩ over finite sums, `prp-inner-product-rules`; double sums, F4.6). Then A(x − y) = Ax − Ay.
4. **`thm-isometries-of-rn`** `[The Isometries of ℝⁿ]` (key): "A map f: ℝⁿ → ℝⁿ is an isometry if and only if there are an orthonormal list a₁, …, aₙ ∈ ℝⁿ and b ∈ ℝⁿ with f(x) = Ax + b for all x. Then b = f(0) and a_j = f(e_j) − f(0), so A and b are determined by f." *Proof.* (⇐) x ↦ Ax is an isometry (`prp-orthonormal-columns-isometry`), and so is its composite with τ_b. (⇒) g ≔ τ_{−f(0)} ∘ f fixes 0 (`prp-isometry-reduce-to-origin`), so it is linear (`thm-isometry-fixing-origin-linear`), hence g(x) = g(Σ x_je_j) = Σ x_jg(e_j) (induction on the number of terms) = Ax with a_j ≔ g(e_j); the a_j are orthonormal since ⟨g(e_i), g(e_j)⟩ = ⟨e_i, e_j⟩. Uniqueness (fold): f(0) = A0 + b = b and f(e_j) = a_j + b.
5. **Quick check.** "Find A and b for f(x, y) = (y + 1, x − 2)." *Solution:* b = (1, −2), a₁ = f(1, 0) − b = (0, 1), a₂ = f(0, 1) − b = (1, 0).

**`## Every isometry is onto` (~1,500).**
1. Lead (~100): x ↦ (x, 0) from ℝ² to ℝ³ keeps distances and is not onto. Inside ℝⁿ that cannot happen; the reason is that ℝⁿ has no room for n + 1 orthonormal vectors. The linear algebra volumes prove such counts by dimension theory; here a direct induction suffices, using reflections.
2. **`lem-orthonormal-at-most-n`** `[At Most n Orthonormal Vectors in ℝⁿ]` (key): "For n ≥ 1, every orthonormal list in ℝⁿ has at most n vectors." *Proof* by induction on n (`@fd2:thm-induction` from base 1), statement P(n): "no orthonormal list in ℝⁿ has more than n vectors". n = 1: two reals u, w with u² = w² = 1 and uw = 0 do not exist (`@fd3:prp-ordered-ring-rules` (f)). Step (move "clear a coordinate with a reflection"): suppose u₁, …, u_k is orthonormal in ℝ^{n+1} with k > n + 1. Let ρ be the identity if u_k = e_{n+1}, and otherwise the reflection exchanging u_k and e_{n+1} (`prp-reflection-properties` (d)); its hyperplane has c = (‖e_{n+1}‖² − ‖u_k‖²)/2 = 0, so ρ(0) = 0 ((e)) and ρ keeps inner products (`prp-isometry-preserves-inner-product`). So w_i ≔ ρ(u_i) is orthonormal with w_k = e_{n+1}, and for i < k the last coordinate of w_i is ⟨w_i, e_{n+1}⟩ = 0. Deleting that coordinate gives vectors w′₁, …, w′_{k−1} ∈ ℝⁿ with the same inner products: an orthonormal list of k − 1 > n vectors in ℝⁿ, contrary to P(n). (Fold: the inner products of the shortened vectors, written out.)
3. **`prp-orthonormal-expansion`** `[n Orthonormal Vectors Expand Every Vector of ℝⁿ]`: "If u₁, …, uₙ ∈ ℝⁿ is an orthonormal list, then z = Σ_j ⟨z, u_j⟩u_j for every z ∈ ℝⁿ." *Proof.* w ≔ z − Σ_j⟨z, u_j⟩u_j has ⟨w, u_i⟩ = ⟨z, u_i⟩ − ⟨z, u_i⟩ = 0. If w ≠ 0, then u₁, …, uₙ, w/‖w‖ is an orthonormal list of n + 1 vectors, contrary to `lem-orthonormal-at-most-n`. So w = 0.
4. **`cor-isometries-bijective`** `[Every Isometry of ℝⁿ Is a Bijection]`: "Every isometry f(x) = Ax + b of ℝⁿ is a bijection; its inverse is the isometry z ↦ (⟨z − b, a₁⟩, …, ⟨z − b, aₙ⟩)." *Proof.* For z ∈ ℝⁿ, x ≔ (⟨z − b, a_j⟩)_j satisfies Ax = Σ_j ⟨z − b, a_j⟩a_j = z − b by `prp-orthonormal-expansion`; so f(x) = z, f is onto; injective by `prp-isometry-composition` (b); the formula is the inverse; it is an isometry by `prp-isometry-composition` (c). Hook paid (one sentence): the answer to Section 4.4's question is yes, inside ℝⁿ. Also: in `cor-isometry-convex-image`, "⊆" is now "=" for balls and spheres (one line: f is onto and f⁻¹ is an isometry).
5. **`cor-rows-orthonormal`** `[The Rows Are Orthonormal Too]`: "If a₁, …, aₙ ∈ ℝⁿ is orthonormal, then so are the rows r_i ≔ (a_{i1}, …, a_{in}) of A." *Proof.* The inverse h(z) = (⟨z, a₁⟩, …, ⟨z, aₙ⟩) of x ↦ Ax is an isometry fixing 0, so by `thm-isometries-of-rn` its columns h(e_i) = (⟨e_i, a_j⟩)_j = (a_{ij})_j = r_i form an orthonormal list. Aftermath: in linear algebra this is "AᵀA = I implies AAᵀ = I"; here it fell out of the geometry (prose pointer, no label).
6. **Quick check.** "Check `cor-rows-orthonormal` for the columns (3/5, 4/5), (−4/5, 3/5)." *Solution:* rows (3/5, −4/5), (4/5, 3/5): norms 1, inner product 12/25 − 12/25 = 0.

### 5.6 Section 4.6: Isometries of the Line and the Plane (`06-isometries-of-the-line-and-plane.md`)

**Budget** ≤ 5,000 (expected ~3,600). Application section (terse proofs; no method box; no B4). Three Quick checks. R1–R4.

**Opening (~100).** Section 4.5 described every isometry of ℝⁿ by an orthonormal list. For n = 1 and n = 2 the lists can be written down, and every isometry can be named.

**`## The line` (~300).**
1. **`prp-isometries-of-line`** `[Isometries of ℝ]`: "The isometries of ℝ are exactly x ↦ x + b and x ↦ −x + b, b ∈ ℝ." *Proof.* `thm-isometries-of-rn` with n = 1: a₁ ∈ ℝ with a₁² = 1, so (a₁ − 1)(a₁ + 1) = 0 and a₁ = ±1 (`@fd3:prp-ordered-ring-rules` (f)).

**`## The plane` (~1,600).**
1. **`lem-unit-orthogonal-plane`** `[Unit Vectors Orthogonal to a Unit Vector of ℝ²]`: "Let a² + b² = 1. The vectors (c, d) with c² + d² = 1 and ac + bd = 0 are exactly (−b, a) and (b, −a)." *Proof.* (a, b), (−b, a) is an orthonormal list; by `prp-orthonormal-expansion`, (c, d) = (ac + bd)(a, b) + (ad − bc)(−b, a) = (ad − bc)(−b, a), and norm 1 forces (ad − bc)² = 1, so ad − bc = ±1. Both candidates work.
2. **`def-direct-opposite`** `[Rotations About 0, Reflections Through 0; Direct and Opposite Isometries]`: for a² + b² = 1, R_{a,b}(x, y) ≔ (ax − by, bx + ay) and S_{a,b}(x, y) ≔ (ax + by, bx − ay). An isometry of ℝ² is **direct** if it is τ_w ∘ R_{a,b} and **opposite** if it is τ_w ∘ S_{a,b}. One sentence: R_{a,b} is called a **rotation about 0**; Chapter 6 attaches to it an angle θ with (a, b) = (cos θ, sin θ).
3. **`thm-isometries-of-plane`** `[The Isometries of the Plane]` (terse, from the two results above): "Every isometry of ℝ² is either direct or opposite, not both, and the data a, b, w are determined by f." *Proof.* `thm-isometries-of-rn`: a₁ = (a, b) with a² + b² = 1; by `lem-unit-orthogonal-plane`, a₂ = (−b, a) (direct) or (b, −a) (opposite). Not both: (−b, a) = (b, −a) would give a = b = 0. Uniqueness from `thm-isometries-of-rn`. One line: the number a₁₁a₂₂ − a₁₂a₂₁ is 1 for direct and −1 for opposite (Looking-ahead sentence: the linear algebra volumes call it the determinant).
4. **`prp-opposite-is-reflection`** `[An Opposite Isometry Fixing 0 Is a Reflection]`: "S_{1,0} is the reflection in the x-axis, and if (a, b) ≠ (1, 0), S_{a,b} is the reflection ρ_{n,0} with n = (a − 1, b)." *Proof.* S_{1,0}(x, y) = (x, −y) = ρ_{(0,1),0}. Otherwise ‖n‖² = 2(1 − a) > 0 (a ≠ 1, since a = 1 forces b = 0); first coordinate of ρ_{n,0}(x, y): x − ((a − 1)x + by)(a − 1)/(1 − a) = ax + by; second: y − b((a − 1)x + by)/(1 − a) = bx + y − b²y/(1 − a) = bx − ay, using b² = (1 − a)(1 + a). Sidecar checks.
5. **`prp-direct-fixed-point`** `[A Direct Isometry Other Than a Translation Fixes Exactly One Point]`: "If f = τ_w ∘ R_{a,b} with (a, b) ≠ (1, 0), then f has exactly one fixed point z, and f(x) = R_{a,b}(x − z) + z for all x: f is the **rotation about z**." *Proof.* f(x, y) = (x, y) is the system (1 − a)x + by = w₁, −bx + (1 − a)y = w₂, with D ≔ (1 − a)² + b² = 2(1 − a) > 0; unique solution z = (((1 − a)w₁ − bw₂)/D, (bw₁ + (1 − a)w₂)/D) (substitution and elimination, as in §01 B2). Then f(x) − z = f(x) − f(z) = R_{a,b}(x − z) by linearity of R_{a,b}.
6. **Remark** `**The four kinds.**` A table: direct with (a, b) = (1, 0): translation (no fixed point unless w = 0); direct otherwise: rotation about a point (one fixed point); opposite: reflection in a line (a line of fixed points) or glide reflection (no fixed point), the dichotomy proved in C1. In prose: Chapter 6 rewrites R_{a,b} as z ↦ (a + bi)z and S_{a,b} as z ↦ (a + bi)z̄.
7. **`exm-plane-composites`** `[Composites]`: S_{a,b} ∘ S_{c,d} = R_{ac+bd, bc−ad}, R_{a,b} ∘ R_{c,d} = R_{ac−bd, ad+bc}, and R_{a,b} = S_{a,b} ∘ S_{1,0}. Two shown in full; the third is B1. (Sidecar checks all three.)
8. **Quick check.** "Classify f(x, y) = ((3x − 4y)/5 + 1, (4x + 3y)/5)." *Solution:* direct, (a, b) = (3/5, 4/5), w = (1, 0); D = 4/5, fixed point z = ((2/5)/(4/5), (4/5)/(4/5)) = (1/2, 1); check f(1/2, 1) = (1/2, 1). A rotation about (1/2, 1).
9. **Quick check.** "Which isometry is (x, y) ↦ (y, x)?" *Solution:* S_{0,1}, the reflection ρ_{(−1,1),0} in the line y = x.
