# The Axiom of Choice

Some objects are built one piece at a time. A union of countably many countable sets is listed by listing each set, and listing each set means picking a list for each of infinitely many sets, with no rule to say which. An injection, a set of representatives and a total order are built the same way: one pair, one class, one comparison at a time. When the pieces can be counted off, induction finishes the job, one step for each natural number. When they cannot, the words "and so on" stand in for a step that is never given, and that is not a proof. *Is it enough to say "choose one from each"?*

The chapter answers in three moves. Section 6.1 states the principle that allows infinitely many arbitrary choices at once, the **axiom of choice**, shows what is and is not a choice (a choice made by a rule needs no axiom), and uses it to give every surjection a right inverse, every countable union of countable sets a listing, and every infinite set a copy of \( \nN \). Section 6.2 states Zorn's lemma (a non-empty partially ordered set in which every non-empty chain has an upper bound has a maximal element) and turns it into a single method, the maximality template: if every growing chain of partial objects has a partial object above it and every unfinished one can be enlarged, then a complete one exists. It runs the template to extend every partial order to a total one. Section 6.3 proves that Zorn's lemma gives the axiom of choice, settles the question Section 4.4 left open (any two sets are comparable in size), and proves the well-ordering theorem. The lemma itself is not proved here: it is equivalent to the axiom, and this volume proves only the half that gives choice.

## Roadmap

- **The axiom of choice.** A union of countably many lists and the choice it hides; the axiom of choice and its statement; when no axiom is needed, because a rule picks the element (a finite number of choices, a least element, a formula); a right inverse for every surjection; surjections as a way of comparing sizes; countable unions of countable sets; every infinite set contains a copy of \( \nN \), so \( \nN \) is the smallest infinite size; and an infinite set is equinumerous with a proper part of itself.
- **Zorn's lemma and how to use it.** A pair-by-pair matching that cannot finish; chains in a partially ordered set, and why finitely many elements of the union of a chain of sets lie in one member; Zorn's lemma, why each hypothesis is needed, and why it is stated and not proved; the maximality template, which gives a set of representatives for any equivalence relation; and extending a partial order to a total order, one added comparison at a time.
- **Equivalent forms of choice.** Zorn's lemma gives the axiom of choice; any two sets are comparable, so sizes satisfy trichotomy; every set can be well-ordered, and a well-ordered set has a choice function; and a table of which implications this volume proves and which *Axiomatic Set Theory* proves.

## Named moves

- **Name the choice** (@exm-method-name-the-choice). Before using the axiom, look for the rule: one choice needs no axiom, finitely many are made one at a time, and a least element or a formula picks without help. If there is no rule, say that the axiom is used and where. (Section 6.1)
- **The maximality template** (@exm-method-maximality). Partial objects ordered by extension; the union of a chain is again a partial object, since each defining condition mentions finitely many elements and these lie in one member of the chain (@lem-chain-union); Zorn's lemma gives a maximal one; a maximal one is complete, since a missing piece would give a strictly larger partial object. (Section 6.2, used again in Section 6.3)

## Threads

- **Right inverses.** Section 2.4 proved that a right inverse forces surjectivity and could not build one. Section 6.1 does (@thm-surjection-right-inverse), and shows that this statement is equivalent to the axiom of choice.
- **Choice.** Sections 4.2, 4.4 and 4.5 avoided the axiom by giving a rule each time: least preimages, a surjection built from an injection, a copy of \( \nN \) supplied in advance. Section 6.1 settles the three cases where no rule exists. Section 6.3 derives the axiom from Zorn's lemma (@thm-choice-from-zorn) and from well-ordering (@prp-well-ordering-gives-choice), and *Axiomatic Set Theory*, Chapter 4 proves the converse.
- **Comparing sizes.** Section 4.4 asked whether any two sets are comparable. Section 6.2 opens with a pair-by-pair matching that does not finish, and Section 6.3 finishes it with Zorn's lemma (@thm-cardinal-comparability).
- **Well-ordering.** Section 3.1 proved that every non-empty set of natural numbers has a least element, and Section 5.3 named the sets with that property. Section 6.3 proves that every set can be given such an order (@thm-well-ordering-theorem).

## Summary

The axiom of choice (@ax-choice) gives a function that picks one element from each of a family of non-empty sets. It is equivalent to the statement that every surjection has a right inverse (@thm-surjection-right-inverse); it makes a countable union of countable sets countable (@thm-countable-union), so that \( \card{A} \le \card{B} \) exactly when there is a surjection \( B \to A \) (@prp-card-le-surjection); and it gives every infinite set a countably infinite subset (@thm-infinite-countable-subset), so that \( \nN \) is the smallest infinite size and an infinite set is equinumerous with a proper subset (@thm-infinite-iff-proper-subset). A choice made by a rule needs no axiom (@exm-method-name-the-choice).

A chain is a subset of a partially ordered set on which the order is total (@def-chain), and finitely many elements of the union of a chain of sets lie in one member (@lem-chain-union). Zorn's lemma (@thm-zorn): a non-empty partially ordered set in which every non-empty chain has an upper bound has a maximal element, usually one of many and not a greatest one. It is stated without proof; it implies the axiom of choice (@thm-choice-from-zorn), and the converse belongs to *Axiomatic Set Theory*, Chapter 4. The maximality template (@exm-method-maximality) gives a set of representatives for any equivalence relation (@exm-zorn-representatives), extends every partial order to a total order (@thm-order-extension), by adding one comparison at a time (@lem-one-step-order-extension), shows that any two sets are comparable in size (@thm-cardinal-comparability), so that exactly one of \( \card{A} < \card{B} \), \( \card{A} = \card{B} \), \( \card{B} < \card{A} \) holds (@cor-cardinal-trichotomy), and well-orders every set (@thm-well-ordering-theorem), which in turn gives choice (@prp-well-ordering-gives-choice).

Every object built in this chapter is shown to exist and none is written down: no formula is known for a set of representatives of \( \nR \) modulo \( \nQ \), for an injection between two arbitrary sets, for a well-order of \( \nR \), or for a total order containing \( \subseteq \) on \( \powerset{\nR} \). Where a formula exists, as for divisibility on \( \nN \) (@exm-divisibility-linear-extension), it is the better proof.

## Terms

- **axiom of choice**: for every family of non-empty sets indexed by a set \( I \), there is a function that picks an element of each (@ax-choice).
- **chain**: a subset in which any two elements are comparable (@def-chain).
- **choice function**: a function \( c \) on the index set with \( c(i) \in A_i \) for every \( i \) (@ax-choice).
- **linear extension**: a total order containing a given partial order; "linear order" is a synonym of "total order" (@thm-order-extension).
- **maximality template**: partial objects, unions of chains, Zorn's lemma, completeness of a maximal object (@exm-method-maximality).
- **partial choice function**: a set of pairs \( (i, x) \) with \( x \in A_i \), at most one for each index (@thm-choice-from-zorn).
- **partial matching**: a relation \( G \subseteq A \times B \) in which each element of \( A \) and of \( B \) occurs in at most one pair (@thm-cardinal-comparability).
- **set of representatives**: a set meeting every equivalence class in exactly one element (@exm-zorn-representatives).
- **well-order**: a total order in which every non-empty subset has a least element (@def-well-ordered-set).
- **Zorn's lemma**: a non-empty partially ordered set in which every non-empty chain has an upper bound has a maximal element (@thm-zorn).
