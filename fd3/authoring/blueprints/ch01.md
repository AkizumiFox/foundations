## index.md

- **Story.** fd2 took ℕ as a set inside the familiar real line and induction as its defining property. To build ℝ (F3.10) without circularity we need ℕ from somewhere else. Start with sets only: the empty set, and a way to go "one further", x ↦ x ∪ {x}. Then 0 = ∅, 1 = {0}, 2 = {0, 1}, … — each number *is* the set of numbers before it. Then everything fd1–fd2 assumed about ℕ becomes a theorem, and a final theorem says that any other "ℕ" is a relabelling of this one.

## 01-sets-from-axioms.md — Axioms for Sets

- **Hook.** fd2 Chapter 6 listed working rules (W1)–(W6) and showed that "every property defines a set" is contradictory (`@thm-russell`, recalled). Which rules are basic, and can they produce pairs, functions and numbers, not just take them as given? In this chapter **every object is a set**.
- **`ax-zf-fragment`** (full explain template; slogan *a few ways to make sets, and one way to tell them apart*). The clauses, each with one line on what it licenses:
  - (Z1) **Extensionality**: sets with the same elements are equal (fd2's `@def-set-equality`, now an axiom);
  - (Z2) **Empty set**: there is a set with no elements;
  - (Z3) **Pairing**: for all a, b there is a set whose elements are exactly a and b;
  - (Z4) **Union**: for every set 𝒮 there is a set whose elements are exactly the elements of members of 𝒮;
  - (Z5) **Power set**: for every set X there is a set whose elements are exactly the subsets of X;
  - (Z6) **Separation**: for every set A and every property P(x) (a formula of fd1's first-order language with ∈ and =, `@def-first-order-formula`, other variables allowed as parameters) there is a set whose elements are exactly the x ∈ A with P(x) (fd2's `@def-set-builder`, now an axiom).
  - Prose: (Z7) Infinity comes in §03, once there is something to iterate. Replacement and Foundation are not needed for ω and are left to the set-theory volume (ST, which revisits this chapter); Choice is `@ax-choice` (fd2 Chapter 8) and is not used here. No metamathematics: we do not ask whether the axioms are consistent or independent.
- **`prp-zf-basic-sets`**: (a) there is exactly one set with no elements, ∅; (b) for all a, b, the set of (Z3) is unique, written {a, b}, and {a} ≔ {a, a}; (c) for every set 𝒮 the set of (Z4) is unique, written ⋃𝒮, and A ∪ B ≔ ⋃{A, B}; A ∩ B and A ∖ B exist by (Z6) inside A; for a non-empty 𝒮, ⋂𝒮 ≔ {x ∈ A₀ : x ∈ S for every S ∈ 𝒮} for any A₀ ∈ 𝒮, and it does not depend on A₀; (d) {a, b} = {c, d} iff (a = c and b = d) or (a = d and b = c); in particular {a} = {c, d} iff a = c = d. Proof: existence from the axiom named, uniqueness by (Z1) each time (as in `@prp-empty-set-unique`); (d) by comparing elements, two cases. (d) is needed in §02; prove it in full.
- **Warning.** (Z3) gives an **unordered** pair: {a, b} = {b, a}. And (Z6) needs the ambient set A: dropping it is the rule `@thm-russell` refutes.
- **Check.** ⋃∅ = ? ⋃{∅} = ? ⋃{{∅}, {∅, {∅}}} = ? (∅; ∅; {∅, {∅}}.)

## 02-pairs-as-sets.md — Ordered Pairs Built from Sets

- **Hook.** fd2's `@def-ordered-pair` postulated an object (a, b) with the characteristic property and promised it could be built from sets. {a, b} forgets order. Fix: mark the first coordinate by putting it in a set of its own.
- **`def-kuratowski-pair`:** (a, b) ≔ {{a}, {a, b}}, a set by (Z3) three times. Slogan: *the first coordinate is the one in every member*.
- **`thm-kuratowski-pair`** (key proof; Try it first; Before reading on: "where is a ≠ b used?"). For all a, b, c, d: (a, b) = (c, d) iff a = c and b = d. Proof: ⇐ by substitution. ⇒, case a = b: (a, b) = {{a}}, so {c} = {a} and {c, d} = {a}, hence c = d = a (`prp-zf-basic-sets` (d)). Case a ≠ b: if c = d, the symmetric argument gives a = b, so c ≠ d. {a} ∈ (c, d), so {a} = {c} or {a} = {c, d}; the second gives c = d, excluded; so a = c. Then {a, b} is the member of (a, b) other than {a} (they differ, since b ∉ {a}), and likewise {c, d} for (c, d); so {a, b} = {a, d}, hence b = d (`prp-zf-basic-sets` (d) with c = a; both disjuncts give b = d). **Alternatively** (one paragraph): ⋂(a, b) = {a} and ⋃(a, b) = {a, b}, so a is read off as the element of ⋂p, and b as the element of ⋃p ∖ ⋂p if that set is non-empty, otherwise b = a.
- **Payment remark.** From here, (a, b) in fd2's `@def-ordered-pair` *is* this set; fd2 Chapters 6–8 used nothing about pairs but the characteristic property, so all of it stands. A relation is a subset of A × B, and fd2's function is the pair (G, Y) of `@def-function`: both are now sets.
- **`exm-failed-pair-encodings`** (false conclusion: "any set built from a and b that mentions a first is an ordered pair"): (i) {a, b}: (∅, {∅}) and ({∅}, ∅) coincide; (ii) {{a}, {b}}: the same failure; (iii) {a, {b}}: with a = {{∅}}, b = ∅, c = {∅}, d = {∅}, both give {{{∅}}, {∅}} although a ≠ c. Prose: Wiener's {{{a}, ∅}, {{b}}} works (C3). Sidecar checks (iii) with frozensets.
- **`prp-cartesian-product-exists`:** for sets A and B there is exactly one set A × B whose elements are exactly the pairs (a, b) with a ∈ A, b ∈ B. Proof: {a} and {a, b} are subsets of A ∪ B, so (a, b) ⊆ 𝒫(A ∪ B), i.e. (a, b) ∈ 𝒫(𝒫(A ∪ B)); take A × B ≔ {p ∈ 𝒫(𝒫(A ∪ B)) : p = (a, b) for some a ∈ A, b ∈ B} by (Z6), (Z5), (Z4); unique by (Z1).

## 04-peano-properties.md — ω Satisfies Peano's Axioms

- **`def-transitive-set`:** x is **transitive** if every element of x is a subset of x (y ∈ x ⇒ y ⊆ x). Warning-sized remark: {{∅}} is not transitive.
- **`lem-omega-transitive`:** (a) every n ∈ ω is a transitive set; (b) ω is transitive: every element of a natural number is a natural number; (c) n ∉ n for every n ∈ ω; (d) every n ∈ ω with n ≠ 0 is S(k) for some k ∈ ω; (e) 0 ∈ n for every n ∈ ω with n ≠ 0. Each by `thm-omega-induction` (b). (a): ∅ is transitive; if n is, then y ∈ S(n) means y ∈ n (so y ⊆ n ⊆ S(n)) or y = n (so y ⊆ S(n)). (b): P(n) ≔ n ⊆ ω; S(n) = n ∪ {n} ⊆ ω. (c) (Before reading on: "why does S(n) ∈ n give n ∈ n?"): if S(n) ∈ S(n), then S(n) ∈ n, so S(n) ⊆ n by (a) and n ∈ n; or S(n) = n, so n ∈ S(n) = n. (d), (e): direct inductions on "n = 0 or …".
- **`thm-omega-peano`:** (P1) 0 ∈ ω; (P2) n ∈ ω ⇒ S(n) ∈ ω; (P3) S(n) ≠ 0 for every n ∈ ω; (P4) for m, n ∈ ω, S(m) = S(n) ⇒ m = n; (P5) `thm-omega-induction` (a). So n ↦ S(n) is a function ω → ω (its graph is a set by (Z6) inside ω × ω, `prp-cartesian-product-exists`). Proof of (P3): n ∈ S(n). (P4): m ∈ S(n), so m ∈ n or m = n; likewise n ∈ m or n = m; if m ≠ n, then m ∈ n and n ∈ m, so n ⊆ m by (a), and m ∈ m, contradicting (c); so m = n (RAA, `@def-rule-raa`). The k in `lem-omega-transitive` (d) is unique by (P4).
- **`def-peano-system`:** a triple (M, e, s) of a set M, an element e ∈ M and a function s : M → M with (P3) s(x) ≠ e for every x ∈ M, (P4) s injective, (P5) every A ⊆ M with e ∈ A and s(x) ∈ A for every x ∈ A equals M. By `thm-omega-peano`, (ω, 0, S) is one.

  - M = {0, 1}, e = 0, s(0) = s(1) = 1: fails (P4) only.

Read (n, 1) as "n" and (k, 2) as "−(k + 1)": the second and third layers form one chain infinite in both directions. (P3), (P4) hold (check by second coordinates; `thm-kuratowski-pair`); (P5) fails: ω × {0} contains e, is closed, and misses (0, 1).
  Sidecar: the two finite structures exhaustively; the third on ω restricted to n < 6.

## 05-recursion-and-arithmetic.md — The Recursion Theorem on ω; Addition and Multiplication

- **Hook.** fd2's `@thm-recursion` was proved for the school ℕ. Its proof used only induction and a few facts about {0, …, n}; on ω, {0, …, n} is simply S(n) (proved in §06). The proof here uses only S(n) as a set and its transitivity; unlike fd2's Step 3, no comparison of indices is needed, since the order on ω comes in §06.
- **`thm-omega-recursion`** (key proof; Before reading on: "where is S(n) ∉ S(n) used?"). Let X be a set, a ∈ X, and g : ω × X → X a function. Then there is exactly one function f : ω → X with f(0) = a and f(S(n)) = g(n, f(n)) for every n ∈ ω. (fd2's statement word for word, with ℕ ≔ ω.) Proof: fd2's three steps with {0, …, n} replaced by S(n) (pointing back to the proof of `@thm-recursion`), with **one departure** in the glue step (below). A **partial solution up to n** is a function h : S(n) → X with h(0) = a and h(S(k)) = g(k, h(k)) for every k with S(k) ∈ S(n). Facts used, each cited: 0 ∈ S(n) (`lem-omega-transitive` (e) and (P3)); S(k) ∈ S(n) ⇒ k ∈ S(n) (k ∈ S(k), and S(n) is transitive, `lem-omega-transitive` (a)); k ∈ S(m) ⇒ S(k) ⊆ S(m) (k ⊆ S(m) since S(m) is transitive, `lem-omega-transitive` (a), and k ∈ S(m)); S(S(n)) = S(n) ∪ {S(n)} (definition); S(n) ∉ S(n) (`lem-omega-transitive` (c)), so adding the pair (S(n), g(n, h(n))) keeps a function; the new input S(n) is the successor of n only ((P4)), so the equation at S(n) asks for g(n, h(n)) and for nothing else; base: S(0) = {0} and no k has S(k) ∈ {0}, by (P3). **Restriction:** if h is a partial solution up to m and k ∈ S(m), then h restricted to S(k) (⊆ S(m) by the fact above) is a partial solution up to k: 0 ∈ S(k), and S(j) ∈ S(k) gives S(j) ∈ S(m) and j ∈ S(k), so the equation at S(j) is one of h's. **Claim** (induction on n, `thm-omega-induction`): for each n ∈ ω there is exactly one partial solution f_n up to n (existence by adding the pair at S(n); uniqueness because the restriction to S(n) of a partial solution up to S(n) is one up to n, and the value at S(n) is forced). **Glue:** 𝒮 ≔ the set of graphs of partial solutions up to some n, a subset of 𝒫(ω × X) ((Z5), (Z6)); its elements are exactly the graphs G_n of the f_n; F ≔ ⋃𝒮 ((Z4)). (Fn1): (n, f_n(n)) ∈ G_n ⊆ F. (Fn2) **without comparing indices** (§06 is not yet available, so fd2's split "m ≤ n or n < m" cannot be used): if (k, y) ∈ G_m and (k, y′) ∈ G_n, then k ∈ S(m) ∩ S(n), so S(k) ⊆ S(m) and S(k) ⊆ S(n); the restrictions of f_m and f_n to S(k) are both partial solutions up to k (Restriction), so they are equal by the Claim's uniqueness, and y = f_m(k) = f_n(k) = y′. This is the one departure from fd2's route, which compared m and n (trichotomy and S(m) ⊆ S(n) for m ≤ n, i.e. `thm-omega-order` (a), (c), proved only in §06). So f ≔ (F, X) is a function ω → X, and f(k) = f_m(k) whenever k ∈ S(m) (by (Fn2), since (k, f_m(k)) ∈ F). Existence: f(0) = f_0(0) = a; f(S(n)) is read off G_{S(n)}: f(S(n)) = f_{S(n)}(S(n)) = g(n, f_{S(n)}(n)) = g(n, f(n)), since n ∈ S(S(n)) and S(n) ∈ S(S(n)). Uniqueness by `thm-omega-induction` (two solutions agree at 0 and, if at n, then at S(n)). No choice: each partial solution is unique.
- **`def-omega-arithmetic`:** (a) for each m ∈ ω, `thm-omega-recursion` with X = ω, a = m, g(n, x) = S(x) gives a unique A_m; m + n ≔ A_m(n); the graph of + : ω × ω → ω is a set by (Z6). So m + 0 = m and m + S(n) = S(m + n). (b) likewise m · 0 = 0 and m · S(n) = m · n + m (a = 0, g(n, x) = x + m). (c) Numerals 1 ≔ S(0), 2 ≔ S(1), …, and n + 1 = S(n) for every n (n + S(0) = S(n + 0) = S(n)); so the recursive equations read m + 0 = m, m + (n + 1) = (m + n) + 1, m · (n + 1) = m · n + m. Consequences used later: 1 + 1 = 2, and k + 2 = k + S(1) = (k + 1) + 1.
- **`cor-omega-successor-cancellation`:** for k, l ∈ ω: k + 1 = l + 1 ⇒ k = l, and k + 1 ≠ 0. ((P4), (P3) with (c).)

## 06-order-on-omega.md — Order and Well-Ordering on ω

- **`def-omega-order`:** for m, n ∈ ω, m < n iff m ∈ n; m ≤ n iff m < n or m = n; > and ≥ as usual.
- **`thm-omega-order`:** (a) < is a strict total order on ω: never n < n; k < m and m < n give k < n; for all m, n exactly one of m < n, m = n, n < m; (b) m < S(n) iff m ≤ n; hence no k ∈ ω has n < k < S(n); (c) n = {m ∈ ω : m < n}; so fd2's {0, …, n} ≔ {k ∈ ω : k ≤ n} is S(n); (d) 0 ≤ n for every n; if n ≠ 0 then 1 ≤ n; and 0 < 1; (e) fd2's {1, …, n} ≔ {k ∈ ω : 1 ≤ k ≤ n} is S(n) ∖ {0}. Proof: irreflexive by `lem-omega-transitive` (c); transitive by (a) of that lemma. Trichotomy, "at least one", by `thm-omega-induction` on n for "for every m: m ∈ n, m = n or n ∈ m", with the **Claim** "m ∈ n ⇒ S(m) ∈ S(n)" (induction on n). Base: 0 = m or 0 ∈ m (`lem-omega-transitive` (e)). Step: if m ∈ n or m = n, then m ∈ S(n); if n ∈ m, the Claim gives S(n) ∈ S(m), so S(n) ∈ m or S(n) = m. "At most one": m ∈ n with m = n, or with n ∈ m, gives m ∈ m. (b) is the definition of S(n) plus irreflexivity and transitivity. (c): ⊇ by definition, ⊆ by `lem-omega-transitive` (b); with (b), {k ∈ ω : k ≤ n} = S(n). (d): `lem-omega-transitive` (e) and (d), then the Claim (0 ≤ k gives 1 = S(0) ≤ S(k)). (e): k ∈ S(n) with k ≠ 0 gives 1 ≤ k by (d) and k ≤ n by (b); conversely 1 ≤ k ≤ n gives k ∈ S(n) by (b), and k ≠ 0 since 1 ≤ 0 is impossible (1 ∉ 0 = ∅, and 1 ≠ 0 by (P3)).
- **Warning (false conclusion).** On arbitrary sets ∈ is not transitive: ∅ ∈ {∅} ∈ {{∅}}, but ∅ ∉ {{∅}}. Transitivity of < is a theorem about ω.
- **`thm-omega-well-ordering`:** every non-empty A ⊆ ω has a least element (an a ∈ A with a ≤ x for every x ∈ A), and it is unique. Proof: suppose A has none. B ≔ {n ∈ ω : n ∩ A = ∅}. 0 ∈ B. If n ∈ B, then S(n) ∩ A = {n} ∩ A; if n ∈ A, then n would be least (no element of A is < n, so all are ≥ n by trichotomy); so S(n) ∈ B. By `thm-omega-induction`, B = ω; but for a ∈ A, a ∈ S(a) ∩ A. Contradiction (RAA: the goal is existential, `@def-rule-raa`). Uniqueness by trichotomy. Compare in prose with fd2's `@thm-well-ordering` (derived there from `@ax-induction`; here from `thm-omega-induction`).
- **`prp-omega-order-arithmetic`:** for k, m, n, b ∈ ω: (a) m ≤ n iff n = m + j for some j ∈ ω, and then j is unique (written n − m); m < n iff such a j is ≠ 0; (b) m + k = n + k ⇒ m = n; (c) m < n ⇒ m + k < n + k; (d) mn = 0 ⇒ m = 0 or n = 0; (e) m < n and k ≠ 0 ⇒ mk < nk; (f) mk = nk and k ≠ 0 ⇒ m = n; (g) (induction started at b) if P(b) and, for every n ≥ b, P(n) implies P(n + 1), then P(n) for every n ≥ b. Proof: (b) by induction on k with (P4) (needs no order; uses only `cor-omega-successor-cancellation`). (a) ⇐ by induction on j (m ≤ m + j < S(m + j) = m + S(j)); ⇒ by induction on n for "every m ≤ n has a j" (base: m ≤ 0 forces m = 0, since nothing is ∈ ∅; step: m ≤ S(n) means m = S(n), j = 0, or m ≤ n by `thm-omega-order` (b), and n = m + j gives S(n) = m + S(j)); uniqueness by (b) and `thm-omega-arithmetic-laws` (b); j = 0 iff n = m. (c): n = m + j, j ≠ 0, so n + k = (m + k) + j (laws (b), (c)). (d): if n = S(j), mn = mj + m, and x + y = 0 forces y = 0 (y = S(y′) would give S(x + y′) = 0, (P3)). (e): nk = mk + jk with jk ≠ 0 by (d). (f) by trichotomy and (e). (g): fd1's "induction started at b", run on ω: Q(i) ≔ P(b + i), and every n ≥ b is b + i by (a).
- **`prp-omega-powers-parity`** (for the §07 citing rule: the ω-versions of the power and parity facts that fd2's countability proofs take from the school ℝ and ℤ). For b ∈ ω, define b^n (n ∈ ω) by `thm-omega-recursion` with X = ω, a = 1, g(n, x) = x · b, so b^0 = 1 and b^{n+1} = b^n · b. Then for b, m, n ∈ ω: (a) b^{m+n} = b^m · b^n; (b) b ≠ 0 ⇒ b^n ≠ 0; (c) b > 1 and m < n ⇒ b^m < b^n; (d) every n ∈ ω is 2q + r with q ∈ ω and r ∈ {0, 1} for exactly one pair (q, r); in particular no n is both 2q and 2q′ + 1. Proof: (a) induction on n, m fixed: b^{m+0} = b^m = b^m · 1; b^{m+S(n)} = b^{S(m+n)} = b^{m+n} · b = (b^m b^n) b = b^m (b^n b) (`thm-omega-arithmetic-laws` (c), (e), (g)). (b) induction on n with `prp-omega-order-arithmetic` (d). (c) first b^j > 1 for j ≥ 1 by `prp-omega-order-arithmetic` (g) with base 1: b^1 = 1 · b = b > 1; b^{j+1} = b^j · b > 1 · b = b > 1 by (e) of that proposition (with b ≠ 0) and `thm-omega-order` (a); then n = m + j with j ≠ 0 (`prp-omega-order-arithmetic` (a)), j ≥ 1 (`thm-omega-order` (d)), and b^n = b^m b^j > b^m · 1 = b^m by (a), (b) and `prp-omega-order-arithmetic` (e). (d) existence by `thm-omega-induction` (b): 0 = 2 · 0 + 0; from n = 2q get S(n) = 2q + 1; from n = 2q + 1 get S(n) = 2q + (1 + 1) = 2q + 2 = 2(q + 1) + 0 (`def-omega-arithmetic` (c), laws (c), (d)). Uniqueness: if 2q + r = 2q′ + r′ with q < q′, write q′ = q + j with j ≠ 0 (`prp-omega-order-arithmetic` (a)); then 2q′ + r′ = 2q + (2j + r′) (`thm-omega-arithmetic-laws` (c), (d)), and cancelling 2q (`prp-omega-order-arithmetic` (b), with law (b)) gives r = 2j + r′. Write j = 1 + i (`prp-omega-order-arithmetic` (a), j ≥ 1 by `thm-omega-order` (d)); then 2j + r′ = 2 + (2i + r′) (`thm-omega-arithmetic-laws` (c), (d)), so r ≥ 2 by `prp-omega-order-arithmetic` (a). But r ∈ {0, 1} = S(1) gives r ≤ 1 < 2 (`thm-omega-order` (b)), which contradicts r ≥ 2 by trichotomy (`thm-omega-order` (a)); so q = q′ by trichotomy, and r = r′ by (b) of that proposition. F3.1 uses none of this; it is here so that the citing rule's clause (ii) is honest. F3.9's ℕ-powers (in its definition of n·1_F and powers, not cited here: F3.9 is later) are given by the same recursion data (X = ℕ = ω, a = 1, g(k, x) = x·n), so they are these powers by the uniqueness half of `thm-omega-recursion`.
- **`prp-tuples-as-sets`:** for n ∈ ω with n ≥ 2 and a set X: for n = 2 an n-tuple is the Kuratowski pair (x₁, x₂) and X² ≔ X × X; for n ≥ 3 an **n-tuple** (x₁, …, xₙ) in X is the graph {(1, x₁), …, (n, xₙ)} of a function {1, …, n} → X (the graph only, so that the tuple does not depend on X; {1, …, n} = S(n) ∖ {0} by `thm-omega-order` (e)). Then (a) Xⁿ, the set of n-tuples in X, is a set (n = 2: `prp-cartesian-product-exists`; n ≥ 3: (Z5), (Z6) inside 𝒫({1, …, n} × X)); (b) two n-tuples are equal iff they agree in every place (n = 2: `thm-kuratowski-pair`; n ≥ 3: `@prp-function-equality` on graphs); (c) for n ≥ 3 an n-tuple is not a Kuratowski pair (it contains the three elements (1, x₁), (2, x₂), (3, x₃), which are distinct by `thm-kuratowski-pair` since 1, 2, 3 are distinct elements of ω (`thm-omega-peano` (P3), (P4)); every element of a Kuratowski pair {{a}, {a, b}} is {a} or {a, b}, so a pair cannot contain three distinct elements; no counting: §§01–07 do not use fd2's finite-set notions), and tuples of different lengths n ≠ n′ ≥ 3 differ (different first coordinates); (d) (the second half of (W2)) for every n ∈ ω (n = 0, 1 allowed) and every function x : {1, …, n} → X, {x₁, …, xₙ} ≔ {y ∈ X : y = x_k for some k ∈ {1, …, n}}, the image of x (`@def-image`), is a set by (Z6) inside X; this is the form fd2's variable-n lists take (`@def-finite`, `@prp-finite-max`); (e) for n ≥ 3 no n-tuple is an element of ω (the argument of `prp-pair-not-natural`: the tuple contains (1, x₁), so it is non-empty, and ∅ is not one of its elements, since each element is a Kuratowski pair (k, x_k) and pairs are non-empty; every m ≠ 0 in ω contains 0 = ∅, `lem-omega-transitive` (e)). With `prp-pair-not-natural`, no n-tuple (n ≥ 2) is a number. Pays fd2's (W5) for n-tuples, the variable-n half of (W2), "a triple is not a pair" (Chapter 6 §03), and, with `prp-pair-not-natural`, "pairs and n-tuples are not numbers".

## 07-categoricity.md — All Peano Systems Are Alike; ω Is ℕ

- **Hook.** ω is one Peano system; (ω ∖ {0}, 1, S) is another (§04 C1); fd2's ℕ, if one grants it, is a third. Are they "the same"?
- **`thm-peano-categoricity`** (key proof; Try it first; Before reading on: "which axiom of M gives surjectivity, and which give injectivity?"). Let (M, e, s) be a Peano system. (a) There is exactly one φ : ω → M with φ(0) = e and φ(S(n)) = s(φ(n)) for every n ∈ ω; (b) φ is a bijection; (c) for any two Peano systems (M, e, s), (M′, e′, s′) there is exactly one bijection ψ : M → M′ with ψ(e) = e′ and ψ(s(x)) = s′(ψ(x)) for every x ∈ M. Proof: (a) `thm-omega-recursion` with X = M, a = e, g(n, x) = s(x). (b) Onto: φ's image (`@def-image`) contains e and is closed under s, so it is M by (P5) of M. One-to-one: `thm-omega-induction` on n for "for every m, φ(m) = φ(n) ⇒ m = n"; base: m ≠ 0 gives m = S(k) (`lem-omega-transitive` (d)) and φ(m) = s(φ(k)) ≠ e by (P3) of M; step: φ(m) = s(φ(n)) ≠ e forces m = S(k), then s(φ(k)) = s(φ(n)) gives φ(k) = φ(n) by (P4) of M, so k = n. (c) ψ ≔ φ′ ∘ φ⁻¹ (`@thm-bijection-iff-inverse`, `@def-composition`); if ψ is any such map, ψ ∘ φ satisfies (a) for M′, so ψ ∘ φ = φ′ and ψ = φ′ ∘ φ⁻¹. Name the move **build by recursion, compare by induction**. *Idea* from the Try-it-first obstacles: the map is forced at 0 and at each successor, so recursion builds it; onto is "the image is closed", one-to-one is (P3), (P4) of M.
- **`prp-isomorphism-preserves-arithmetic`:** let (M, e, s) be a Peano system with functions ⊕, ⊗ : M × M → M such that x ⊕ e = x, x ⊕ s(y) = s(x ⊕ y), x ⊗ e = e, x ⊗ s(y) = (x ⊗ y) ⊕ x for all x, y ∈ M, and let φ be as in `thm-peano-categoricity`. Then φ(m + n) = φ(m) ⊕ φ(n) and φ(mn) = φ(m) ⊗ φ(n) for all m, n ∈ ω (induction on n), and m < n iff φ(n) = φ(m) ⊕ z for some z ≠ e (`prp-omega-order-arithmetic` (a), with φ a bijection, `thm-peano-categoricity` (b), and φ(0) = e: for ⇒, j ≠ 0 gives φ(j) ≠ e; for ⇐, z = φ(j) with j ≠ 0 and φ(n) = φ(m + j) give n = m + j).
- **`cor-omega-identification`** (the identification; Before reading on: "which clause does fd3 actually use?"). (a) **About fd2's ℕ.** fd2's ℕ (Chapter 7 §01: ℕ ⊆ ℝ with (ℕ0), (ℕS) and `@ax-induction`), with e = 0 and s(n) = n + 1, is a Peano system: (P3) by `@lem-naturals-arithmetic` (a) (n + 1 ≥ 1 > 0), (P4) by school arithmetic, (P5) by the set form of `@ax-induction` (fd2 Chapter 7 §01, the remark at its start). Its + and · are functions ℕ × ℕ → ℕ (`@lem-naturals-arithmetic` (b)) satisfying the equations of `prp-isomorphism-preserves-arithmetic`, and m < n there iff n = m + z for some z ∈ ℕ with z ≠ 0 (⇒: z ≔ n − m ∈ ℕ by `@lem-naturals-arithmetic` (d), and z ≠ 0 since n ≠ m; ⇐: z ≥ 1 > 0 by `@lem-naturals-arithmetic` (a)). So there is exactly one bijection φ : ω → ℕ with φ(0) = 0 and φ(S(n)) = φ(n) + 1, and it preserves +, ·, <; φ sends each numeral of ω to the numeral of the same name.
