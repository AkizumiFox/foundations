**Signature moves** (`index.md`, "Named moves").
- **Least positive element, then divide.** Take the least positive element d of a set closed under integer combinations; divide any element by d; the remainder lies in the set and is smaller than d, so it is 0. (Faded triple.)
- **Multiply the Bézout identity.** From 1 = ax + by, multiply by c: c = acx + bcy, and read off what divides c.
- **Compute on representatives; the ideal absorbs the change.** An operation on classes a + I is well defined because the change of representative lies in I, and I absorbs multiplication (F3.2's "one argument at a time", now with an ideal).

## index.md

- **Story.** fd2 proved the division algorithm for the school integers and stopped short of unique factorization; F3.2 built new integers out of pairs. Everything about divisibility must now be proved again, for the built ℤ, from the ordered-ring axioms and one well-ordering lemma (`@prp-integer-least-element`). ## 01-division-with-remainder.md — Divisibility and Division with Remainder

- **Hook.** F3.2 showed 2x = 1 has no solution in ℤ. So "a/b" is not available in ℤ; what remains is the relation "b is a multiple of a", and the next best thing to division: a quotient and a remainder.
- **Divisibility, read on the constructed ℤ.** Restate `@def-divides` and `@def-prime` word for word, with ℤ now F3.2's ring; one sentence: they use only ·, ≤ and ℤ_{>0}.
- **`prp-divisibility-rules-integers`.** For a, b, c, x, y ∈ ℤ: (a) a | 0, 1 | a, a | a; and 0 | a ⇒ a = 0; (b) a | b and b | c ⇒ a | c; (c) a | b and a | c ⇒ a | bx + cy; (d) a | b ⇒ (−a) | b and a | (−b); (e) if a | b with a > 0 and b > 0, then a ≤ b; (f) for a, b ∈ ℕ: a | b and b | a ⇒ a = b; (g) a | 1 ⇒ a = 1 or a = −1; (h) for a ≠ 0, exactly one of a, −a lies in ℤ_{>0}. Proof: (a)–(d) from `@thm-integers-commutative-ring` and `@prp-ring-algebra` ((c): bx + cy = (kx + ly)a; (d): b = (−k)(−a) by `@prp-ring-algebra` (c)). (e): b = ka; k ≤ 0 would give ka ≤ 0 (k = 0: ka = 0 by `@prp-ring-algebra` (b); k < 0: ka < 0·a = 0 by `@prp-ordered-ring-rules` (c) and `@prp-ring-algebra` (b)), against b > 0; so k > 0, hence k ≥ 1 by discreteness (`@thm-integers-ordered-ring` (c)). If k = 1, b = a; if k ≥ 2, b − a = (k − 1)a > 0·a = 0 by `@prp-ordered-ring-rules` (c) and `@prp-ring-algebra` (b). (f): if a = 0 then b = 0 by (a), likewise if b = 0; else a ≤ b ≤ a by (e) (`@thm-integers-ordered-ring` (b): elements of ℕ ∖ {0} are positive), so a = b (`@prp-ordered-ring-rules` (i)). (g): a ≠ 0 by (a); by (h) and (d) some ±a > 0 divides 1, so ±a ≤ 1 by (e), and ±a ≥ 1 by discreteness. (h): trichotomy (O1) and `@prp-ordered-ring-rules` (a). One sentence: (f) is fd2's `@prp-divides-partial-order` (antisymmetry on ℕ), now on ℕ ⊆ ℤ; on ℤ it fails (2 | −2 | 2).
- **`thm-integers-division-remainder`.** Let a ∈ ℤ and n ∈ ℤ_{>0}. (a) There are **unique** q, r ∈ ℤ with a = qn + r and 0 ≤ r < n. (b) Moreover q = ⌊a/n⌋, the integer part of the rational a/n (`@prp-rational-integer-part`), so r = a − n⌊a/n⌋.
  - Proof of (a), existence: R ≔ {a − kn : k ∈ ℤ} ∩ {x ∈ ℤ : x ≥ 0}. Non-empty: if a ≥ 0 take k = 0; if a < 0 take k = a, since a − an = a(1 − n) and n ≥ 1 by discreteness (`@thm-integers-ordered-ring` (c)): if n = 1, then a − an = a·0 = 0 (`@prp-ring-algebra` (b)); if n ≥ 2, then 1 − n < 0, and a(1 − n) > 0·(1 − n) = 0 by `@prp-ordered-ring-rules` (d) and `@prp-ring-algebra` (b). R has the lower bound 0, so a least element r = a − qn (`@prp-integer-least-element`). If r ≥ n, then r − n = a − (q + 1)n ∈ R and r − n < r: contradiction. Uniqueness: from qn + r = q′n + r′ with, say, r′ < r: r − r′ = (q′ − q)n with 0 < r − r′ ≤ r < n; k ≔ q′ − q > 0 (k ≤ 0 gives kn ≤ 0: kn = 0 if k = 0, by `@prp-ring-algebra` (b), and kn < 0·n = 0 if k < 0, by `@prp-ordered-ring-rules` (c) and `@prp-ring-algebra` (b); as in `prp-divisibility-rules-integers` (e)), so k ≥ 1 and kn ≥ n (kn = n if k = 1; kn − n = (k − 1)n > 0·n = 0 if k ≥ 2, by the same two rules), contradiction. So r = r′, then (q − q′)n = 0 and q = q′ by `@prp-ordered-ring-rules` (f).
  - Proof of (b): from (a), qn ≤ a < qn + n in ℤ, hence in ℚ (`@prp-integers-embed-rationals`, `@thm-rationals-ordered-field`); multiply by n⁻¹ > 0 (`@prp-reciprocal-order`, `@prp-ordered-ring-rules` (c)): q ≤ a/n < q + 1; uniqueness in `@prp-rational-integer-part`.
  - Remark (the fd2 twin). The statement of (a) is fd2's `@thm-division-algorithm`, proved there for the school ℤ. The proof above is fd2's route with each school fact replaced by its fd3 label: closure of ℤ under +, −, · → `@thm-integers-commutative-ring`; "positive integer ⇒ ≥ 1" and discreteness → `@thm-integers-ordered-ring` (b), (c); well-ordering of integers bounded below → `@prp-integer-least-element`. For n = 2 and a ∈ ℕ, (a) is F3.1's `@prp-omega-powers-parity` (d) (compared with, not used). Name the atlas pair (see the table).
- **`cor-integers-even-odd`.** (a) Every a ∈ ℤ is 2q or 2q + 1 for exactly one q ∈ ℤ, and not both forms. (b) If a² is even, then a is even. Proof: (a) is the theorem with n = 2; (b): a = 2q + 1 gives a² = 2(2q² + 2q) + 1, odd by (a).
- **Remark (small primes on the constructed ℤ).** 2, 3, 5 and 7 are prime in F3.2's ℤ (`@def-prime`; fd2's check after `@def-prime` is about the school ℤ and is not cited). Each p ∈ {2, 3, 5, 7} satisfies p ≥ 2; a positive divisor d of p satisfies 1 ≤ d ≤ p (`prp-divisibility-rules-integers` (e); discreteness `@thm-integers-ordered-ring` (c)), so d ∈ {1, …, p} (discreteness again: m < n ⇒ m + 1 ≤ n). Each d with 1 < d < p leaves a non-zero remainder: 3 = 1·2 + 1; 5 = 2·2 + 1 = 1·3 + 2 = 1·4 + 1; 7 = 3·2 + 1 = 2·3 + 1 = 1·4 + 3 = 1·5 + 2 = 1·6 + 1. So d ∤ p, since p = kd + 0 would be a second division with remainder (uniqueness in `thm-integers-division-remainder` (a)). Hence the positive divisors of p are 1 and p. Cited below as "the small-primes remark" (§03 Check, A1 (b), B3; §04 B2; §05 C3; R2; the F3.4 promise).
- **Warning.** "The remainder" is the r with 0 ≤ r < n: −17 = (−3)·5 − 2 is true, but −2 is not the remainder; the remainder is 3, from −17 = (−4)·5 + 3. Allowing negative "remainders" destroys uniqueness (fd2's warning after `@thm-division-algorithm`, now for negative a).

## 02-gcd-and-bezout.md — The Greatest Common Divisor, Bézout, and the Euclidean Algorithm

- **Hook.** Which amounts can be paid exactly with 12-unit and 42-unit coins, giving change allowed? The set {12x + 42y} turns out to be all multiples of 6. Why 6, and why "all multiples"?
- **`def-integer-linear-combinations`:** for a, b, n ∈ ℤ: aℤ + bℤ ≔ {ax + by : x, y ∈ ℤ} and nℤ ≔ {kn : k ∈ ℤ}. Closed under +, −, and multiplication by any integer (one line each). nℤ = nℤ + 0ℤ.
- **`def-integer-gcd`:** d is a **common divisor** of a and b if d | a and d | b. For (a, b) ≠ (0, 0), gcd(a, b) is the greatest common divisor in ≤; it exists: the common divisors include 1, and are bounded above by a positive element c ∈ {a, −a, b, −b} (exists by `prp-divisibility-rules-integers` (h); every positive common divisor is ≤ c by (d), (e)), so `@prp-integer-least-element` (greatest element) applies; gcd(a, b) ≥ 1. Convention gcd(0, 0) ≔ 0 (every integer divides 0; the convention makes clause (c) of the theorem below, read with d replaced by gcd(a, b), hold for (0, 0) too, and matches fd2's `@exm-divisibility-lcm`, where 0 is the top of (ℕ, |)). gcd(a, b) = gcd(b, a) by definition.
- **`thm-integers-bezout`** (key proof; Try it first: "a = 12, b = 42: list the positive numbers 12x + 42y you can reach; which is least, and why should it divide 12? ten minutes"; Before reading on: "where is the minimality of d used, and where its positivity?"). Let a, b ∈ ℤ, not both 0, and S ≔ (aℤ + bℤ) ∩ ℤ_{>0}. (a) S has a least element d = ax₀ + by₀. (b) d | a and d | b. (c) Every common divisor of a and b divides d. (d) d = gcd(a, b); in particular gcd(a, b) = ax + by for some x, y ∈ ℤ. (e) aℤ + bℤ = dℤ.
  - Proof. (a) Say a ≠ 0; then a or −a = a·(−1) lies in S (`prp-divisibility-rules-integers` (h)); 1 is a lower bound, `@prp-integer-least-element`. (b) Divide a by d (`thm-integers-division-remainder`): a = qd + r, 0 ≤ r < d; r = a(1 − qx₀) + b(−qy₀) ∈ aℤ + bℤ; if r > 0, r ∈ S and r < d, contradicting minimality; so r = 0. Same for b. (c) `prp-divisibility-rules-integers` (c) with d = ax₀ + by₀. (d) d is a common divisor by (b); a common divisor c > 0 divides d by (c), so c ≤ d (`prp-divisibility-rules-integers` (e)); c ≤ 0 < d otherwise. (e) ⊇: kd = a(kx₀) + b(ky₀); ⊆: d | ax + by by (b) and `prp-divisibility-rules-integers` (c).
  - *Idea* (from the Try-it-first's obstacles): the obvious candidate "the largest common divisor" gives no formula ax + by; start instead from the combinations, take the smallest positive one, and show by division that it divides a and b.
  - Remark: (c) says gcd(a, b) is greatest also in the divisibility order: for a, b ∈ ℕ it is the infimum of {a, b} in (ℕ, |) (in general, of {a′, b′}, where a′ is the one of a, −a that lies in ℕ and likewise b′ (`prp-divisibility-rules-integers` (h); absolute values come only in F3.9): a and −a have the same divisors by (d), so gcd(a, b) = gcd(a′, b′)), the mirror of fd2's `@exm-divisibility-lcm` (supremum = lcm). With the convention, (c) and (e) hold for (0, 0) as well when d is read as gcd(0, 0) = 0: every integer divides 0, and 0ℤ + 0ℤ = {0} = 0ℤ.
- **`def-coprime-integers`:** a, b ∈ ℤ are **coprime** if gcd(a, b) = 1.
- **`cor-coprime-iff-combination`:** a and b are coprime iff ax + by = 1 for some x, y ∈ ℤ. (⇒ (d) of the theorem; ⇐: 1 ∈ aℤ + bℤ, so (a, b) ≠ (0, 0), and gcd(a, b) divides a and b, hence divides ax + by = 1 (`prp-divisibility-rules-integers` (c)), so gcd(a, b) = 1 by `prp-divisibility-rules-integers` (g) and gcd ≥ 1.)
- **`lem-gcd-remainder-step`:** if a ∈ ℤ, b ∈ ℤ_{>0} and a = qb + r with q, r ∈ ℤ, then aℤ + bℤ = bℤ + rℤ, hence gcd(a, b) = gcd(b, r). Proof: ax + by = b(qx + y) + rx and bx + ry = a·y + b(x − qy); the gcds agree by (a), (d), (e) of the theorem (both are the least positive element of the same set; (b, r) ≠ (0, 0) since b > 0).
- **`thm-euclidean-algorithm-integers`.** Let a ∈ ℤ and b ∈ ℤ_{>0}. Define (x_k, y_k) ∈ ℤ × ℕ for k ∈ ℕ by (x₀, y₀) ≔ (a, b) and (x_{k+1}, y_{k+1}) ≔ (y_k, r_k) if y_k > 0, where r_k is the remainder of x_k on division by y_k, and (x_{k+1}, y_{k+1}) ≔ (x_k, y_k) if y_k = 0. (A definition by `@thm-recursion` with X = ℤ × ℕ; the step is a function by the uniqueness in `thm-integers-division-remainder`.) Then: (a) x_kℤ + y_kℤ = aℤ + bℤ for every k ∈ ℕ; (b) there is a least K ∈ ℕ with y_K = 0; K ≥ 1, and y_{k+1} < y_k for k < K; (c) x_K = gcd(a, b).
  - Proof. (a) `@ax-induction` on k, base P(0) trivial; step by `lem-gcd-remainder-step` (or trivially if y_k = 0). (b) The set {y_k : k ∈ ℕ} ⊆ ℕ has a least element y_m (`@prp-integer-least-element`); if y_m > 0, then y_{m+1} = r_m < y_m, contradiction; so some y_k = 0, and K is the least such index (`@prp-integer-least-element` again). K ≠ 0 since y₀ = b > 0; for k < K, y_k > 0 and y_{k+1} = r_k < y_k. (c) x_K = y_{K−1} > 0, and by (a) aℤ + bℤ = x_Kℤ + 0ℤ = x_Kℤ, whose least positive element is x_K (k x_K ≥ x_K for k ≥ 1); by `thm-integers-bezout` (a), (d), gcd(a, b) = x_K.

## 03-unique-factorization.md — Euclid's Lemma and the Fundamental Theorem of Arithmetic

- **Hook.** 60 = 2·30 = 6·10 = 2·2·3·5. Every way of splitting 60 into factors as far as possible ends with the same primes. fd2 proved that every n ≥ 2 has a prime factor (school ℤ) and declined to prove that the full splitting is unique; this section proves both, on F3.2's ℤ. The key is a property of primes that "has no divisors" does not obviously give.
- **`thm-euclid-lemma-integers`.** Let a, b, c ∈ ℤ with a | bc and gcd(a, b) = 1. Then a | c. Proof (the move **multiply the Bézout identity**): 1 = ax + by (`cor-coprime-iff-combination`); c = acx + bcy; a | acx, and a | bcy since bc = ak; so a | c (`prp-divisibility-rules-integers` (c)).
- **`def-prime-factorization`.** A **list** of length k ∈ ℕ in ℤ is a function p : {1, …, k} → ℤ, written (p_1, …, p_k) (the empty list when k = 0). Its product ∏_{i=1}^{k} p_i is defined by the recursion of `@def-sum-product`, used as a pattern (F3.1's citing rule, group (iii)): its recursive clause and the proof of its "Finite lists" remark use only `@thm-recursion`, `@ax-induction` on ω and the multiplication of the target set, so they run unchanged with X = ℤ, an ordered commutative ring (F3.2); equivalently, read them in the ordered field ℚ ⊇ ℤ, as group (iii) allows, and note that ℤ is closed under · (`@prp-integers-embed-rationals`). The general-index part (`@prp-integers-closed`) is not used. Concretely, it is applied to the sequence p̄ that extends the list by p̄_i ≔ p_i for i ≤ k and p̄_i ≔ 1 for i > k: this is `@thm-recursion` with X = ℤ, initial value 1 and g(j, x) ≔ x·p̄_{j+1}, a function on all of ℕ × ℤ. By the "Finite lists" remark after `@def-sum-product`, the values P_j ≔ ∏_{i=1}^{j} p_i for j ≤ k do not depend on the extension. So P_0 = ∏_{i=1}^{0} p_i = 1, and P_{j+1} = ∏_{i=1}^{j+1} p_i = (∏_{i=1}^{j} p_i)·p_{j+1} for every j < k ("the recursion of `def-prime-factorization`"). A **prime factorization** of n ∈ ℤ_{>0} is a list of primes that is **non-decreasing** (i ≤ j ⇒ p_i ≤ p_j) with product n. The empty list is the prime factorization of 1.
- **`cor-prime-divides-product`.** Let p be prime (`@def-prime`). (a) For every a ∈ ℤ: p | a or gcd(p, a) = 1. (b) If p | bc, then p | b or p | c. (c) If (q_1, …, q_l) is a list of primes (`def-prime-factorization`; l ∈ ℕ) and p | ∏_{j=1}^{l} q_j, then p = q_j for some j. Proof: (a) g ≔ gcd(p, a) ≥ 1 divides p, so g ∈ {1, p} (`@def-prime`); g = p gives p | a. (b) by (a) and the lemma. (c) `@ax-induction` on l, base P(0): ∏^0 = 1 (the recursion of `def-prime-factorization`), and p | 1 would give p = ±1 (`prp-divisibility-rules-integers` (g)), but p ≥ 2; step: ∏_{j=1}^{l+1} q_j = (∏_{j=1}^{l} q_j)·q_{l+1} (the same recursion); by (b), p divides the first factor (then P(l)) or q_{l+1}, whose positive divisors are 1 and q_{l+1}, and p ≠ 1.
- **`prp-coprime-divisors-product`.** Let m, n, c ∈ ℤ with m | c, n | c and gcd(m, n) = 1. Then mn | c. Proof: c = mk; n | mk and gcd(n, m) = 1, so n | k (the lemma); k = nl, c = (mn)l.
- **`lem-least-divisor-prime`.** Let n ∈ ℤ with n ≥ 2. The set {d ∈ ℤ : d ≥ 2, d | n} has a least element, and it is prime; so n has a prime factor. Proof: n is in the set; lower bound 2; least element p (`@prp-integer-least-element`). If p were not prime, it would have a positive divisor e ∉ {1, p}; then 1 < e < p (`prp-divisibility-rules-integers` (e) and e ≥ 1), so e ≥ 2 by discreteness, and e | n (transitivity): contradiction. Remark: this is fd2's `@thm-prime-factor` on the constructed ℤ, by least counterexample instead of strong induction.
- **`thm-fundamental-arithmetic`** (key proof, uniqueness half; Before reading on: "why compare the **largest** primes p_k and q_l?"). Every n ∈ ℤ_{>0} has **exactly one** prime factorization.
  - Existence (least counterexample). Suppose the set of n ∈ ℤ_{>0} with no prime factorization is non-empty; let n be its least element (`@prp-integer-least-element`). n ≠ 1 (empty list), so n ≥ 2. The prime factors of n form a non-empty set (`lem-least-divisor-prime`) bounded above by n (`prp-divisibility-rules-integers` (e)); let p be the **largest** (`@prp-integer-least-element`, greatest element). n = pm with m ∈ ℤ_{>0} and m < n (n = pm ≥ 2m > m). By minimality m has a prime factorization (q_1, …, q_l). If l ≥ 1, then m = (∏_{j=1}^{l−1} q_j)·q_l by the recursion in `def-prime-factorization`, so q_l | m, hence q_l | n (transitivity, `prp-divisibility-rules-integers` (b)), so q_l ≤ p by the choice of p; since the list is non-decreasing, q_i ≤ q_l ≤ p for all i. (If l = 0 there is nothing to check.) Then (q_1, …, q_l, p) is non-decreasing (by q_l ≤ p when l ≥ 1; it is the one-entry list (p) when l = 0) with product (∏_{j=1}^{l} q_j)·p = mp = n by the recursion: contradiction.
  - Uniqueness. `@ax-induction` on k for P(k): "for every l ∈ ℕ, every two prime factorizations (p_1, …, p_k), (q_1, …, q_l) with equal products are equal (l = k, p_i = q_i)". Base P(0): ∏ q = 1; if l ≥ 1 then q_l | 1, impossible (`prp-divisibility-rules-integers` (g), q_l ≥ 2); so l = 0. Step: products equal and k + 1 ≥ 1, so l ≥ 1 (same argument with p_{k+1}). p_{k+1} | ∏ q, so p_{k+1} = q_j ≤ q_l (`cor-prime-divides-product` (c), non-decreasing); symmetrically q_l = p_i ≤ p_{k+1}. So p_{k+1} = q_l. Then (∏_{i=1}^{k} p_i)·p_{k+1} = (∏_{j=1}^{l−1} q_j)·p_{k+1}, and cancelling p_{k+1} ≠ 0 (`@prp-ordered-ring-rules` (f)) gives equal products of the shortened lists, which are prime factorizations; P(k) gives l − 1 = k and p_i = q_i for i ≤ k.
  - Answer to the prompt: the recursion peels off the **last** factor, so the last entries can be cancelled at once; comparing largest with largest needs only that the lists are non-decreasing.
  - Remark: fd2's `@exr-countable-sets-b2` line (vii) cites unique factorization, which fd2 could not use; it is now available (R2 below).
- **`prp-rationals-lowest-terms`.** Every x ∈ ℚ can be written x = p/q with p ∈ ℤ, q ∈ ℤ_{>0} and gcd(p, q) = 1, and the pair (p, q) is unique. Moreover, if x = r/s with s ∈ ℤ_{>0}, then q | s and r = (s/q)·p; so q is the least positive denominator of x (F3.2's §04 C1, N(x)). Proof: x = r/s (`@prp-integers-embed-rationals` (b)); d ≔ gcd(r, s) ≥ 1 (s ≠ 0); r = dp, s = dq with q > 0; from d = rx₀ + sy₀ = d(px₀ + qy₀) and d ≠ 0, px₀ + qy₀ = 1, so gcd(p, q) = 1 (`cor-coprime-iff-combination`); and r/s = p/q since rq = dpq = ps. Uniqueness and "moreover": p/q = r/s gives ps = rq; q | ps with gcd(q, p) = 1, so q | s (lemma); s = qt, then ps = rq gives r = pt (cancel q); if also gcd(r, s) = 1, then t > 0 divides r and s, hence divides gcd(r, s) = 1 (`thm-integers-bezout` (c)), so t = 1 (`prp-divisibility-rules-integers` (g)). Remark: fd2's `@lem-lowest-terms` (only "not both even") and `@exr-induction-in-practice-c2` (full sense, school ℚ) are the twins.
- **Warning (false conclusion: uniqueness is not automatic).** In H ≔ {1, 5, 9, 13, …} = {4k + 1 : k ∈ ℕ}, closed under ·, call h ∈ H with h > 1 "H-prime" if it is not a product of two elements of H both > 1. Then 9, 21, 49 are H-prime and 441 = 9·49 = 21·21: two different H-factorizations. Existence goes through in H (least counterexample); uniqueness fails, because Euclid's lemma fails: 9 | 21·21 in H, but 9 ∤ 21. The proof of the lemma used 1 = ax + by, a combination with **sums**, and H is not closed under +.

## 04-quotient-rings.md — Ideals, Quotient Rings, and ℤ/nℤ

- **Hook.** fd2 (`@prp-congruence-arithmetic`) made ℤ/n into a clock with + and ·, checking well-definedness by hand. F3.2 did the same check twice more. Here the check is done **once**, for every commutative ring and every "ideal"; ℤ/nℤ is the first example, and the same theorem will build ℝ from Cauchy sequences (F3.10, prose pointer) and F[x]/(f) (F4.5, prose pointer).
- **`def-ideal-commutative-ring`:** let R be a commutative ring (`@def-commutative-ring-and-field`). I ⊆ R is an **ideal** if 0 ∈ I; a, b ∈ I ⇒ a + b ∈ I; and a ∈ I, r ∈ R ⇒ ra ∈ I. (Then −a = (−1)a ∈ I, by `@prp-ring-algebra` (c).) Examples: {0}, R, nℤ and aℤ + bℤ in ℤ. Non-examples: ℕ in ℤ ((−1)·1 ∉ ℕ); ℤ in ℚ ((1/2)·1 ∉ ℤ).
- **`thm-quotient-ring-by-ideal`** (key proof; Before reading on: "where is 'ra ∈ I for every r ∈ R' used, and why does closure under + not suffice for the product?"). Let R be a commutative ring and I an ideal. (a) a ~_I b ⟺ a − b ∈ I is an equivalence relation on R; the class of a is a + I ≔ {a + x : x ∈ I}. (b) [a] + [b] ≔ [a + b], [a]·[b] ≔ [ab], −[a] ≔ [−a] are well defined on R/I ≔ R/~_I. (c) R/I with these operations is a commutative ring with zero [0] and one [1], and the quotient map π(a) ≔ [a] satisfies π(a + b) = π(a) + π(b), π(ab) = π(a)π(b), π(1) = [1]. (d) [a] = [0] ⟺ a ∈ I; and [1] = [0] ⟺ I = R.
  - Proof. (a) a − a = 0 ∈ I; b − a = (−1)(a − b); a − c = (a − b) + (b − c). x ∈ [a] ⟺ x − a ∈ I ⟺ x = a + (x − a). (b) By `@thm-well-defined-on-classes` (b), one argument at a time: if a − a′ ∈ I, then (a + b) − (a′ + b) = a − a′ ∈ I and ab − a′b = (a − a′)b ∈ I (**the ideal absorbs b**); the second argument by commutativity; −a − (−a′) = (−1)(a − a′) ∈ I, `@thm-well-defined-on-classes` (a). (c) Each axiom of `@def-commutative-ring-and-field` holds in R/I because both sides are classes of the two sides of the same identity in R (F3.2's move "reduce to the level below"; distributivity in full: [a]([b] + [c]) = [a(b + c)] = [ab + ac] = [a][b] + [a][c]). The equations for π are the definitions read backwards. (d) a − 0 ∈ I; [1] = [0] ⟺ 1 ∈ I ⟺ I = R (r = r·1).
  - *Idea:* a change of representative is an element of I; sums of such changes stay in I, and multiplying a change by anything stays in I.
- **Warning (false conclusion).** Closure under + and − is not enough for the product. ℤ ⊆ ℚ is closed under + and −, so ~ ("x − y ∈ ℤ") is an equivalence relation on ℚ and + on ℚ/ℤ is well defined; but [x][y] ≔ [xy] is not: [1/2] = [3/2], while (1/2)(1/2) = 1/4 and (3/2)(1/2) = 3/4, and 3/4 − 1/4 = 1/2 ∉ ℤ.
- **`thm-integer-ideals-principal`.** (a) For a, b ∈ ℤ, aℤ + bℤ is an ideal of ℤ; in particular nℤ is. (b) Every ideal I of ℤ equals nℤ for exactly one n ∈ ℕ: n = 0 if I = {0}, and otherwise n is the least positive element of I. Proof: (a) from the closure lines of `def-integer-linear-combinations`. ## 05-units-and-crt.md — Units Modulo n, the Field ℤ/pℤ, and the Chinese Remainder Theorem

- **Hook.** In ℤ/5ℤ every non-zero class can be divided by; in ℤ/6ℤ, [2] cannot. Which classes are invertible, and for which n are all of them?
- **`def-ring-unit`:** in a commutative ring R, u is a **unit** if uv = 1 for some v ∈ R. Such v is unique (v = v(uv′) = (vu)v′ = v′), written u⁻¹; R^× is the set of units; a product of units is a unit, (uw)⁻¹ = u⁻¹w⁻¹. A commutative ring with 1 ≠ 0 is a field (`@def-commutative-ring-and-field`) iff every non-zero element is a unit (that is axiom (F8)).
- **`thm-units-mod-n`.** Let n ∈ ℤ_{>0} and a ∈ ℤ. Then [a] is a unit of ℤ/nℤ iff gcd(a, n) = 1; in that case [a]⁻¹ = [x] for any x, y ∈ ℤ with ax + ny = 1 (computed by `thm-euclidean-algorithm-integers` and back-substitution). Proof: ⇐ `cor-coprime-iff-combination`: [a][x] = [ax] = [1 − ny] = [1]. ⇒ [a][x] = [1] means n | ax − 1, ax − 1 = ny, so 1 = ax + n(−y) and gcd(a, n) = 1 (`cor-coprime-iff-combination`).
- **`exm-unit-inverse-mod-n`:** [17] in ℤ/60ℤ: 60 = 3·17 + 9, 17 = 1·9 + 8, 9 = 1·8 + 1, 8 = 8·1; 1 = 9 − 8 = 2·9 − 17 = 2·60 − 7·17; so [17]⁻¹ = [−7] = [53] (17·53 = 901 = 15·60 + 1). Non-unit: [12] in ℤ/60ℤ, gcd 12, and [12][5] = [0]. Sidecar.
- **`thm-integers-mod-prime-field`** (stated so that F4.2 can cite it as "ℤ/pℤ is a field"). Let n ∈ ℤ with n ≥ 2. Then ℤ/nℤ is a field in the sense of `@def-commutative-ring-and-field` — a commutative ring with [1] ≠ [0] in which every non-zero element is a unit, i.e. (F1)–(F9) hold — **iff n is prime**. Proof: ⇐ [a] ≠ [0] means p ∤ a, so gcd(a, p) = 1 (`cor-prime-divides-product` (a)), and [a] is a unit (`thm-units-mod-n`); [1] ≠ [0] by `thm-integers-mod-n-ring` (c). ⇒ if n ≥ 2 is not prime, it has a positive divisor r ∉ {1, n}; n = rs with 1 < r < n and then 1 < s < n; [r] ≠ [0] ≠ [s] (n ∤ r, since 0 < r < n and `prp-divisibility-rules-integers` (e)); [r][s] = [0]. In a field xy = 0 and x ≠ 0 give y = x⁻¹xy = x⁻¹·0 = 0 (`@prp-ring-algebra` (b)); so ℤ/nℤ is not a field.
- **`thm-chinese-remainder-two`** (Try it first: "find an x with x ≡ 2 (mod 3) and x ≡ 3 (mod 5) by trying; then use 1 = 2·3 − 1·5 to find a formula that works for every right-hand side; ten minutes"). (a) For all a, b ∈ ℤ, x ≔ a·nv + b·mu satisfies x ≡ a (mod m) and x ≡ b (mod n); an integer x′ satisfies both congruences iff x′ ≡ x (mod mn). (b) The rule Φ([x]_{mn}) ≔ ([x]_m, [x]_n) is a well-defined bijection ℤ/mnℤ → ℤ/mℤ × ℤ/nℤ with Φ([x] + [y]) = Φ([x]) + Φ([y]), Φ([x][y]) = Φ([x])Φ([y]) (componentwise) and Φ([1]) = ([1], [1]).
