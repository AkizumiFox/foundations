**Purpose.**
- F3.10 builds ℝ as classes of Cauchy sequences of rationals. Every fact about sequences it uses must be proved **without ℝ**: the only numbers are those of F3.2, and ε ranges over ℚ_{>0}. This chapter proves those facts once, for an **arbitrary ordered field F**, so that F3.10 applies them with F = ℚ.
- Add to F3.2's ordered-field rules what limits need: fraction rules, halving, the absolute value and the triangle inequality; the copy of ℕ (and of ℚ, by the embedding ι_F) inside any ordered field; the Archimedean property as a property of F, with the integer part and the density of ℚ that it gives.
- Limits with ε ∈ F_{>0}: uniqueness, boundedness, the limit laws, limits and order. Cauchy sequences: convergent ⇒ Cauchy ⇒ bounded, closure under + and ·, the **sign theorem** for non-null Cauchy sequences, reciprocals.
- End with the gap F3.10 fills: F3.2's Newton sequence for √2 is Cauchy in ℚ with **no rational limit**.
- **Nothing here uses completeness**: no sup of a subset of F, no monotone convergence, no Bolzano–Weierstrass (§06 says so, checkably).
- The reader leaves able to (i) prove an inequality in F from the axioms; (ii) run an ε–N proof in which every constant is chosen before it is used and depends only on earlier quantities; (iii) say why a Cauchy sequence need not converge, with a rational example.

**Signature moves** (`index.md`, "Named moves").
- **Split ε.** To make a sum of k terms small, give each ε/k; combine thresholds by a maximum. (Faded triple.)
- **Bound, then shrink.** In a product, replace the factor you cannot control by a bound fixed in advance, then make the other factor small.
- **Fix the bad ε.** "Not null" is ∃ε ∀N ∃n ≥ N: it hands you one ε to keep for the rest of the proof.
- **Locate the missing limit.** With the limit laws, a would-be limit L must satisfy an equation (L² = 2) the field cannot solve.

## 01-rules-and-absolute-value.md — Working in an Ordered Field

- **Hook.** F3.2 proved the rules of inequalities from the axioms. Limits need a few more: halving a tolerance, comparing fractions, and measuring distance. Each is one line from F3.2's rules, and each is used dozens of times later.
- **Standing setup** (paragraph pointing back to `@def-ordered-ring-and-field`): F is an ordered field; `@thm-rationals-ordered-field` makes ℚ one; `@prp-ring-algebra`, `@prp-ordered-ring-rules`, `@prp-reciprocal-order` are used without restating them.
- **`lem-field-fraction-rules`** (F a field, `@def-commutative-ring-and-field`): for a, b, c, d ∈ F with b, d ≠ 0: (a) b⁻¹ is unique and (b⁻¹)⁻¹ = b; (bd)⁻¹ = b⁻¹d⁻¹; (b) a/b + c/d = (ad + bc)/(bd) and (a/b)(c/d) = (ac)/(bd); (c) 1/b − 1/d = (d − b)/(bd); (d) ab = 0 ⇒ a = 0 or b = 0 (for any a, b ∈ F). Proof: (a) b⁻¹ is unique, by the uniqueness argument of `@prp-ring-algebra` (a), and (b⁻¹)⁻¹ = b. Next, (bd)(b⁻¹d⁻¹) = 1. Hence bd ≠ 0, since otherwise 1 = 0·(b⁻¹d⁻¹) = 0 by `@prp-ring-algebra` (b), and uniqueness gives (bd)⁻¹ = b⁻¹d⁻¹. This makes bd a legal denominator in (b) and (c), which are then direct computation. (d) is the contrapositive of the bd ≠ 0 step: if ab = 0 and a ≠ 0, then b = a⁻¹(ab) = 0. Item order unchanged; all items proved in the text.
- **`prp-ordered-field-halves`**: in F: (a) ≤ is a total order on F (`@def-partial-order`) with < as its strict part: `@prp-ordered-ring-rules` (i) (pointer, not reproved); (b) 2 ≔ 1 + 1 > 0; for ε ∈ F_{>0}: 0 < ε/2 < ε and ε/2 + ε/2 = ε; for a < b: a < (a + b)/2 < b; (c) for a, b ∈ F_{>0}: a ≤ b ⇒ 1/b ≤ 1/a; (d) 0 ≤ a ≤ b and 0 ≤ c ≤ d ⇒ ac ≤ bd. Proof: (a) is `@prp-ordered-ring-rules` (i); (b)–(d) come from `@prp-ordered-ring-rules` (a)–(c), (e) and `@prp-reciprocal-order`, with (d) proved as ac ≤ bc ≤ bd.
- **`def-absolute-value-ordered-field`**: |x| ≔ x if x ≥ 0, −x if x < 0.
- **`prp-absolute-value-ordered-field`**: for x, y, z, r ∈ F: (a) |x| ≥ 0, and |x| = 0 iff x = 0; (b) |−x| = |x|, |xy| = |x||y|, |x|² = x², and |1/x| = 1/|x| for x ≠ 0; (c) −|x| ≤ x ≤ |x|; (d) |x| ≤ r iff −r ≤ x ≤ r, and |x| < r iff −r < x < r; (e) (triangle) |x + y| ≤ |x| + |y|, and |x − z| ≤ |x − y| + |y − z|; (f) (reverse triangle) ||x| − |y|| ≤ |x − y|. (a)–(d) by sign cases; (e) from (c), (d) with no case split; (f) from (e). Display the form used all chapter: **|a_n − a| < ε ⇔ a − ε < a_n < a + ε**.
- **Warning.** "a ≤ b and c ≤ d ⇒ ac ≤ bd" needs the nonnegativity of (d): a = c = −2, b = d = 0 gives 4 ≤ 0.
- **Quick check.** Is |a| − |b| ≤ |a − b| always? Is |a − b| ≤ |a| − |b|? (Yes, by (f); no: a = 0, b = 1.)
- **Exercises.**
  - **A1:** name the rule behind each step of 0 < 1/2 < 1 in F (`@prp-ordered-ring-rules` (e) for 1 > 0, (b) for 2 > 1 > 0, `@prp-reciprocal-order` for 0 < 1/2 < 1/1). **A2:** true or false in every ordered field, with reason or counterexample in ℚ: a < b ⇒ a² < b² (false: −2 < 1); |a| < |b| ⇒ a < b (false: a = 1, b = −2); x² + 1 > 0 (true).
  - **B1:** prove (c) and (d) of `prp-ordered-field-halves`. **B2:** solve |2x − 3| < 5 in F (−1 < x < 4), naming each rule. **B3:** |a + b + c| ≤ |a| + |b| + |c| and ||a| − |b|| ≤ |a + b|.
  - **C1:** x² = −1 has no solution in an ordered field (`@prp-ordered-ring-rules` (e)); prose pointer: so the complex numbers of fd4 cannot be ordered.

## 02-naturals-and-archimedes.md — ℕ and ℚ inside an Ordered Field; the Archimedean Property

- **Hook.** In F the elements 1, 1 + 1, 1 + 1 + 1, … behave like 1, 2, 3, … Do they? And does every element of F lie below one of them? In ℚ, F3.2 proved yes; in general, no.
- **`def-naturals-in-ordered-field`**: n·1_F for n ∈ ℕ (F3.2's n·a, defined by (ℕ7)); powers x⁰ ≔ 1, x^{k+1} ≔ x^k·x for x ∈ F, k ∈ ℕ (`@thm-recursion` with X = F); and, by the same recursion with X = ℕ ((ℕ7)), powers of natural numbers n⁰ ≔ 1, n^{k+1} ≔ n^k·n for n, k ∈ ℕ. (Defined here, not ledgered as an F3.1 fact. The only ℕ-power used in fd3 is 2^k, in (c), §02 B3, §06 B2 (the index of H_{2^k}) and §06 R2. F3.10 and F3.4 use only powers in F: (2·1_F)^k in F3.10's `lem-power-two-bound`, 10^k and 3^k in ℚ in F3.10 (§01, R3), and the power in F behind 10^{-n} in F3.4's R4.)
- **`prp-naturals-in-ordered-field`**: for m, n, k ∈ ℕ: (a) (m + n)·1_F = m·1_F + n·1_F and (mn)·1_F = (m·1_F)(n·1_F); (b) m < n ⇒ m·1_F < n·1_F (`@prp-ordered-ring-rules` (h)), so n ↦ n·1_F is injective, and n·1_F ≥ 1 for n ≥ 1; (c) (n^k)·1_F = (n·1_F)^k, in particular (2^k)·1_F = (2·1_F)^k, the k-th power in F of 2 = 1 + 1 (proof by induction on k: base n⁰·1_F = 1·1_F = 1_F = (n·1_F)⁰; step (n^{k+1})·1_F = (n^k·n)·1_F = ((n^k)·1_F)(n·1_F) by (a)); (d) in ℚ, n·1_ℚ is the image of n under `@prp-naturals-embed-integers` and `@prp-integers-embed-rationals` (both satisfy the recursion of n·1; uniqueness in `@thm-recursion`). Proofs: (a) the sum law is `@prp-ordered-ring-rules` (h) with R = F and a = 1_F (pointer, not reproved). The product law (mn)·1_F = (m·1_F)(n·1_F) is proved by `@ax-induction` on n with m fixed, base P(0): (m·0)·1_F = 0·1_F = 0 = (m·1_F)·0 = (m·1_F)(0·1_F) (`@prp-ring-algebra` (b)); step: (m(n + 1))·1_F = (mn + m)·1_F = (mn)·1_F + m·1_F (sum law) = (m·1_F)(n·1_F) + (m·1_F)·1_F = (m·1_F)((n + 1)·1_F), using (ℕ1) (m(n + 1) = mn + m) and the defining equations 0·a = 0, (n + 1)·a = n·a + a of F3.2's n·a (from (ℕ7)). (b) is `@prp-ordered-ring-rules` (h) (1_F ≠ 0 in a field); injectivity follows by trichotomy, and n·1_F ≥ 1 for n ≥ 1 comes from (h) with m = 1 and 1·1_F = 0·1_F + 1_F = 1_F. After (d) the text writes n for n·1_F where no confusion arises, and says so.
- **`thm-rationals-embed-ordered-field`** (the embedding of ℚ; F3.10, F3.4 and F3.3 use it). For every ordered field F there is **exactly one** map ι_F: ℚ → F with ι_F(1) = 1_F, ι_F(x + y) = ι_F(x) + ι_F(y) and ι_F(xy) = ι_F(x)ι_F(y) for all x, y ∈ ℚ; it extends n ↦ n·1_F (ι_F(n) = n·1_F for n ∈ ℕ), is injective and strictly increasing, and reflects order (ι_F(x) < ι_F(y) ⇒ x < y, by trichotomy). Route: for m ∈ ℤ put m·1_F ≔ n·1_F if m = n ∈ ℕ and −(n·1_F) if m = −n (by `@prp-naturals-embed-integers` (c), every m ∈ ℤ is n or −n with n ∈ ℕ; the cases overlap only at m = 0, since n = −n′ with n, n′ ≥ 0 forces n = n′ = 0 by `@thm-integers-ordered-ring` (b), and there 0·1_F = 0 = −(0·1_F)); extend (a) to ℤ by sign cases (two in full, the rest "the same with signs", all in the text); ι_F(p/q) ≔ (p·1_F)(q·1_F)⁻¹ for p ∈ ℤ, q ∈ ℤ_{>0}, well defined because p/q = r/s ⟺ ps = rq (`@prp-integers-embed-rationals` (b)) and (a) on ℤ; + and · by `lem-field-fraction-rules` (b); strictly increasing since x > 0 means x = p/q with p, q ∈ ℤ_{>0} (the comparison formula of `@thm-rationals-ordered-field`), so ι_F(x) > 0 by (b) and `@prp-reciprocal-order`. Uniqueness: any such ψ has ψ(0) = 0, ψ(n) = n·1_F by induction, ψ(−x) = −ψ(x), ψ(1/q)ψ(q) = 1. Remark: after this, "ℚ ⊆ F" is an honest abuse, and the text writes q for ι_F(q) where only one field is in play. Remark (one sentence, used by F3.4): uniqueness says every additive, multiplicative χ: F → L with χ(1) = 1 has χ ∘ ι_F = ι_L, since χ ∘ ι_F is such a map ℚ → L.
- **`def-archimedean-ordered-field`**: F is **Archimedean** if for every x ∈ F there is n ∈ ℕ with x < n·1_F. By (d), `@thm-rationals-archimedean` says exactly that ℚ is Archimedean.
- **`prp-archimedean-reciprocal`** (generalizes `@cor-rationals-archimedean-epsilon` to any F): if F is Archimedean, then for every ε ∈ F_{>0} there is N ∈ ℤ_{>0} with 1/(n·1_F) < ε **for every n ≥ N**. Proof: N with N·1_F > 1/ε; N ≠ 0; for n ≥ N, n·1_F ≥ N·1_F > 1/ε > 0, so `@prp-reciprocal-order`. Quantifier order displayed; N depends on ε.
- **`prp-integer-part-ordered-field`** (generalizes F3.2's `@prp-rational-integer-part`). If F is Archimedean, then for every x ∈ F there is **exactly one** m ∈ ℤ with ι_F(m) ≤ x < ι_F(m + 1). Proof in the text: S ≔ {k ∈ ℤ : x < ι_F(k)} is non-empty (Archimedes for x) and has an integer lower bound −n, where −x < n·1_F (Archimedes for −x; then ι_F(k) > x > ι_F(−n), so k > −n because ι_F reflects order); its least element (`@prp-integer-least-element`) is m + 1, and m ∉ S gives ι_F(m) ≤ x. ## 03-limits.md — Sequences and Limits in an Ordered Field

- **Hook.** In ℚ, 1/2, 2/3, 3/4, … "tends to 1". Say what that means with only rationals to measure with, and prove it has at most one meaning.
- **`def-sequence-ordered-field`**: a sequence in F is a function a: ℕ → F (`@def-function`), written (a_n)_{n∈ℕ}; a property holds **eventually** if it holds for every n ≥ N₀, for some N₀.
- **`def-sequence-limit-ordered-field`** (major: full template; slogan *every tolerance in F is eventually met*): a_n → a in F if ∀ε ∈ F_{>0} ∃N ∈ ℕ ∀n ∈ ℕ (n ≥ N ⇒ |a_n − a| < ε). The domain of ε is part of the definition: for F = ℚ, ε is rational. Pointing back to `@exm-translate-limit` (the same formula, read in school ℝ). Divergent; negation in symbols (`@prp-bounded-quantifier-negation`).
- **`def-null-sequence-ordered-field`**: a_n → 0. **`def-bounded-sequence-ordered-field`**: ∃M ∈ F_{>0} ∀n |a_n| ≤ M.

## 04-limit-laws.md — The Algebra and Order of Limits

- **Hook.** Every limit so far was estimated by hand. Laws for sums, products and quotients compute limits from known ones, in any ordered field.

  - (a) **split ε**, in full (the faded triple's full version).
  - (c) *Idea:* a_n b_n − ab = a_n(b_n − b) + b(a_n − a); |a_n| is not small, but it is bounded. *Proof:* M ∈ F_{>0} with |a_n| ≤ M for all n (`prp-convergent-bounded-ordered-field`), **fixed before ε**; N₁ with |b_n − b| < ε/(2M); N₂ with |a_n − a| < ε/(2(|b| + 1)) (the + 1 covers b = 0); N ≔ max; the estimate by `prp-absolute-value-ordered-field` and `prp-ordered-field-halves` (d).
