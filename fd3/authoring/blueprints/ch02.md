**Purpose.**
- In ℕ (F3.1's ω) the equation 5 + x = 3 has no solution, and 2x = 1 none in ℤ. Build ℤ and then ℚ **as sets**, each as a quotient of pairs by an equivalence relation, so that subtraction and division become possible, and prove that the result is an ordered ring (ℤ) and an **ordered field** (ℚ) containing a copy of what came before.
- Make **well-definedness** the chapter's central skill: an operation on classes is defined through representatives and must be checked not to depend on them. State it once as a general lemma (`thm-well-defined-on-classes`) and use it for every operation and relation.
- Hand F3.9 exactly what it needs: the ordered-field axioms (own labels, below) with ℚ as a proved instance, the first rules of inequalities, the **Archimedean property of ℚ** with rational ε, the integer part of a rational, and **the gaps in ℚ** (no rational square root of 2; {x ∈ ℚ : x² < 2} is bounded above with no supremum in ℚ; a rational Newton sequence that "should" converge to √2) as the motivation for F3.10.
- The reader leaves able to (i) define an operation on a quotient and check it on representatives, one argument at a time; (ii) verify a ring or field axiom on classes by reducing it to an identity in the previous number system; (iii) prove a rational inequality from the axioms, not from pictures.

**Signature moves** (`index.md`, "Named moves"):
- **Check on representatives, one argument at a time.** To show [x] ∗ [y] ≔ [x ∗ y] is well defined, change x to an equivalent x′ with y fixed, then y with x fixed, and join the two by transitivity. (Faded triple.)
- **Reduce to the level below.** An axiom about classes becomes, on representatives, an identity or inequality in ℕ (for ℤ) or in ℤ (for ℚ), which is already known.
- **Order from a positive set.** Specify the positive elements P, check closure and trichotomy, and let a < b mean b − a ∈ P (`prp-order-from-positives`).

## 01-integers-as-classes.md — ℤ as Classes of Pairs

- **Hook (a naive notion that fails).** Try "an integer is a natural number with a sign": then 0 has two names (+0, −0), and addition needs four sign cases with a subtraction in ℕ that only works one way round. Pairs record "a − b" without performing it.
- **`def-integers-as-classes`:** on ℕ × ℕ, (a, b) ~ (c, d) ⟺ a + d = b + c; ℤ ≔ (ℕ × ℕ)/~ (`@def-quotient-set`). Full explain template (major for fd3; slogan: *an integer is a difference you have not computed yet*). Say: an element of ℤ is a **set of pairs**, not a number with a sign (compare fd2's "a pair is not a number", `@def-ordered-pair`).
- **`prp-integer-pairs-equivalence`** (Before reading on): ~ is an equivalence relation (`@def-equivalence-relation`). Reflexive and symmetric by (ℕ1). Transitive: from a + d = b + c and c + f = d + e, add: a + d + c + f = b + c + d + e; cancel c + d (ℕ2) to get a + f = b + e. Warning inside the proof: we may not "subtract d", since ℕ has no subtraction; cancellation is the legal step.

## 02-well-defined-operations.md — Well-Definedness, and the Arithmetic of ℤ

- **Hook.** fd2 (`@prp-congruence-arithmetic`, `@exm-ill-defined-class-map`) already met "well defined" for ℤ/n. This section isolates the lemma once, for every quotient in fd3 (ℤ here, ℚ in §04, ℝ in F3.10).
- **`thm-well-defined-on-classes`** (the central lemma). Let ~ be an equivalence relation on X and ≈ one on Y.
  - (a) If f : X → Y satisfies x ~ x′ ⇒ f(x) ≈ f(x′) for all x, x′ ∈ X, then there is **exactly one** function F : X/~ → Y/≈ with F([x]) = [f(x)] for every x ∈ X.
  - (b) If g : X × X → X satisfies, for all x, x′, y, y′ ∈ X, x ~ x′ ⇒ g(x, y) ~ g(x′, y) and y ~ y′ ⇒ g(x, y) ~ g(x, y′), then there is exactly one G : (X/~) × (X/~) → X/~ with G([x], [y]) = [g(x, y)].
  - (c) If S ⊆ X satisfies x ~ x′ and x ∈ S ⇒ x′ ∈ S, then S̄ ≔ {[x] : x ∈ S} satisfies [x] ∈ S̄ ⟺ x ∈ S, for every x ∈ X.
  - Proof of (a): F ≔ {([x], [f(x)]) : x ∈ X} ⊆ (X/~) × (Y/≈); every class is some [x] (`@def-quotient-set`); if ([x], [f(x)]) and ([x′], [f(x′)]) have [x] = [x′], then x ~ x′ (`@thm-classes-partition`), so [f(x)] = [f(x′)]: exactly one output (`@def-function`). Uniqueness: two such functions agree on every [x], hence everywhere (`@prp-function-equality`). (b): x ~ x′ and y ~ y′ give g(x, y) ~ g(x′, y) ~ g(x′, y′), transitivity; then let G ≔ {(([x], [y]), [g(x, y)]) : x, y ∈ X} ⊆ ((X/~) × (X/~)) × (X/~). Every element of (X/~) × (X/~) is some ([x], [y]) (`@def-quotient-set`). If ([x], [y]) = ([x′], [y′]), then [x] = [x′] and [y] = [y′] (`@def-ordered-pair`), so x ~ x′ and y ~ y′ (`@thm-classes-partition`), and the chain above gives [g(x, y)] = [g(x′, y′)]: exactly one output (`@def-function`). Uniqueness as in (a) (`@prp-function-equality`). No product relation on X × X is introduced. (c): ⇐ is the definition; ⇒: [x] = [x′] with x′ ∈ S gives x ~ x′, and the hypothesis (with symmetry) gives x ∈ S.
  - **Remark (each hypothesis has a job):** without the hypothesis of (c), S = {(a, b) : a > 0} on ℕ × ℕ gives [(0, 0)] = [(1, 1)] ∈ S̄ while (0, 0) ∉ S.

- **`def-commutative-ring-and-field`:** a **commutative ring** is a set R with + and · satisfying (F1)–(F7) and (F9) of linear algebra's numbering **except** that (F7) here does not require 1 ≠ 0; a **field** is a commutative ring with 1 ≠ 0 satisfying (F8). - **`prp-ring-algebra`:** in a commutative ring R, for a, b ∈ R: (a) 0, 1, −a are unique, −(−a) = a; (b) a · 0 = 0; (c) (−a)b = −(ab), (−a)(−b) = ab; (d) (a + b)² = a² + 2ab + b², with 2 ≔ 1 + 1. Proof by uniqueness ("show it satisfies the defining equation"); (a), (b) in full, (c), (d) briefly.
- **`def-ordered-ring-and-field`:** an **ordered commutative ring** is a commutative ring with a relation < satisfying (O1) trichotomy, (O2) transitivity, (O3) a < b ⇒ a + c < b + c, (O4) 0 < a, 0 < b ⇒ 0 < ab; an **ordered field** is a field that is an ordered commutative ring. - **`prp-order-from-positives`:** let R be a commutative ring and P ⊆ R with (P1) a, b ∈ P ⇒ a + b ∈ P and ab ∈ P, and (P2) for every a exactly one of a ∈ P, a = 0, −a ∈ P. Define a < b ⟺ b − a ∈ P. Then (R, <) satisfies (O1)–(O4) and P = {a : a > 0}. Conversely, in an ordered commutative ring, P ≔ {a : a > 0} satisfies (P1)–(P2). Proof in full ((O1) from (P2) applied to b − a, with −(b − a) = a − b by `prp-ring-algebra`; (O2) from closure under +; (O3) since (b + c) − (a + c) = b − a; (O4) from closure under ·).

## 05-ordered-field-of-rationals.md — ℚ as an Ordered Field; the Archimedean Property

- **`def-rational-order`:** P_ℚ ≔ {[(p, q)] : p > 0}; well defined by `thm-well-defined-on-classes` (c) because q > 0.
- **`thm-rationals-ordered-field`** (key proof; Before reading on: "where is q > 0 used?"). ℚ with `def-rational-order` is an ordered field (`def-ordered-ring-and-field`); moreover p/q < r/s ⟺ ps < rq for q, s ∈ ℤ_{>0}, and j(m) < j(n) ⟺ m < n. Proof via `prp-order-from-positives`:
  - P_ℚ well defined: if pq′ = p′q, q, q′ > 0 and p > 0, then p′q = pq′ > 0, so p′ > 0 (p′ ≤ 0 would give p′q ≤ 0 by `prp-ordered-ring-rules` (c)).
  - (P1): [(p, q)] + [(r, s)] = [(ps + rq, qs)] with ps + rq > 0 (products and sums of positives in ℤ); product [(pr, qs)], pr > 0.
  - (P2): p > 0, p = 0 or −p > 0, exactly one (trichotomy in ℤ); and [(p, q)] = 0 ⟺ p = 0.
  - The comparison formula: r/s − p/q = [(rq − ps, qs)], positive iff rq − ps > 0.
- **`prp-reciprocal-order`:** in an ordered field, a > 0 ⇒ a⁻¹ > 0, and 0 < a < b ⇒ 0 < 1/b < 1/a. (Proof from `prp-ordered-ring-rules` (c), (e).)
- **Midpoints, briefly** (no label): for rationals a < b, a < (a + b)/2 < b; so there is no least positive rational (x/2 < x). Warning: density is not "next to".
- **`thm-rationals-archimedean`** (Try it first): for every x ∈ ℚ there is n ∈ ℕ with x < n. Proof: x = p/q, q ∈ ℤ_{>0}. If p ≤ 0, then x ≤ 0 < 1. If p > 0, then p ∈ ℕ, q ≥ 1 (discreteness), so p ≤ pq, i.e. p/q ≤ p (comparison formula), and p < p + 1 ∈ ℕ. **No supremum and no completeness is used**: say so; this is the point of contrast with an1 and with ℝ(x) (prose only).
- **`cor-rationals-archimedean-epsilon`:** for every ε ∈ ℚ_{>0} there is n ∈ ℤ_{>0} with 1/n < ε; every m ≥ n then works too. Proof: n > 1/ε by the theorem, then `prp-reciprocal-order`. Quantifier order shown in symbols: n depends on ε (fd1's `@prp-quantifier-negation` for the swapped version's negation is the A item). This is the form F3.9 uses with **rational ε**.
- **`prp-rational-integer-part`:** for every x ∈ ℚ there is exactly one m ∈ ℤ with m ≤ x < m + 1; write ⌊x⌋. Proof: S ≔ {k ∈ ℤ : x < k} is non-empty (theorem) and has an integer lower bound −n with n > −x (theorem applied to −x; then every k ∈ S has k > x > −n); its least element is m + 1 (`prp-integer-least-element`), and m ∉ S gives m ≤ x. ## 06-gaps-in-the-rationals.md — The Gaps in ℚ

- **Hook.** ℚ is an ordered field, Archimedean, and dense in itself. Is anything missing? The diagonal of the unit square.
- **`thm-no-rational-square-two`:** there is no x ∈ ℚ with x² = 2. **Descent proof** (proof ordering item; differs from fd1's parity proof, which used school facts about ℚ). Suppose x² = 2; x ≠ 0, and (−x)² = x², so take x > 0, x = p/q with p, q ∈ ℤ_{>0}; then p² = 2q² in ℤ (`prp-integers-embed-rationals` (b)). Let q be least in D ≔ {q ∈ ℤ_{>0} : p² = 2q² for some p ∈ ℤ_{>0}} (`prp-integer-least-element`). Then q < p (else q² ≥ p² = 2q², so q² ≤ 0) and p < 2q (else p² ≥ 4q² > 2q²), by `prp-ordered-ring-rules` (g). Put p′ ≔ 2q − p and q′ ≔ p − q, both in ℤ_{>0}, q′ < q, and p′² − 2q′² = 2q² − p² = 0 (`prp-ring-algebra` (d)). So q′ ∈ D, contradicting minimality. Remark: this is ¬I on "x² = 2" (`@def-rules-negation`), with no RAA (`@def-rule-raa`). Prose comparison: fd1's `@thm-sqrt2-irrational` proves the same statement about the school ℚ by parity; here we have no parity yet (F3.5).
- **`thm-rationals-gap-sqrt2`** (key proof; Try it first): let A ≔ {x ∈ ℚ : x² < 2} and A⁺ ≔ {x ∈ A : x > 0} = {x ∈ ℚ : x > 0, x² < 2}. (b) A⁺ has the same rational upper bounds as A, so A⁺ is also non-empty, bounded above, and has no supremum in ℚ (this is fd2 ch07 §06's set, 06-orders.md:219).
  - Proof of (b), one line: 1 ∈ A⁺ ⊆ A, so every upper bound of A bounds A⁺; conversely an upper bound u of A⁺ has u ≥ 1 > 0 ≥ x for every non-positive x ∈ A, and u bounds the positive elements of A, which are A⁺ (`prp-ordered-ring-rules` (i), `thm-rationals-ordered-field`). Equal sets of upper bounds give equal (non-)existence of a least one (`@def-order-supremum`), so (a) gives (b).
  - Bounded: 2 is an upper bound (x ≥ 2 > 0 gives x² ≥ 4).
  - Two maps, for rational s > 0: t(s) ≔ (s² + 2)/(2s) and u(s) ≔ 4s/(s² + 2) = 2/t(s). Identities (sidecar): t(s)² − 2 = (s² − 2)²/(4s²); s − t(s) = (s² − 2)/(2s); u(s) − s = s(2 − s²)/(s² + 2); 2 − u(s)² = 2(s² − 2)²/(s² + 2)².
  - Suppose s = sup A in ℚ. Then s ≥ 1 > 0 (1 ∈ A), and s² ≠ 2 (`thm-no-rational-square-two`). If s² < 2: u(s) ∈ A and u(s) > s, so s is not an upper bound. If s² > 2: t(s) < s, and t(s) is an upper bound (t(s) > 0 and t(s)² > 2; for x ∈ A, x > t(s) would give x² > t(s)² > 2 by `prp-ordered-ring-rules` (g)), so s is not the least. Contradiction either way (trichotomy).
